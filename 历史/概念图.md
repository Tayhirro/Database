# 历史概念图（时间线与依赖关系）

## 1. 行政区划制度演化

### 1.1 制度演变链
```
州郡县制（秦汉-隋）
    │
    ├─ 秦：郡县两级，36郡
    ├─ 汉：州（监察）-郡-县三级演变
    │   ├─ 西汉：13刺史部（监察区）
    │   └─ 东汉末：州行政化，州牧制度
    ├─ 三国两晋南北朝：州郡数量激增，侨置州郡
    └─ 隋：废郡，回归州县两级
        ↓
道路制（唐宋）
    │
    ├─ 唐：贞观十道 → 开元十五道（监察区）
    │   └─ 安史之乱后：节度使-道-州（军政合一）
    └─ 宋：路-州-县，四监司分权制衡
        ├─ 帅司（安抚司）：军事
        ├─ 漕司（转运司）：财政
        ├─ 宪司（提刑司）：司法
        └─ 仓司（常平司）：民生
        ↓
行省制（元明清）
    │
    ├─ 元：行中书省（中央派出）
    │   ├─ 腹里（中书省直辖）
    │   └─ 10行省
    ├─ 明：承宣布政使司（三司分权）
    │   ├─ 两京十三司
    │   └─ 巡抚、总督逐渐成型
    └─ 清：省-府-县，督抚制定型
        └─ 18省（内地）+ 边疆特区
        ↓
现代省制（民国-今）
    └─ 基本继承清制，省界微调
```

### 1.2 典型州郡演变示例（江州/九江）
```
晋代（304年）
    └─ 设江州，治浔阳（今九江）
        ↓
唐代（618-907）
    ├─ 江州（州级）
    ├─ 浔阳郡（天宝年间改郡名）
    └─ 辖：浔阳、彭泽、都昌
    └─ 白居易贬江州司马（815-818）
        ↓
宋代（960-1279）
    ├─ 江州（州级）
    ├─ 属江南东路/西路
    └─ 辖：德化、德安、瑞昌、湖口、彭泽、都昌
        ↓
元代（1277年）
    └─ 升江州路（路级）
        ↓
明代（1368年）
    └─ 改九江府（府级）
        ↓
清代（1644-1912）
    ├─ 九江府
    ├─ 辖：德化、德安、瑞昌、湖口、彭泽
    └─ 1858年开埠（通商口岸）
        ↓
现代（1949-今）
    └─ 九江市（地级市）
```

## 3. 学习路径建议

### 3.1 理解行政区划制度的前置知识
1. **基础概念**：州、郡、县、道的区别 → `structures/administrative/州郡县制.md`
2. **制度演变**：从监察区到行政区 → `structures/administrative/道路制.md`
3. **现代源头**：省制的形成 → `structures/administrative/行省制.md`
4. **典型案例**：具体州郡的沿革 → `structures/administrative/江州.md`

### 3.2 理解李泰需要的前置知识
1. **朝代背景**：唐朝建立与发展 → `structures/dynasties/唐朝.md`
2. **时代特征**：贞观之治 → `structures/periods/贞观之治.md`
3. **储位制度**：唐代皇位继承制度
4. **文学发展**：初唐文学 → `../文学/structures/periods/TangPoetry.md`

### 3.3 从行政区划延伸的学习方向
1. **制度史**：地方行政制度的演变逻辑
2. **政治史**：中央与地方权力分配（如藩镇割据、三司分权）
3. **文化史**：行政区划与文化区划的关系（如"江西"的文化认同）
4. **文学史**：贬谪路线与文学发生（江州司马、永州司马等）

### 3.4 从李泰延伸的学习方向
1. **政治史**：储位之争、唐初政治斗争
2. **文化史**：《括地志》、唐代地理学发展
3. **文学史**：初唐文学、魏王府文人集团
4. **制度史**：唐代藩王制度、亲王府的组织

## 4. 跨领域关联

### 4.1 历史 ↔ 文学
- 李泰：历史人物 + 文学作家
- 曹植：历史人物 + 文学作家（可参考此模式）

### 4.2 历史 ↔ 地理
- 《括地志》：历史文献 + 地理著作
- 江州：行政区划 + 文化地理空间
- 浔阳江：自然地理 + 文学意象

### 4.3 行政区划 ↔ 文学
- **贬谪制度**：州郡等级决定贬谪远近，影响文学创作
  - 江州司马（白居易《琵琶行》）
  - 永州司马（柳宗元《永州八记》）
- **空间意象**：行政区划名称成为文学意象
  - "浔阳江头夜送客"（江州）
  - "烟花三月下扬州"（扬州）
  - "西出阳关无故人"（关州/关外）
- **地域文化**：行政区划边界与文化流派形成
  - 江西诗派（宋代江南西路）
  - 桐城派（清代安徽省桐城县）
