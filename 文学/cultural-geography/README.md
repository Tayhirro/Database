# 文化地理（Cultural Geography）

## 说明

本目录收录具有文学意义的地理空间，这些空间因特定文学作品、历史事件或文化记忆而被赋予超越纯地理的文学意涵。

---

## 组织方式

按**地理层级**组织：
- **一级空间**：大型地理单元（长江、黄河、江南、中原等）
- **二级空间**：具体地点（浔阳江、赤壁、长安等）
- **三级空间**：具体点位（湓浦口、浔阳楼等）

---

## 条目结构

每个文化地理空间条目包含：
1. **地理坐标**：实际地理位置
2. **文学意象**：该空间在文学中的典型象征
3. **核心文本**：关联的代表作品
4. **意象谱系**：该空间衍生的各类意象
5. **历史地位**：地理与历史背景

---

## 与文学其他部分的关联

- **works/**：空间作为作品背景
- **authors/**：作家与空间的关联（贬谪、游历、故乡）
- **modules/意象**：空间意象的修辞分析
- **历史/**：空间的历史事件背景
