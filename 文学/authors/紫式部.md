# 紫式部（Murasaki Shikibu / 生卒年不详，约 10–11 世纪）

## 1. 一句话
- 平安时代女作家，以《源氏物语》确立了日本古典叙事的高峰：把宫廷社会的礼法与情感纠葛写成极细密的心理与关系网络。

## 2. 基本信息
- **生卒**：不详（约 973?–1014?）
- **国籍**：日本
- **活跃时期**：平安时代中后期
- **所属流派**：王朝文学 / 日本古典文学
- **主要体裁**：物语（长篇叙事散文）、日记文学（相关作品与传世材料）

## 3. 生平要点
- **早期**：出身于中下级贵族与文人传统家庭（藤原北家旁支等说法常见），受汉学与和歌文化熏陶。
- **创作生涯**：大体在平安宫廷文化圈中完成《源氏物语》的写作与修订，并以和歌与叙事写作立名。
- **重要转折**：入宫廷侍奉（一条天皇中宫藤原彰子），对宫廷礼法、权力结构与女性处境的近距离观察，成为其叙事材料的重要来源。
- **晚期**：生平细节记载有限，后世多通过作品与零散史料推测。

## 4. 风格特征
- **主题偏好**：无常（物哀）、情感与礼法的张力、身份与目光政治、记忆与替代。
- **叙事特点**：叙述距离灵活；擅长用场景与细部动作呈现人物心理；以关系网络推动情节。
- **语言风格**：含蓄、细腻、重“余韵”；常借季节意象、香与衣物等符号系统组织情感表达。
- **形式创新**：将和歌、典故与礼法化的交流方式整合进叙事机制，使“抒情”与“叙事”互为驱动。

## 6. 文学史定位
- **贡献**：把长篇叙事推进到“心理与关系网络”层面的复杂度；为日本叙事传统提供范式级样本。
- **影响**：对日本古典审美（物哀、幽玄）与后世叙事写作影响深远；亦是世界文学研究中的关键文本作者。
- **评价变迁**：从宫廷经典到现代研究热点（叙事学、文化史、性别研究、接受史等多路径）。
