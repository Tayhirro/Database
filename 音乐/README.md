# 音乐知识库说明

这套知识库按“内容用途”组织，不再使用含义模糊的 `structures/modules` 分类：

- **theory**：解释概念与规律，包括基础乐理、和声、节奏、旋律、曲式和进阶理论。
- **practice**：记录可以直接练习或制作的内容，包括创作、节奏训练、编曲和音乐制作。
- **reference**：保存体裁、乐器与音源等分类资料，用来描述作品和制作素材，而不是冒充“音乐结构”。
- **library**：保存具体作品与艺人卡片。
- **inbox**：暂未拆分的随手笔记，整理后再归入前四类。
- **resources**：教材、PDF 等外部资料。

> [!important] 两个容易混淆的边界
> - 节奏理论在 `theory/03-rhythm`；鼓组、律动和风格节奏练习在 `practice/rhythm`。
> - 二部、三部、回旋、奏鸣以及流行歌曲段落结构统一在 `theory/05-form`。

## 维护约定

- 新概念先判断是“解释规律”还是“训练方法”，分别进入 `theory/` 或 `practice/`。
- 新体裁、乐器与音源进入 `reference/`；具体软件音源集中追加到 `reference/instruments/音乐-音源库.md`。
- 新作品、艺人进入 `library/works/`、`library/artists/`。
- 尚未判断归属的内容先放 `inbox/`，不要直接堆在根目录。
- 内部笔记优先使用 Obsidian Wikilink，外部网页才使用普通 Markdown 链接。
