# 乐句乐段（Musical Phrase and Period）

## 定义

### 乐句（Phrase）
乐句是旋律的基本结构单位，通常由2-4小节组成，具有相对完整的音乐意义。

### 乐段（Period）
乐段是由若干乐句组成的更大的音乐结构单位，通常包含完整的音乐思想。

## 乐句的结构

### 长度
- **典型长度**：4小节（最常见）
- **短乐句**：2小节
- **长乐句**：8小节或更长
- **不规则乐句**：3、5、6、7小节等

### 乐句的组成

#### 1. 动机（Motive）
- 最小的音乐单位
- 通常1-2小节
- 具有独特的节奏或旋律特征
- 乐句由动机发展而来

#### 2. 乐节（Sub-phrase）
- 乐句的一半
- 通常2小节
- 2个乐节构成一个乐句

### 乐句的类型

#### 1. 陈述性乐句
- 提出音乐主题
- 通常在乐曲开始
- 较为完整

#### 2. 呼应性乐句
- 回应前一乐句
- 形成对话效果

#### 3. 过渡性乐句
- 连接不同段落
- 可能不太完整

#### 4. 结束性乐句
- 终止感强
- 明确的终止式

## 乐句的终止式

### 1. 完全终止（Perfect Cadence）
- V → I
- 最强的终止感
- 通常用于乐段结束

### 2. 半终止（Half Cadence）
- 任何和弦 → V
- 不完全的终止
- 制造悬念，等待继续

### 3. 不完全终止（Imperfect Cadence）
- V → 非I和弦
- 或主和弦在旋律声部不是主音

### 4. 变格终止（Plagal Cadence）
- IV → I
- "阿门终止"
- 较为柔和

### 5. 阻碍终止（Deceptive Cadence）
- V → VI（最常见）
- 欺骗性进行
- 延缓结束

## 乐句的关系

### 1. 平行关系
- 两个乐句旋律相似
- 可能节奏相同，音高略有变化
- 记为：a + a'

### 2. 对比关系
- 两个乐句旋律材料不同
- 形成对比
- 记为：a + b

### 3. 承接关系
- 后句继续前句的发展
- 自然连贯

### 4. 呼应关系
- 问句与答句
- 上句与下句

## 乐段的结构

### 单乐句乐段
- 只有一个乐句
- 较少见
- 通常4小节

### 双乐句乐段（Period）
最常见的乐段结构

#### 1. 平行乐段（Parallel Period）
- 两个乐句主题相似
- 结构：a + a'
- 例：
  - 第一句：4小节，半终止
  - 第二句：4小节（与第一句相似），完全终止

#### 2. 对比乐段（Contrasting Period）
- 两个乐句主题对比
- 结构：a + b
- 提供变化和对比

### 三乐句乐段
- 结构可能：a + b + a'
- 或：a + a' + b
- 常见于民歌

### 四乐句乐段
- 16小节（4×4）
- 结构多样：
  - a + a' + b + a''
  - a + b + a' + c
  - a + b + c + d

## 乐段的扩展手法

### 1. 重复（Repetition）
完全或部分重复

### 2. 模进（Sequence）
旋律型在不同音高上重复

### 3. 扩充（Extension）
延长某些部分

### 4. 收缩（Contraction）
压缩某些部分

### 5. 插入（Insertion）
在原有结构中插入新材料

## 不对称结构

### 5小节乐句
- 4+1（扩充）
- 3+2（不规则划分）

### 3小节乐句
- 常见于现代流行音乐
- 打破常规

### 7小节乐句
- 4+3或3+4
- 不对称美感

## 不同音乐风格的乐句乐段

### 古典音乐
- 严格的4小节乐句
- 对称结构
- 明确的终止式

### 流行音乐
- **主歌（Verse）**：通常8小节为一个单位
- **副歌（Chorus）**：8或16小节
- 可能有不对称结构

### 民歌
- 简单的乐段结构
- 常见：上下句（2个乐句）
- 对称平衡

### 爵士音乐
- 标准：32小节（AABA结构）
- 每个A或B段通常8小节
- 即兴时可打破规律

## 乐句乐段的分析方法

### 步骤
1. **确定乐句边界**：找休止、呼吸点、终止式
2. **标记乐句关系**：a, a', b, c...
3. **分析终止式**：半终止、完全终止等
4. **确定乐段类型**：平行、对比等
5. **观察扩展手法**：重复、模进等

### 标记方法
```
乐句1（a）：4小节，半终止（HC）
乐句2（a'）：4小节，完全终止（PAC）
乐段类型：平行乐段
```

## 创作中的应用

### 1. 平衡与对比
- 平行提供统一
- 对比提供变化

### 2. 问答结构
- 第一句：提问（半终止）
- 第二句：回答（完全终止）

### 3. 层次规划
- 动机 → 乐句 → 乐段 → 段落 → 全曲
- 各层次清晰

### 4. 情感表达
- 不同乐句承载不同情感
- 通过乐句关系表达情感发展

## 乐句乐段的实践

### 听辨练习
1. 听音乐，找出乐句边界
2. 判断乐句关系（平行/对比）
3. 识别终止式类型

### 创作练习
1. 创作4小节乐句
2. 创作平行乐段（a + a'）
3. 创作对比乐段（a + b）
4. 尝试不对称结构

### 分析练习
分析经典作品的乐句乐段结构

## 经典例子

### 古典
- 莫扎特《小星星变奏曲》：典型的平行乐段
- 贝多芬《欢乐颂》：清晰的4小节乐句

### 流行
- 《Yesterday》（Beatles）：8小节为单位
- 大多数流行歌：主歌8小节，副歌8或16小节
