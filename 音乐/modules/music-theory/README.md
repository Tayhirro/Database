# 乐理（Music Theory）知识体系

本目录系统化地组织音乐理论相关知识，从基础概念到进阶应用。

## 目录结构

### 01-basics - 基础乐理
音乐理论的基础概念，是学习所有音乐知识的基石。
- [音程](01-basics/音程.md) - 两个音之间的距离关系
- [音阶](01-basics/音阶.md) - 音的排列规律
- [调式](01-basics/调式.md) - 音阶的组织方式
- [调性](01-basics/调性.md) - 音乐的调式中心
- [记谱法](01-basics/记谱法.md) - 音乐的书写系统

### 02-harmony - 和声理论
多个音同时发声的组织规律。
- [三和弦](02-harmony/三和弦.md) - 基础和弦结构
- [七和弦](02-harmony/七和弦.md) - 扩展和弦结构
- [和弦进行](02-harmony/和弦进行.md) - 和弦的连接规律
- [原位三和弦的连接](02-harmony/原位三和弦的连接.md) - 四部写作的基础声部进行
- [和声功能](02-harmony/和声功能.md) - 和弦在调性中的作用
- [转调](02-harmony/转调.md) - 调性的转换技巧

### 03-rhythm - 节奏理论
音乐时间维度的组织规律。
- [拍号](03-rhythm/拍号.md) - 节拍的记谱方式
- [节奏型](03-rhythm/节奏型.md) - 常见节奏模式
- [切分音](03-rhythm/切分音.md) - 节奏的重音变化
- [复节奏](03-rhythm/复节奏.md) - 复杂节奏结构

### 04-melody - 旋律理论
单声部音乐线条的构建原则。
- [音域](04-melody/音域.md) - 旋律的音高范围
- [旋律线条](04-melody/旋律线条.md) - 旋律的走向特征
- [动机发展](04-melody/动机发展.md) - 旋律素材的变化手法
- [对位法](04-melody/对位法.md) - 多声部旋律的结合技术

### 05-form - 曲式分析
音乐作品的结构组织方式。
- [乐句乐段](05-form/乐句乐段.md) - 音乐的基本结构单位
- [二部曲式](05-form/二部曲式.md) - AB结构
- [三部曲式](05-form/三部曲式.md) - ABA结构
- [回旋曲式](05-form/回旋曲式.md) - 主题反复出现的结构
- [奏鸣曲式](05-form/奏鸣曲式.md) - 复杂的大型曲式

### 06-advanced - 进阶理论
现代音乐理论及专业应用。
- [现代和声](06-advanced/现代和声.md) - 20世纪后的和声语言
- [调式互换](06-advanced/调式互换.md) - 大小调互换技巧
- [爵士和声](06-advanced/爵士和声.md) - 爵士音乐和声体系
- [配器法](06-advanced/配器法.md) - 乐器组合与编写

## 学习路径建议

1. **入门阶段**：从 01-basics 开始，掌握音程、音阶、调式等基础概念
2. **进阶阶段**：学习 02-harmony 和 03-rhythm，理解和声与节奏
3. **应用阶段**：结合 04-melody 和 05-form，分析和创作音乐
4. **专业阶段**：深入 06-advanced，探索现代音乐理论
