# 拍号（Time Signature）

## 定义
拍号是记谱法中标明每小节拍数和单位拍时值的记号，通常写成分数形式。

## 拍号的构成

### 分子（上方数字）
表示每小节有几拍

### 分母（下方数字）
表示以几分音符为一拍
- 2 = 二分音符
- 4 = 四分音符
- 8 = 八分音符
- 16 = 十六分音符

## 常见拍号

### 1. 4/4拍
- 每小节4拍，四分音符为一拍
- 最常用的拍号
- 也称"common time"（C）
- 特点：稳定、均衡
- 常见于：流行、摇滚、古典等各类音乐

### 2. 3/4拍
- 每小节3拍，四分音符为一拍
- 华尔兹节奏
- 强-弱-弱
- 常见于：舞曲、民歌

### 3. 2/4拍
- 每小节2拍，四分音符为一拍
- 进行曲节奏
- 强-弱
- 常见于：进行曲、波尔卡

### 4. 6/8拍
- 每小节6拍，八分音符为一拍
- 复拍子，强-弱-弱-次强-弱-弱
- 实际感觉常为2拍（以附点四分音符为单位）
- 常见于：民谣、巴洛克音乐

### 5. 5/4拍
- 不规则拍号
- 可分为2+3或3+2
- 特点：不对称、现代感
- 例：《Take Five》

### 6. 7/4拍或7/8拍
- 不规则拍号
- 可分为2+2+3、3+2+2等
- 常见于：爵士、前卫摇滚、东欧民间音乐

### 7. 12/8拍
- 复合拍子
- 感觉为4拍，每拍3个八分音符
- 慢速布鲁斯常用

## 拍号的分类

拍号首先描述的是小节内部的拍数、单位拍和重音组织。复节奏、多重拍子、交叉节奏等也和节拍感有关，但不等同于“拍号类型”。

### 按单位拍的细分方式

- **单拍子（Simple Meter）**：每个主拍通常二等分，如 2/4、3/4、4/4
- **复拍子（Compound Meter）**：每个主拍通常三等分，单位拍常是附点音符，如 6/8、9/8、12/8

注意单位拍：6/8 虽然写作 6 个八分音符，但实际常感觉为 2 个附点四分音符的主拍。

### 按每小节主拍数

- **二拍子**：2/2、2/4、6/8（复二拍子）
- **三拍子**：3/4、9/8（复三拍子）
- **四拍子**：4/4、12/8（复四拍子）
- **混合拍子 / 不规则拍子**：5/8、7/8、11/8、15/8 等，常由 2 拍组和 3 拍组组合而成，具体分组看音乐语境

## 特殊拍号与记谱

### 附加拍号（Additive Meter）

用加法明确标记拍子的分组方式，强调每个分组的第一拍。它通常用于不规则拍子或混合拍子。

#### 记谱方式
- **3+2+3/8**：8个八分音符，分为 3+2+3 的强弱组
- **2+2+3/8**：7个八分音符，分为 2+2+3 的强弱组
- **2+3+2/8**：7个八分音符，分为 2+3+2 的强弱组

#### 强弱规律
```
3+2+3/8: 强-弱-弱 | 强-弱 | 强-弱-弱
2+2+3/8: 强-弱 | 强-弱 | 强-弱-弱
```

---

### 无理拍号（Irrational Meter）

分母不是 2 的幂（1, 2, 4, 8, 16...）的拍号。

### 组合拍号（Composite Meter）

把多个拍号并列或相加标出，用来说明一个更长周期内的拍号组合。

- **3/4 + 2/4**：一个周期中先有 3 拍，再有 2 拍
- **2/4 + 3/8**：不同单位拍的拍号被组合在同一个周期中

## 拍号的变化

### 变拍（Meter Change）

在乐曲中改变拍号。

- 例：从 4/4 转到 3/4
- 作用：制造段落变化、重音变化或结构转折

### 变换拍子（Changing Meter）

乐曲中拍号频繁切换，通常每小节或每几小节就换一次。

- 拍号不断变化，无法用单一拍号概括
- 常见写法：4/4 -> 3/4 -> 5/8 -> 2/4
- 效果：制造不规则、推进感或不可预测的节奏感

#### 与不规则拍号的区别

```
不规则拍号：同一个不规则拍号持续使用，如 7/8
变换拍子：拍号连续切换，如 4/4 -> 3/4 -> 5/8 -> 2/4
```

#### 经典作品

- Stravinsky《春之祭》（Sacrificial Dance 段落）
- Mussorgsky《图画展览会》之"漫步"
- Bartók 弦乐四重奏

### 交替拍号（Alternating Meter）

规律性地在两个或多个拍号之间交替。

- 例：4/4 和 3/4 交替
- 和变换拍子的区别：交替拍号通常有可预测的循环规律

## 与拍号相关但不等同于拍号的节奏现象

### 多重拍子（Polymeter）

不同声部同时使用不同拍号，通常共享同一个速度或基本脉冲。

```
声部A：4/4 拍
声部B：3/4 拍
结果：两个声部的强拍周期性错位
```

重点：Polymeter 的核心是“小节周期不同”，不是单纯的节奏比例不同。

### 复节奏 / 多节奏（Polyrhythm）

在同一个拍框架或同一时间长度内，不同声部使用不同的节奏划分。
- bpm不同 
```
三连音 对 二连音（3:2）
四连音 对 三连音（4:3）
```

重点：Polyrhythm 的核心是“同一时间内的节奏划分不同”。详见 [[复节奏]]。

### 交叉节奏（Cross-rhythm）

一个节奏型故意和主拍重音发生冲突，使听感上像在挑战原本的拍子。

- 常见于非洲鼓乐、爵士、拉丁音乐、前卫摇滚
- 可以被视为复节奏的一种表现，但重点更偏向“重音与主拍的冲突”

### 节拍调制（Metric Modulation）

通过把旧速度中的某个音值重新解释为新速度的单位拍，实现精确的速度或拍感转换。

```
旧速度中的三连音四分音符 = 新速度中的四分音符
```

重点：Metric Modulation 是速度和拍感的转换方法，不是某一种拍号。

### 散拍子（Free Time / Senza Misura）

没有固定拍号或固定小节结构，节奏处理较自由。

#### 特点
- 无小节线，或小节线仅作参考
- 演奏者自由处理节奏
- 常见于华彩段落（Cadenza）

#### 记谱方式
- 不写拍号
- 或写 "FREE" / "自由地" / "senza misura"
- 有时写 4/4 但标注 "free time"

#### 应用
- 华彩乐段（Cadenza）
- 散板（中国传统音乐）
- 抒情慢板的自由段落
- Erik Satie 的部分作品
- Charles Ives《Concord Sonata》

## 不同拍号的应用

### 4/4拍
- 流行歌曲：绝大多数
- 摇滚乐：标准节奏
- 古典交响乐：常用

### 3/4拍
- 华尔兹舞曲
- 许多民歌
- 抒情歌曲

### 6/8拍
- 巴洛克音乐
- 摇篮曲
- 某些民谣

### 5/4或7/8拍
- 爵士乐实验
- 前卫摇滚
- 电影配乐

## 拍号与情绪

- **2/4**：轻快、进行
- **3/4**：优雅、流动
- **4/4**：稳定、通用
- **6/8**：摇摆、柔和
- **5/4、7/8**：不安、现代、异域

## 实践建议

1. 使用节拍器练习不同拍号
2. 拍手打出强弱规律
3. 分析喜欢的音乐的拍号
4. 尝试创作不同拍号的旋律
5. 练习视奏不同拍号的乐谱
