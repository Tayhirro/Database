# 赋格与复调曲式（Fugue and Polyphonic Forms）

## 概述
复调曲式以**多条旋律线同时进行**为组织原则（区别于主调曲式的"旋律+伴奏"）。赋格是其中最严谨、最重要的形式，巴洛克时期达到顶峰（巴赫为集大成者）。

## 赋格（Fugue）

### 核心材料
| 术语 | 说明 |
|---|---|
| **主题（Subject）** | 赋格的核心旋律，最先在某一声部出现 |
| **答题（Answer）** | 主题在其他声部的"应答"，通常在**属调**（五度上），有守调答题/完全答题之分 |
| **对题（Countersubject）** | 与答题同时出现的对应旋律 |
| **小结尾（Codetta）** | 答题与主题之间的连接片段 |

### 结构

```
呈示部 → 间插段 → 中间部 → 间插段 → 再现部 →（尾声）
```

1. **呈示部（Exposition）**：主题在各声部**依次进入**（主-属-主-属…），声部数 = 主题出现次数（三声部赋格主题出现 3 次）
2. **间插段（Episode）**：由主题/对题材料片段发展而来，起转调与过渡作用
3. **中间部**：主题在新调上多次出现（属调、关系调、下属调…），可变形（扩大/缩小/倒影/逆行）
4. **再现部（Final Section）**：主题回主调，最后常以主音持续音（踏板音）加强结束
5. **紧接段（Stretto / 密接和应）**：主题在各声部**密集重叠**进入，制造高潮——常用在再现部前

### 赋格常见变体
- **二重赋格（Double Fugue）**：两个主题，分别呈示后结合
- **三重赋格**：三个主题
- **赋格段（Fugato）**：只出现呈示部规模的赋格段落（嵌在奏鸣曲式等大型曲式内）

### 著名赋格作品
- 巴赫《平均律钢琴曲集》BWV 846-893（48 首前奏曲与赋格——"钢琴家的旧约"）
- 巴赫《赋格的艺术》BWV 1080（未完成的赋格绝唱）
- 巴赫《d 小调托卡塔与赋格》BWV 565（管风琴）
- 贝多芬《第九交响曲》末乐章（"欢乐颂"含赋格段）

## 卡农（Canon）

- 一个声部奏出旋律后，其他声部**严格模仿**进入（轮唱即最简卡农）
- 按模仿方式：同度卡农、八度卡农、逆行卡农、扩大卡农、无限卡农（循环卡农）
- **例子**：帕赫贝尔《D 大调卡农》、巴赫《戈德堡变奏曲》第 3/6/9 变奏（各音程卡农）、周杰伦《千里之外》间奏（卡农进行）

## 创意曲（Invention）

- 巴赫专为教学创作：二声部创意曲 15 首（BWV 772-786）+ 三声部创意曲 15 首（BWV 787-801）
- 规模小于赋格，主题+展开+再现的浓缩结构
- 是学习复调写作的标准教材

## 帕萨卡利亚与恰空（Passacaglia / Chaconne）

- 见 [[变奏曲式]]：固定低音（或固定和声）反复 + 上声部变奏
- 与赋格常结合使用

## 复调曲式与主调曲式的对位关系

- 主调曲式中常**插入复调段**（如奏鸣曲发展部、交响曲中的赋格段）增加层次与紧张度
- 流行音乐中：卡农进行（I-V-vi-III-IV-I-IV-V）、轮唱式副歌都是复调思维的简化应用

## 分析要点

1. 找**主题**首次进入的声部与调性
2. 数呈示部主题出现次数 = 声部数
3. 标记答题调性（属调）、对题材料
4. 找间插段（新材料发展、转调段）
5. 观察主题变形（扩大/缩小/倒影/逆行/紧接段）
