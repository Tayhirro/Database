# 二部曲式（Binary Form）

## 定义
二部曲式是由两个结构相当、同等重要的部分（A和B）组成的音乐结构，是最基本的曲式之一。巴洛克时期器乐（尤其组曲舞曲）最常用，两段通常各自反复（AA | BB）。

## 基本结构

```
A  -  B
```

- **A部**：呈示第一主题
- **B部**：对比或发展A部材料

## 核心分类（中国教材标准术语）

### 1. 并列单二部曲式（A ‖ B）

> 用户常说的"并列二部曲式"即此。

**特点**：
- A、B 两段并列，**B 段结束处不出现 A 段材料的回归**
- 两段均为完整的乐段（乐段级）
- 记为：`A ‖ B`

**结构**：
```
A（呈示）   B（对比/发展）
```

**终止特征**：
- A 部常结束于半终止（属和弦）或转调终止（大调→属调、小调→关系大调）
- B 部回到主调，完全终止结束

**例子**：
- 大量巴洛克组曲舞曲：阿勒芒德、库朗特、萨拉邦德、吉格（两段各自反复）
- 巴赫《法国组曲》中的多数舞曲
- 舒伯特《摇篮曲》（并列单二部）

### 2. 再现单二部曲式（A B A'）

**特点**：
- B 段（或其后）**再现 A 段的开始材料**（常为 A 的前半句）
- 再现一般较短，随后以终止式结束——**注意：不是完整的第三段**
- 记为：`A B(A)` 或 `A BA'`

**结构**：
```
A      B + a'（B 段末尾引用 A 开头材料）
```

**与单三部曲式（ABA）的关键区别**（易混淆点）：
| | 再现单二部 | 单三部曲式 |
|---|---|---|
| 再现的规模 | A 的材料**短暂出现**（常只前半句） | A 是**完整的一个乐段** |
| 再现的位置 | 嵌在 B 段末尾 | 独立的第三部分 |
| 结构写法 | A \| B a' | A \| B \| A |
| 和声意义 | 奏鸣曲式再现部的滥觞 | A 段仅"反复"之意 |

**例子**：
- 《噢！苏珊娜》（Oh! Susanna）——回旋式二段体的经典例
- 许多巴洛克加沃特舞曲

## 国际术语对照（分析英文文献时用）

按 **A 段是否回归主调**（段落式/连续式）× **B 段与 A 段的关系**（简易/回旋/平衡）分类：

| 类型 | 结构 | 说明 |
|---|---|---|
| 简易、段落式 | A（和声解决）B | A 段结束回归主调 |
| 回旋、段落式 | A（和声解决）B A' | 即"再现单二部" |
| 简易、连续式 | A（和声未解决）B | A 段停在属调/关系调，直接连入 B |
| 回旋、连续式 | A（和声未解决）B A' | 连续式 + 末尾再现 |
| 平衡、连续式 | A（和声未解决）B（终句取材自A） | B 结尾"引用"A 的材料收束（斯卡拉蒂键盘奏鸣曲多见） |

- **连续式**：A 段不回归主调（大调作品 A 通常导向属调，小调作品常导向关系大调 III 级）
- **段落式**：A 段先行解决和声、回归主调，才进入 B 段
- **对称式**（较少见）：A、B 长度完全相同

## 复二部曲式（Compound Binary）

- 由**两个单二部曲式**组成，或由单二部 + 单三部等结构组成
- 各部分本身是完整曲式（乐段以上规模）
- 规模较大，常见于较大型器乐作品

## 二部曲式的规模

### 小型二部曲式
- 总长度：8-16 小节（A 4 小节 + B 4 小节）
- 常见于：儿歌、简单器乐曲

### 中型二部曲式
- 总长度：16-32 小节（每部 8 小节，常为 2 个乐句）
- 常见于：舞曲、艺术歌曲

### 大型二部曲式
- 总长度：32 小节以上，每部分可能含多个乐段

## 调性布局

### 大调作品
- A 部：I → V（或停在 I 的半终止/完全终止）
- B 部：V → I

### 小调作品
- A 部：i → III（关系大调）
- B 部：III → i

### 对称布局
- A 部：主调 → 新调；B 部：新调 → 主调（"出去再回来"）

## 不同时期的二部曲式

- **巴洛克**：组曲舞曲几乎全为二部曲式，两段各有反复记号；A 段和声不回归（连续式）渐成常态
- **古典**：小型器乐曲、艺术歌曲；再现单二部为奏鸣曲式铺路
- **现代/流行**：Verse + Chorus 可视为广义二部组织

## 著名例子

### 巴洛克
- 巴赫《法国组曲》《英国组曲》中的舞曲（阿勒芒德/库朗特/萨拉邦德/吉格）
- 巴赫《d 小调法国组曲》BWV 812 萨拉邦德（连续式：A 段 8 小节，B 段 16 小节）
- 斯卡拉蒂键盘奏鸣曲（平衡式二部曲式的大师）
- 亨德尔《水上音乐》某些段落
- 韩德尔《赫丘力士》咏叹调（段落式到连续式的过渡例）

### 古典
- 《噢！苏珊娜》（再现单二部/回旋式）
- 莫扎特、海顿小步舞曲中的主题段落

## 分析二部曲式的步骤

1. **确定分界点**：找到 A、B 部的分界（调性终止 + 材料变化）
2. **判断 A 段终止**：半终止（连续式倾向）/ 完全终止回主调（段落式倾向）
3. **检查 B 段结尾**：有无 A 材料回归 → 并列 or 再现
4. **调性分析**：标记各部分调性走向
5. **判断类型**：并列单二部 / 再现单二部 / 复二部

## 创作技巧

1. **明确对比**：A、B 两段在材料或调性上要有差异
2. **统一性**：即使对比，也要有共同的动机/节奏语言
3. **调性规划**：A 部可转调，B 部回主调
4. **平衡**：两段长度不必相等但要平衡
5. **终止设计**：A 部引向 B 部，B 部明确结束

## 练习建议

- 听辨：听巴洛克舞曲，标出 A/B 分界，判断并列 or 再现
- 分析：巴赫《法国组曲》舞曲、斯卡拉蒂奏鸣曲、《噢！苏珊娜》
- 创作：先写 8 小节并列单二部（A 停属和弦），再改造成再现单二部（B 末尾回 A 前半句），体会两者差异
