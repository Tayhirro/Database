# 组曲与套曲曲式（Suite and Cycle Forms）

## 概述
单个曲式（二部、三部、回旋、奏鸣……）组织的是**一个乐章内部**的结构；**组曲/套曲**则把多个完整乐章组合成更大的作品——可以看作"曲式学的地图之上还有地图"。

## 巴洛克组曲（Baroque Suite）

以**舞曲**为单元，按固定顺序排列（各曲均为二部曲式、同一调性、速度对比）：

```
阿勒芒德（Allemande，4/4 中速）
库朗特（Courante，三拍快舞曲）
萨拉邦德（Sarabande，慢速三拍庄重）
（可插入小步舞曲/加沃特/布雷/帕萨卡利亚等）
吉格（Gigue，快速复调舞曲）
```

**著名例子**：
- 巴赫《法国组曲》BWV 812-817
- 巴赫《英国组曲》BWV 806-811
- 巴赫《帕蒂塔》BWV 825-830（德国组曲）
- 巴赫《无伴奏大提琴组曲》BWV 1007-1012
- 亨德尔《水上音乐》《皇家焰火音乐》

## 古典奏鸣套曲（Classical Sonata Cycle）

多乐章器乐作品的乐章组织逻辑（奏鸣曲、交响曲、协奏曲、重奏）：

| 乐章 | 速度/性格 | 常用曲式 |
|---|---|---|
| 第一乐章 | 快板（Allegro） | 奏鸣曲式 |
| 第二乐章 | 慢板（慢/如歌） | 三部曲式、变奏曲式、无展开部奏鸣曲式 |
| 第三乐章 | 小步舞曲/谐谑曲 | 复三部曲式 |
| 第四乐章 | 急板（Presto） | 回旋曲式、回旋奏鸣曲式、奏鸣曲式 |

- **三乐章**：快-慢-快（协奏曲、古典奏鸣曲常见，省略小步舞曲乐章）
- **四乐章**：快-慢-（小步舞曲/谐谑曲）-快（交响曲、弦乐四重奏典型）

**著名例子**：
- 贝多芬《第五交响曲"命运"》（四乐章）
- 莫扎特《第 40 交响曲》（四乐章）
- 贝多芬《第五钢琴协奏曲"皇帝"》（三乐章）

## 声乐套曲（Song Cycle）

一组艺术歌曲围绕同一主题/诗篇，有统一构思：

- 舒伯特《冬之旅》《美丽的磨坊女》
- 舒曼《诗人之恋》《妇女的爱情与生活》
- 中国：洗星海《黄河大合唱》、大型声乐套曲《长征组歌》

## 交响诗/音诗（Symphonic Poem）

- 单乐章"标题音乐"套曲化结构：自由曲式/奏鸣曲式/变奏结构皆可
- 李斯特首创：13 首交响诗（如《前奏曲》《塔索》）
- 理查·施特劳斯《查拉图斯特拉如是说》《唐璜》

## 分析要点

1. 先看**乐章数**与速度布局（快-慢-快？）
2. 每个乐章**内部**再分析曲式
3. 关注乐章间的**调性关系**（同调性/关系调/同名调）
4. 组曲：关注舞曲种类与速度对比；套曲：关注主题贯穿（如"固定乐思"）
