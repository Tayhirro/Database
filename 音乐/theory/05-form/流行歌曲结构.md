# 流行歌曲结构

## 1. 一句话
- "歌曲"通常指可唱的短结构作品，常见模块是：主歌（Verse）/副歌（Chorus）/桥段（Bridge）/前副歌（Pre-chorus）。
- 两套曲式体系：**AABA（老标准曲/爵士，32 小节）** 与 **Verse-Chorus（现代流行）**。

## 2. 段落模块词典

| 模块 | 英文 | 功能 |
| --- | --- | --- |
| 前奏 | Intro | 建立氛围，预告主题 |
| 主歌 | Verse | 陈述细节/叙事，旋律相对平稳，每段歌词不同 |
| 前副歌 | Pre-Chorus | 桥接主歌与副歌，逐句推进张力（"爬坡段"） |
| 副歌 | Chorus | 全曲记忆点，旋律上口、歌词重复，张力最强 |
| 桥段 | Bridge | 与前后形成对比的"第三材料"，通常只出现一次 |
| 尾奏 | Outro | 收尾，常引用副歌或主歌材料 |

## 3. 常见结构

- `Verse -> Chorus`（循环）
- `Verse -> Pre -> Chorus`
- `Verse -> Chorus -> Verse -> Chorus -> Bridge -> Chorus`（现代流行最常用）

## 4. AABA（32 小节标准曲式）

```
A（8小节） A（8小节） B（8小节） A（8小节）
 主题×2     主题再现    桥段对比    主题回归
```

- 1920-1950 标准曲/爵士标准的"主菜"结构：**A 段即副歌（记忆点），先出现两遍**巩固主题
- B 段 = Bridge（桥段），8 小节，对比材料，通常只出现一次
- 大调 AABA 的 B 段常转属调/离调，小调 AABA 的 B 段常转关系大调
- 例：《Over the Rainbow》《Yesterday》（披头士）、《月亮代表我的心》等大量标准曲
- ⚠️ 注意：AABA 里的 A ≠ 现代流行里的"主歌"——AABA 的 A 是主菜（≈副歌），"主歌"在那个时代是 AABA 之前的自由引子（verse），演出常省略

## 5. 两套体系的对照

| | AABA 标准曲式 | Verse-Chorus 流行曲式 |
| --- | --- | --- |
| 主体段 | A（主菜/≈副歌）先出现两次 | 主歌在前、副歌在后交替 |
| 桥段 | B（8 小节，一次） | Bridge（通常一次，靠后） |
| 总长 | 固定 32 小节 | 不固定 |
| 时代 | 1920-1950 爵士标准 | 1960s 以后摇滚/流行 |
| 逻辑 | 起-承-转-合 | 陈述-对比-回归（副歌回归） |

## 6. 段落间的"能量"设计（编曲视角）

- 典型能量曲线：Intro（低）→ Verse（低-中）→ Pre-Chorus（爬升）→ **Chorus（峰值）** → Verse（回落）→ … → Bridge（新对比）→ Chorus（最高峰值）→ Outro（回落）
- 副歌回归的"宏观 ABA"逻辑：出去转一圈，回到原点才完整（见 [[三部曲式]]）
- 实操：同一副歌唱三遍，每次配器递增（加鼓、加和声、加高音区），就是"再现部的变化再现"
