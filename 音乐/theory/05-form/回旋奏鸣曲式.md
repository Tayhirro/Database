# 回旋奏鸣曲式与奏鸣回旋曲式（Rondo-Sonata Form）

## 定义
**回旋奏鸣曲式** = **回旋原则**（主部 A 反复回归）+ **奏鸣原则**（呈示部中主部-副部的调性对比、再现部调性统一）结合而成的曲式。

- 古典时期**奏鸣曲、交响曲、协奏曲的末乐章**最常见
- 兼有回旋的"活泼回归"与奏鸣的"逻辑发展"

## 典型结构

| 呈示部 | 展开部 | 再现部 |
| --- | --- | --- |
| A 主部 | B 副部 | A 主部 | C 展开部/插部 | A 主部 | B' 副部 | A 主部 |
| 主调 | 从属调 | 主调 | 调性动乱 | 主调 | 主调（调性附和） | 主调 |

- 主部 A 在典型结构中**共出现 4 次**（首尾呼应 + 中段两次）
- 副部 B：呈示部在从属调（大调作品通常在属调），**再现部回到主调**——奏鸣原则的核心标志
- C：展开部或插部，调性游移、材料发展

## 变体家族（易混淆辨析）

### 1. 典型回旋奏鸣曲式：`A B A | C | A B A`（主部 4 次）

主部第一次出现**不可省略**（必须在副部之前确立主题）。

### 2. 奏鸣回旋曲式：`A B | C | A B A`（省略呈示部第二次主部）

- 呈示部只剩 A B（主部-副部），**奏鸣特征先出现**；到再现部才见回旋回归
- 故名"奏鸣-回旋"（奏鸣特征在前）

### 3. 回旋奏鸣曲式的其他省略变体

| 省略位置 | 结构 | 特征 |
| --- | --- | --- |
| 省略第三次主部 | A B A \| C \| B A | 再现部从副部开始 |
| 省略第四次主部 | A B A \| C \| A B | 再现部以副部收束 |

## 与纯回旋曲式的区别

| | 回旋曲式 | 回旋奏鸣曲式 |
|---|---|---|
| 副部调性 | 插部可自由转调 | **呈示部副部在从属调，再现部回主调**（奏鸣原则） |
| 结构 | A B A C A…（插部全为新材料） | 三段部性：呈示-展开-再现 |
| 结尾 | 主部收束 | 可带尾声（Coda） |

## 与奏鸣曲式的区别

| | 奏鸣曲式 | 回旋奏鸣曲式 |
|---|---|---|
| 呈示部 | A B（主部-副部） | **A B A**（主部回归一次） |
| 展开部 | 发展部（材料发展） | 展开部或独立插部 C |
| 整体 | 主部共 2 次 | 主部共 3-4 次 |

## 著名例子

| 作品 | 说明 |
|---|---|
| 贝多芬《"悲怆"奏鸣曲》第三乐章 | 教科书标准例（回旋奏鸣曲式） |
| 贝多芬《"华德斯坦"奏鸣曲》第三乐章 | 回旋奏鸣曲式 |
| 莫扎特《G 大调钢琴协奏曲》K.453 第三乐章 | 回旋奏鸣曲式（协奏曲终乐章典型） |
| 海顿《第 104 交响曲"伦敦"》末乐章 | 回旋奏鸣曲式 |
| 莫扎特《土耳其进行曲》K.331/3 | 纯回旋曲式（对照用，非回旋奏鸣） |

## 分析要点

1. 确认主部 A 出现**几次**（3 或 4）→ 判断典型还是省略变体
2. 找副部 B 的调性：呈示部从属调、再现部回主调 → 奏鸣原则的标志
3. 看中间部分：是材料发展（展开部）还是独立新段落（插部）→ 偏奏鸣 or 偏回旋
4. 主部出现顺序：`A B A C A B A` 典型回旋奏鸣；`A B C A B A` 奏鸣回旋
