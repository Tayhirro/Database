# 变奏曲式（Variation Form）

## 定义
以一个**主题**为基础，用各种手法对它进行**多次变化重复**而形成的曲式：

```
A  A1  A2  A3  A4  …（An）
主题  变奏1 变奏2 变奏3 变奏4 …（变奏n）
```

- 主题每次出现都**保留可辨认的核心**（旋律骨架/和声框架/低音），其余尽可变化
- 体现"统一中的变化"——同一个音乐形象的多面观察

## 变奏的类型

### 1. 固定低音变奏（Ostinato / Ground Bass）

- **低音保持不变**，上声部不断变化
- 源于文艺复兴/巴洛克
- 两个著名体裁：
  - **帕萨卡利亚（Passacaglia）**：固定低音主题，多在低声部反复
  - **恰空（Chaconne）**：固定和声进行反复（低音可略变）

**例子**：
- 帕赫贝尔《D 大调卡农》（固定低音 8 小节无限循环）
- 巴赫《d 小调恰空》（无伴奏小提琴 BWV 1004）
- 巴赫《哥德堡变奏曲》（部分变奏建立于固定低音）

### 2. 固定旋律变奏（Cantus Firmus Variation）

- 主题旋律（定旋律）保持不变，各声部围绕它变化
- 多见于宗教音乐、圣咏

### 3. 装饰（严格）变奏

- 主题的**旋律、和声、结构骨架基本不变**，只做装饰加花
- 节奏加密（四分变八分/十六分）、旋律加装饰音、音型化伴奏
- 变奏之间关系紧密，主题轮廓始终清晰

**例子**：
- 莫扎特《小星星变奏曲》K.265（最著名的入门例）
- 海顿、莫扎特钢琴变奏曲

### 4. 自由（性格）变奏

- 每次变奏成为一个**有独立性格的段落**（如改成进行曲、圆舞曲、赋格、抒情段）
- 主题只保留核心动机或和声框架，变化幅度大
- 浪漫时期主流

**例子**：
- 贝多芬《迪亚贝利变奏曲》Op.120（33 首性格变奏）
- 拉赫玛尼诺夫《帕格尼尼主题狂想曲》（第 18 变奏是最著名旋律）
- 柴可夫斯基《洛可可主题变奏曲》

## 常用变奏手法清单

| 手法 | 说明 |
|---|---|
| 旋律装饰 | 加花、加装饰音、音型化 |
| 节奏变化 | 加密/放宽、改节奏型（附点、切分） |
| 调式调性 | 大调↔小调（同主音转换）、移调 |
| 和声变化 | 换和声配置、加七和弦、转调 |
| 织体变化 | 主调↔复调、分解和弦↔柱式、音区移动 |
| 速度/性格 | 抒情段、舞曲化、进行曲化、赋格段 |
| 结构变化 | 紧缩、扩充、加连接与尾声 |

## 双主题变奏与变奏组曲

- **双主题变奏**：两个主题交替变奏（A B A1 B1 A2 B2…），海顿常用
- **变奏曲的尾声**：常以主题最后一次完整再现或性格化结尾收束

## 在流行/现代音乐中的对应

- 电子音乐中"一个动机反复变化"（不同的鼓组/音色/加花）
- 爵士的"主题-即兴-主题"（head-solos-head）本质是自由变奏思维
- 改编曲（Remix）——对原曲主题做装饰/性格变奏

## 分析要点

1. 先找出**主题**（结构、调性、终止）
2. 每次变奏标出：保留了什么（骨架）？改变了什么（手法）？
3. 判断变奏类型：固定低音/装饰/自由/混合
4. 观察变奏间的**布局逻辑**（渐强？对称？性格序列？）
