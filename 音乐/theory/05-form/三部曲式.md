# 三部曲式（Ternary Form / ABA Form）

三部曲式是音乐中最常见的曲式之一，由三个部分组成，基本结构为"陈述-对比-再现"（ABA），体现了"离开-回归"的美学原则。

## 基本结构

### 核心模式：ABA

**A段（呈示部）**
- 陈述主要音乐材料
- 建立调性和主题
- 通常在主调上

**B段（对比部/中段）**
- 提供对比材料
- 调性、节奏、音色等方面的变化
- 制造张力和新鲜感

**A'段（再现部）**
- 回到A段材料
- 可以是完全再现或变化再现
- 带来回归感和完整感

### 结构比例
典型比例：
- A : B : A = 8 : 8 : 8（对称式）
- A : B : A = 8 : 16 : 8（扩展中段）
- 实际应用中可灵活变化

## 三部曲式的类型

### 0. 并列单三部曲式（A B C）

**特点**：
- 三段**材料各不相同**，第三段**不重复**第一段
- 记为：`A B C`（"无再现三部曲式"）

**例子**：
- 部分民歌、分节歌式变体
- 对比性强的歌曲（三段歌词各配新旋律）

> ⚠️ 无特殊说明时，"三部曲式"默认指**带再现的单三部曲式（ABA）**。并列单三部（ABC）较少见，分析时若第三段不回归第一段材料，即为 ABC。

### 1. 单三部曲式（Simple Ternary）

每个部分由一个乐段构成。

**结构**：
```
A段（8小节）- B段（8小节）- A段（8小节）
```

**特点**：
- 规模较小
- 结构紧凑
- 常见于歌曲、小品
- 再现部可原样再现或变化再现（装饰/缩减/扩展）

**例子**：
- 舒伯特《小夜曲》
- 舒伯特《音乐瞬间》No.3
- 格里格《培尔·金特》之《晨景》（单三部）

### 2. 复三部曲式（Compound Ternary）

每个部分本身是一个完整的曲式（乐段以上的结构，如单二部、单三部）。

**结构**：
```
A部分（单二部 a-b）- B部分（单三部 c-d-c'）- A'部分（a-b 再现）
```

**特点**：
- 规模较大、结构复杂
- 常见于器乐作品：小步舞曲、谐谑曲、圆舞曲、进行曲

**中部（B）的两种类型**（重点）：
1. **三声中部（Trio）**：材料与两端形成对比、织体轻巧（原为三重奏演奏，故名 Trio），结构完整、调性相对独立——小步舞曲/谐谑曲的标配
2. **插部型中部**：材料来自 A 的动机发展或全新插部，对比更自由

**例子**：
- 贝多芬《G 大调小步舞曲》（小步舞曲-三声中部-小步舞曲）
- 贝多芬钢琴奏鸣曲的谐谑曲乐章
- 柴可夫斯基《四季·六月船歌》
- 李焕之《春节序曲》（快-慢-快复三部）

### 2.5 双三部曲式

- 单三部曲式的**变体**：`A B A B' A`（中段反复一次）
- 介于单三部与回旋曲式之间的"中间曲式"（教材称"单三部五部曲式"）

### 3. 带再现的三部曲式

### 3. 带再现的三部曲式

再现部有变化或缩减。

**变化再现**：
- 旋律装饰
- 和声改变
- 织体变化
- 调性变化

**缩减再现**：
- 省略某些段落
- 压缩材料
- 直接进入尾声

### 4. 带引子和尾声的三部曲式

**引子（Introduction）**
- 准备主题进入
- 建立氛围
- 可能预示主题材料

**尾声（Coda）**
- 巩固结束感
- 可能发展主题
- 渐弱或渐强结束

**结构**：
```
引子 - A - B - A' - 尾声
```

## 各部分的写作特点

### A段（呈示部）

**调性**：
- 通常在主调
- 可能离调但会回到主调

**主题特征**：
- 明确、完整
- 容易记忆
- 确立作品性格

**结束方式**：
- 完全终止（在主调）
- 半终止（为B段准备）

### B段（对比部）

**对比手段**：

1. **调性对比**
   - 关系大小调（C大调 → a小调）
   - 属调（C大调 → G大调）
   - 下属调（C大调 → F大调）
   - 平行调（C大调 → c小调）

2. **主题对比**
   - 全新主题
   - A段主题变形
   - A段动机发展

3. **节奏对比**
   - 节奏型变化
   - 速度变化
   - 韵律对比

4. **织体对比**
   - 主调 ↔ 复调
   - 密集 ↔ 稀疏
   - 厚重 ↔ 轻盈

5. **音色对比**
   - 配器变化
   - 力度变化
   - 演奏法变化

**连接方式**：
- 直接连接
- 过渡句连接
- 链接段落

### A'段（再现部）

**再现类型**：

1. **完全再现**
   - 与A段完全相同
   - 增强统一感
   - 常见于小型作品

2. **变化再现**
   - 旋律装饰
   - 织体变化
   - 和声丰富化
   - 力度改变

3. **紧缩再现**
   - 省略重复
   - 压缩长度
   - 保留核心材料

4. **扩展再现**
   - 延长某些部分
   - 添加新材料
   - 发展高潮

## 调性布局

### 大调作品典型调性布局

```
A段：I级（主调）
B段：V级、vi级、IV级
A'段：I级（主调）
```

### 小调作品典型调性布局

```
A段：i级（主调）
B段：III级、v级、VI级
A'段：i级（主调）
```

### 调性统一原则
- 开始和结束在同一调性
- 中段提供调性对比
- 再现部回归主调

## 经典案例分析

### 案例1：肖邦《降D大调前奏曲》（"雨滴"）

**A段（1-27小节）**
- 降D大调
- 持续音型"雨滴"
- 宁静氛围

**B段（28-75小节）**
- 转至升c小调（同主音小调）
- 戏剧性对比
- "暴风雨"般的中段

**A'段（76-89小节）**
- 回到降D大调
- 变化再现
- 平静回归

### 案例2：莫扎特《A大调钢琴奏鸣曲》K.331 第一乐章（变奏曲主题）

**A段**
- A大调
- 优雅主题
- 8小节

**B段**
- 转至E大调（属调）
- 对比材料
- 8小节

**A'段**
- 回到A大调
- 主题再现
- 8小节

### 案例3：舒曼《童年情景》之《梦幻曲》

**A段**
- F大调
- 温柔主题

**B段**
- d小调区域
- 情绪变化

**A'段**
- F大调
- 变化再现

## 与其他曲式的关系

### 三部曲式 vs 二部曲式
- **二部**：AB，对比但不回归
- **三部**：ABA，回归统一

### 三部曲式 vs 回旋曲式
- **三部**：ABA，一次回归
- **回旋**：ABACA…，多次回归

### 在大型曲式中的应用
- 奏鸣曲的慢乐章常用三部曲式
- 交响曲的谐谑曲乐章常用复三部曲式
- 协奏曲的慢乐章

## 现代应用

### 流行音乐
- Verse - Chorus - Verse 结构
- 前奏 - 主歌 - 副歌 - 主歌
- 桥段（Bridge）作为B段

### 爵士音乐
- AABA 曲式（32小节标准）
- 每个A段8小节
- B段（Bridge）8小节

### 电影音乐
- 主题 - 变化 - 回归
- 情绪的离开与回归
- 叙事结构的音乐呼应

## 创作建议

### 1. 确立清晰的A段
- 主题要有特点
- 调性明确
- 容易记忆

### 2. 设计有效的对比
- 至少在一个维度上形成对比
- 对比不宜过分夸张
- 保持整体风格统一

### 3. 安排好再现
- 决定完全还是变化再现
- 如何回归（突然/渐进）
- 是否添加尾声

### 4. 注意比例平衡
- 避免某部分过长或过短
- 保持听觉上的平衡
- 根据内容调整长度

### 5. 创造有机联系
- B段可以使用A段的动机
- 过渡段落要自然
- 整体保持连贯性
