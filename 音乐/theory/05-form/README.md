# 曲式与作品结构说明

导航：[[音乐/00-音乐索引|音乐索引]]｜[[音乐/theory/05-form/索引|曲式索引]]

这里的“结构”只指音乐材料如何在时间中组织：

- 微观：动机、乐句、乐段。
- 歌曲：Intro、Verse、Pre-Chorus、Chorus、Bridge、Outro。
- 基础曲式：二部、三部、回旋。
- 大型曲式：奏鸣曲式等。

专辑属于作品集合，现场属于演出形态，二者不再被当成曲式。
