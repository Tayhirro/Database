# 曲式索引（Form）

导航：[[音乐/00-音乐索引|音乐索引]]｜[[音乐/theory/README|理论总览]]

## 体系总览

```
乐句乐段（微观语法）
   │
   ├── 一段曲式（单曲式）
   ├── 二部曲式（并列/再现）──── 复二部曲式
   ├── 三部曲式（并列/再现）──── 复三部曲式
   ├── 变奏曲式（固定低音/装饰/自由变奏）
   ├── 回旋曲式（小型/典型/变体）
   ├── 奏鸣曲式（含无展开部变体）
   ├── 回旋奏鸣曲式（回旋×奏鸣）
   ├── 赋格与复调曲式（卡农/创意曲/帕萨卡利亚）
   ├── 组曲与套曲曲式（多乐章组织）
   └── 单曲式与自由曲式（前奏曲/托卡塔/狂想曲等）
```

## 易混淆辨析速查

| 易混对 | 关键区分 |
| --- | --- |
| 再现单二部 vs 单三部 | 再现规模：B 尾只"引"A 开头（二部）vs 完整第三段（三部） |
| 并列单二部 vs 复乐段 | 二部两段**对比材料**；复乐段两段**同主题材料** |
| 三部曲式 vs 回旋曲式 | 一次回归（ABA）vs 多次回归（ABACA…） |
| 回旋曲式 vs 回旋奏鸣曲式 | 副部调性有无"再现部回主调"的奏鸣原则 |
| 回旋奏鸣 vs 奏鸣回旋 | 主部出现 4 次（回旋奏鸣）vs 3 次（奏鸣回旋） |
| 变奏曲式 vs 回旋曲式 | 变奏：主题每次**变形**出现；回旋：主题**原样**回归 |
| 单二部 vs 单三部 | 二段不回归 vs 三段回归 |
| 一段曲式 vs 乐段 | 乐段是结构单位；一段曲式是"一个乐段就是整首作品" |
