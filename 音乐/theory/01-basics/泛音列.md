# 泛音列（Harmonic Series）

## 一句话
- 任何"一维线状"振动体（弦、空气柱）发声时，**不是只做一个振动，而是同时以所有整数倍频率的驻波模式振动**——这些多出来的频率（2f、3f、4f…）就是泛音，按频率排列就是泛音列。

## 泛音的产生（为什么是整数倍）

### 前提：两端被"钉死"
- 弦的两端固定在琴桥/琴枕上，**端点位移永远是 0（节点）**。
- 正弦波的性质：**每隔半个波长才回到 0（过零点）**。
- 所以两个固定端（两个零点）之间**只能装整数个半波**——只有整数个半波，右端点才正好落在零点上。

```
λ = 2L     → 基音（1 个半波）
λ = L      → 八度（2 个半波）
λ = 2L/3   → 五度（3 个半波）
λ = L/2    → 又八度（4 个半波）
```

- 波长与频率：f = v/λ = n·(v/2L) = **n × 基音频率** → 泛音必然是整数倍。

### 另一个角度：反射必须"对得上"
- 拨弦产生的波在两端来回反射。跑一个来回（距离 2L），若刚好是**整数个波长**（2L = nλ），反射波与原波**互相加强**，振动持续；对不上则**互相抵消**，瞬间消失。
- 所以"整数倍"不是规定，是"能持续"与"瞬间消失"的淘汰赛结果。

### 常见误区
- 不是"只能做整数个拱"，而是"两端不动"这个物理约束把其他模式全部淘汰了。
- "正一半"（λ = L）不是不行——它正好是第二次泛音（八度）。

## 泛音列（以 C 为例）

| 分音 | 频率 | 与基音比 | 音程 | 说明 |
|---|---|---|---|---|
| 第1分音 | 1f | 1:1 | 基音 | 音高本体 |
| 第2分音 | 2f | 2:1 | 八度 | 最亲（同音名） |
| 第3分音 | 3f | 3:2 | **纯五度** | 八度后第一个新音程 |
| 第4分音 | 4f | 4:3 | 纯四度 | 五度的反面（八度÷五度） |
| 第5分音 | 5f | 5:4 | 大三度 | 纯律用到的分音 |
| 第6分音 | 6f | 6:5 | 小三度 | — |
| 第7分音 | 7f | ~7:4 | （小七度，不准确） | 律制外的音 |
| 第8分音 | 8f | 8:1 | 又八度 | — |

## 泛音与协和（为什么纯五度地位高）

- 两个音同时响，若**泛音对齐**（如 C 与 G：G 的基音 = C 的第 3 分音），听感**顺滑不打架**；若泛音错位（如 C 与 ♯F 三全音），产生拍频干扰，**刺耳紧张**。
- 因此"协和度排序" = 泛音列中的排位：八度（2:1）→ 纯五度（3:2）→ 纯四度（4:3）→ 大三度（5:4）……
- 纯五度是**八度之后第一个出现的新音程**，血缘最近 → 属音（上方五度）成为调式二号人物、Ⅴ→Ⅰ 终止式最有力（见 [[音乐/theory/01-basics/调式|调式]]、[[音乐/theory/01-basics/调性|调性]]、[[音乐/theory/01-basics/音程|音程]]）。

## 泛音与音律

- **五度相生律**：只用第二、第三分音（3:2 连续相生）。
- **纯律**：在五度之外加进第五分音（5:4 纯律大三度）。
- 两种律制的差异（如 e¹ 高度不同）正是"依据的自然层级"不同：五度更原始，三度是更精细的调整。
- **五声音阶 = 五度相生的第一次落地**：从宫音连续相生四次得宫→徵→商→羽→角，按高低排成音阶即 1 2 3 5 6（见 [[音乐/theory/01-basics/音阶|音阶]]）。

## 泛音与音色（Timbre）

- 同一个基音，各泛音的**强度比例**不同 → **音色**（见 [[音乐/practice/production/音色|音色]]）。
  - 中间拨弦 → 基音强、泛音少 → 空、纯（长笛感）
  - 靠近琴桥拨弦 → 泛音多 → 亮、尖（拨片感）
- 泛音配方 = 音色配方；EQ/滤波改变频谱轮廓就是在改泛音强度比例。

## 反例：为什么鼓和钟"音高不清晰"

- **二维/三维振动体**（鼓膜、钟、锣）的驻波模式波长不是严格的 2L/n，泛音是**非整数倍**（inharmonic partials）。
- 只有"一维线状"振动（弦、空气柱）才有干净的整数倍泛音列——这也是钢琴、吉他、人声能定准音高，打击乐不能的原因。
