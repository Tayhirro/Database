# 爵士和声（Jazz Harmony）

## 定义
爵士和声是爵士音乐中特有的和声体系，以复杂的七和弦、扩展音、替代和弦和色彩性和声为特征。

## 爵士和声的基础

### 1. 七和弦为基本单位
在爵士中，三和弦很少单独使用，七和弦是最基本的和声单位。

#### 主要七和弦类型
- **大七和弦**：Cmaj7（C-E-G-B）
- **属七和弦**：C7（C-E-G-Bb）
- **小七和弦**：Cm7（C-Eb-G-Bb）
- **小大七和弦**：CmM7（C-Eb-G-B）
- **半减七和弦**：Cm7b5（C-Eb-Gb-Bb）
- **减七和弦**：Cdim7（C-Eb-Gb-Bbb/A）

### 2. 扩展音（Tensions/Extensions）
在七和弦基础上加入9、11、13音

#### 九和弦（9th Chords）
- **Cmaj9**：C-E-G-B-D
- **C9**：C-E-G-Bb-D
- **Cm9**：C-Eb-G-Bb-D

#### 十一和弦（11th Chords）
- **Cmaj11**：C-E-G-B-D-F
- **C11**：C-E-G-Bb-D-F
- **Cm11**：C-Eb-G-Bb-D-F

#### 十三和弦（13th Chords）
- **Cmaj13**：C-E-G-B-D-F-A
- **C13**：C-E-G-Bb-D-F-A
- **Cm13**：C-Eb-G-Bb-D-F-A

### 3. 变化音（Alterations）
升降扩展音，创造更复杂的和声色彩

- **C7b9**：降九音
- **C7#9**：升九音（Hendrix和弦）
- **C7#11**：升十一音（Lydian属和弦）
- **C7b13**：降十三音
- **C7alt**：多个变化音（b9, #9, b5, #5）

## 核心和声进行

### 1. II-V-I 进行
爵士和声的核心，最重要的进行

#### 大调 II-V-I
```
Dm7 - G7 - Cmaj7
(II)  (V)  (I)
```

#### 小调 II-V-I
```
Dm7b5 - G7 - Cm7
(IIø)   (V)  (i)
```

#### 扩展版本
```
Dm9 - G13 - Cmaj9
Dm11 - G7#11 - Cmaj13
```

### 2. Turnaround（回转）
回到起点的进行，常用于结尾

#### 基本型
```
Cmaj7 - Am7 - Dm7 - G7
(I)     (VI)  (II)  (V)
```

#### 变化型
```
Cmaj7 - A7 - Dm7 - G7
(使用副属和弦A7代替Am7)
```

### 3. Blues进行
12小节布鲁斯和声

#### 基础布鲁斯
```
| C7  | C7  | C7  | C7  |
| F7  | F7  | C7  | C7  |
| G7  | F7  | C7  | G7  |
```

#### 爵士布鲁斯
```
| Cmaj7 | F9   | Cmaj7 | Cm7 F7 |
| Fm7   | Bb7  | Cmaj7 | Em7 A7 |
| Dm7   | G7   | Cmaj7 A7 | Dm7 G7 |
```

## 和弦替代技巧

### 1. 三全音替代（Tritone Substitution）
用根音相距三全音的属七和弦替代

#### 原理
- G7的三全音（B-F）= Db7的三全音（F-B）
- 导音与七音互换

#### 应用
```
原进行：Dm7 - G7 - Cmaj7
替代后：Dm7 - Db7 - Cmaj7
```

#### 效果
- 半音下行的低音进行（Db→C）
- 更加色彩丰富

### 2. 副属和弦（Secondary Dominants）
把任何和弦当作临时的I级，在其前面加上它的V7

#### 例子
```
| Cmaj7 | E7  | Am7 | D7  | Dm7 | G7  | Cmaj7 |
         (V/VI)     (V/II)      (V/I)
```

- **E7**：Am的V7（副属）
- **D7**：Dm的V7（副属）

### 3. 调式互换（Modal Interchange）
从平行调借用和弦

#### 从C小调借用（在C大调中）
- **Cm7**：小主和弦
- **Fm7**：小下属
- **Abmaj7**：bVI
- **Bb7**：bVII

#### 应用
```
| Cmaj7 | Fm7 | Cmaj7 | Abmaj7 |
        (借自Cm)      (借自Cm)
```

### 4. Coltrane Changes
John Coltrane发明的复杂替代

#### Giant Steps进行
大三度循环：
```
| Bmaj7 D7 | Gmaj7 Bb7 | Ebmaj7 | Am7 D7 |
| Gmaj7 Bb7 | Ebmaj7 F#7 | Bmaj7 | Fm7 Bb7 |
```

## 调式和声（Modal Harmony）

### 调式即兴的基础
不强调功能和声，而是在某一调式上即兴

### 主要调式及和弦

#### 1. Dorian调式
```
Dm7作为主和弦
和声：Dm7 | Em7 | Dm7 | Dm7
```
特征：大六度（B自然音）

#### 2. Mixolydian调式
```
G7作为主和弦
和声：G7 | G7 | G7 | G7
```
特征：降七度

#### 3. Lydian调式
```
Cmaj7#11
和声：Cmaj7 | Cmaj7 | Cmaj7 | Cmaj7
```
特征：升四度

### Miles Davis的调式爵士
《So What》：
```
Dm7(Dorian) - 16小节
Ebm7(Dorian) - 8小节
Dm7(Dorian) - 8小节
```

## 和声节奏（Harmonic Rhythm）

### 快速和声变化
```
| Cmaj7 Dm7 | Em7 A7 | Dm7 G7 | Cmaj7 |
  每两拍换一个和弦
```

### 慢速和声
```
| Dm7 | Dm7 | G7 | G7 |
  一个和弦持续两小节
```

### Rhythm Changes
基于《I Got Rhythm》的和声进行
```
A段：
| Bbmaj7 G7 | Cm7 F7 | Dm7 G7 | Cm7 F7 |
| Fm7 Bb7 | Ebmaj7 Ab7 | Dm7 G7 | Cm7 F7 |
```

## Voicing（和弦配置）

### 1. Drop 2 Voicing
省略从上数第二个音，下降八度

### 2. Drop 3 Voicing
省略从上数第三个音，下降八度

### 3. Shell Voicing
只弹根音、三音、七音（省略五音）

### 4. Rootless Voicing
省略根音（贝斯演奏根音）

#### Bill Evans Voicing
```
Cmaj7：E-G-B-D（省略根音C）
```

### 5. Quartal Voicing
以四度叠置代替三度
```
D-G-C-F（而非三度叠置）
```

## 重配和声（Reharmonization）

### 技巧

#### 1. 加入经过和弦
```
原：| Cmaj7 | Dm7 |
新：| Cmaj7 C#dim7 | Dm7 |
```

#### 2. 使用三全音替代
```
原：| Dm7 G7 | Cmaj7 |
新：| Dm7 Db7 | Cmaj7 |
```

#### 3. 调式互换
```
原：| Cmaj7 Dm7 | Em7 A7 |
新：| Cmaj7 Dm7 | Ebm7 Ab7 |
```

#### 4. Coltrane循环
用大三度循环替代

## 爵士和声的聆听与学习

### 必听专辑
1. **Bill Evans - Portrait in Jazz**（和声配置）
2. **John Coltrane - Giant Steps**（复杂和声）
3. **Miles Davis - Kind of Blue**（调式和声）
4. **Herbie Hancock - Maiden Voyage**（现代和声）

### 学习步骤
1. **掌握II-V-I**：所有12个调
2. **学习标准曲**：学习Real Book中的经典曲目
3. **分析和声**：分析喜欢的爵士曲目
4. **即兴练习**：在和声进行上即兴
5. **重配和声**：尝试给旋律重配和声

### 练习方法

#### 1. II-V-I练习
在所有12个调上练习

#### 2. 标准曲分析
分析《Autumn Leaves》、《All the Things You Are》等

#### 3. 耳朵训练
听辨和弦质量和进行

#### 4. 即兴应用
在和弦进行上即兴solo

## 爵士和声的记谱

### 和弦记号
- **Cmaj7**或**CΔ7**：大七
- **C7**：属七
- **Cm7**或**C-7**：小七
- **Cø7**或**Cm7b5**：半减七
- **C°7**：减七
- **C7alt**：变化音属七

### Lead Sheet
只写旋律和和弦符号，演奏者自己配置voicing
