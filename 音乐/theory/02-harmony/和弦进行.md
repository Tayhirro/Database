# 和弦进行（Chord Progression）

## 1. 定义
和弦进行是指和弦在时间轴上的连接方式（sequence），它既可以用“功能逻辑”（T/PD/D/T）理解，也可以用“低音线 + 声部连接（voice leading）”解释为什么顺耳。

## 2. 一张骨架：T / PD / D / T
功能性调性音乐里最常用的骨架是：
- **T（主功能）**：I、vi、iii（稳定/确立调性）
- **PD（前属/下属功能）**：ii、IV（离开主功能、准备属功能）
- **D（属功能）**：V、vii°（紧张/需要解决）
- **骨架**：`T → PD → D → T`

常见省略与变体：
- `T → D → T`（更直接的张力-解决）
- `T → PD → T`（偏“变格”/更柔和）
- `… → D`（半终止：先制造“未完待续”）

## 3. 让进行“顺”的两件事

### 3.1 根音/低音运动（Root/Bass Motion）
常见根音走向（不是规则，更多是“概率更顺”）：
- **循环五度（下降五度/上行四度）**：最常见、最“自然”的推进（例：`vi → ii → V → I`）
- **级进（上/下行二度）**：平稳、容易写出“线条感”的低音
- **三度关系**：柔和、常用于同功能替换（例：`I ↔ vi ↔ iii`）
- **平行移动（planing）**：更偏现代/色彩化（功能会变弱，听感更“音色块”）

### 3.2 声部连接（Voice Leading）
同一套根音进行，能否“高级/顺耳”，常取决于声部连接：
- **共同音尽量保持**（尤其是内声部）
- **尽量用级进解决倾向音**：导音上行到主音；七音（属七）多下行解决
- **用转位让低音线更像旋律**（例如让低音级进，而不是一直跳进）
- **踏音（pedal point）**：低音不动，上方换和弦也会形成“推进”

## 4. 句法：终止式 + 和声节奏

### 4.1 终止式（Cadence）
把“句子结束在哪”想清楚，进行自然就会成型：
- **正格终止（Authentic）**：`V(7) → I`（最强的结束）
- **变格终止（Plagal）**：`IV → I`（更柔和，“阿门感”）
- **半终止（Half）**：`… → V`（停在属功能，带悬念）
- **阻碍/欺骗终止（Deceptive）**：大调常见 `V → vi`；小调常见 `V → VI`（把解决“躲开”）
- **终止四六（Cadential 6/4）**：`I6/4 → V → I`（I6/4多被当作属和弦的装饰/延长）

### 4.2 和声节奏（Harmonic Rhythm）
和声节奏 = 和弦变化速度（每拍/每小节/每两小节换一次等）。
- **更慢**：更稳、更“叙事/铺垫”（常见于主歌/前奏）
- **更快**：更“兴奋/推动”（常见于副歌/过渡）
- 同一套和弦循环，仅改变和声节奏与分解方式，也能听起来像“不同段落”

## 5. 常见进行速查（以 C 大调为例）

### 5.1 流行/通用循环
| 罗马数字 | C 大调和弦示例 | 常见听感/用途 |
| --- | --- | --- |
| `I–V–vi–IV` | C–G–Am–F | “轴心”循环，稳定又有起伏 |
| `vi–IV–I–V` | Am–F–C–G | 抒情/情绪推进强 |
| `I–vi–IV–V` | C–Am–F–G | 经典老派循环（“50s”） |
| `I–IV–V–I` | C–F–G–C | 民谣/摇滚/布鲁斯骨架 |

### 5.2 功能性推进（更“走向明确”）
| 罗马数字 | C 大调和弦示例 | 说明 |
| --- | --- | --- |
| `ii–V–I` | Dm7–G7–Cmaj7 | 典型 `PD→D→T` |
| `vi–ii–V–I` | Am7–Dm7–G7–Cmaj7 | “循环五度”压缩版 |
| `iii–vi–ii–V–I` | Em7–Am7–Dm7–G7–Cmaj7 | 更长的五度链（推进感更强） |

### 5.3 卡农（常见的完整八和弦循环）
- `I–V–vi–iii–IV–I–IV–V`（以 D 大调为例：D–A–Bm–F#m–G–D–G–A）

## 6. 小调常见模板（以 a 小调为例）
小调进行常会牵涉“调式来源”（自然/和声/旋律小调），但有几套非常实用的模板：
- **功能性小调骨架**：`i–iv–V–i`（例：Am–Dm–E–Am；V 常用大三和弦/属七以强化属功能）
- **小调 ii–V–i（爵士常用）**：`iiø7–V7–i`（例：Bm7b5–E7–Am）
- **自然小调循环（偏流行/民谣）**：`i–VI–III–VII`（例：Am–F–C–G）
- **安达卢西亚终止（flamenco/流行常见）**：`i–♭VII–♭VI–V`（例：Am–G–F–E）

## 7. 扩展与替代（让进行更“有故事”）

### 7.1 同功能替代（不改大方向，换质感）
- **T**：`I ↔ vi ↔ iii`
- **PD**：`IV ↔ ii`
- **D**：`V ↔ vii°`

### 7.2 副属和弦（Secondary Dominant）
把某个目标和弦临时当“主”，在它前面加它的属：
- 例（C 大调）：`D7 → G`（`V/V → V`）、`A7 → Dm`（`V/ii → ii`）

### 7.3 借用和弦 / 调式互换（Modal Interchange）
从平行大小调借用和弦以改变色彩（不一定转调）：
- 大调里常见：`iv`、`♭VII`、`♭VI`
- 小调里常见：`IV`、`♯vi°` 等（取决于你使用的“小调版本”）

### 7.4 经过和弦（Passing Chords）与装饰
“不改变目标，只增加路径”的常用办法：
- **sus**：`Vsus4 → V → I`（先悬置再解决）
- **经过减七/导和弦**：在两个目标和弦之间用半音/导向方式连接（尤其常见于爵士/古典）
- **分解/琶音/织体变化**：听感上“更丰富”，但功能骨架不一定改变

## 8. 写作与分析的实用流程
1. **先定终止点**：每个乐句要落在 `I` 还是 `V`（先确定“句号/逗号”）
2. **再写功能骨架**：用 `T/PD/D/T` 填出最短路径
3. **优化低音线**：转位/踏音/级进，让低音像旋律
4. **再加色彩**：7/9/11/13、借用和弦、副属、sus/add
5. **做变体**：省略、延长、换和声节奏、改变分解方式，避免整首歌一成不变
