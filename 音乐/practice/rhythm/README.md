## 目录结构

### 01-基础节奏型
12 种核心 groove，按难度递进。每种含网格谱 + FL 钢琴卷帘坐标。
- [01-基础节奏型.md](01-基础节奏型.md) — 从"脊椎 Beat"到"Shuffle"

### 02-进阶律动
超越基础 8/16 Beat 的律动技巧。
- [02-进阶律动.md](02-进阶律动.md) — Swing vs Shuffle、Ghost Note、力度律动、三连音滚奏、微时值偏移

### 03-风格节奏
8 大风格的鼓组配方。
- [03-风格节奏.md](03-风格节奏.md) — House / Trap / Funk / DnB / Lofi / Reggae / Jazz / Rock

---

## 学习路径建议

```
第 1 步：01-基础节奏型   → 按 #1→#12 顺序，一个节奏练稳再下一个
第 2 步：02-进阶律动     → 给基础节奏加 Swing、Ghost Note、力度变化
第 3 步：03-风格节奏     → 理解每种风格是前面技巧的"配方组合"
```
