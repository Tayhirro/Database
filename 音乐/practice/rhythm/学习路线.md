# 节奏学习路线

## 1. 一句话
- 节奏 = 声音在时间轴上的排列；核心抓手：**拍号/重音、切分、律动（groove）**。

## 2. 学习路线图（分层递进）

> **核心原则：每层只引入一个新变量，其余保持不变。对比听，不要混着学。**

```
Level 0 ─ 时间感 ─────────── 跟节拍器数拍，脚踩 1-2-3-4
  │
Level 1 ─ Backbeat ───────── Kick(1,3) + Snare(2,4) ← 流行音乐的"脊椎"
  │
Level 2 ─ Hi-Hat 密度 ────── 4分 → 8分 → 8分三连音 → 16分
  │
Level 3 ─ 律动（Groove）──── 直拍 → Swing（三连音偏移）→ Shuffle
  │
Level 4 ─ Kick 切分 ──────── 正拍 → 反拍 → 16分弱位 → Ghost notes
  │
Level 5 ─ 风格化 ─────────── House / Trap / Funk / DnB / Jazz ...
```

## 3. 最小工具箱
- 拍号：4/4、3/4、6/8、12/8
- 切分：弱拍强调、反拍、16 分弱位
- Groove：鼓组 pattern + 人类微时值（swing/shuffle）
- 力度（Velocity）：重拍 vs 弱拍的音量对比 = 律动的灵魂
