# ample-gvc-插件   -gsc  

## DI 单声道



## Doubling-guitar

- 双吉他采样



## Fret  Sound  噪音

- FR：演奏间隙触収的自然噪音 





## 空弦     *

- G#6 控制空弦  
- 大力度开，小力度关
- 所有音高为E1 A1 D2 G2 B2 and E3 空弦演奏



## 演奏模式   **

- 乐器真实演奏法限制，如两个同弦的音符不能同时发音
- 只允许演奏单音

## Capo Logic Mode 指法逻辑切换  * D

- B6
- 大力度 旋律
- 小力度  和弦



## 自动连奏模式切换    *  D

- D#6切换    
- D#6 切换自动连奏模式，大力度开启“自动滑音”，小力度为“自动击勾弦”

## FX Sound Group

| 音名 | 效果音                    |
| ---- | ------------------------- |
| F5   | 滑弦噪音（Scratch）       |
| F#5  | 拍弦（Slap）              |
| G5   | 护弦制音（Press）         |
| G#5  | 扫弦制音（Stroke Muting） |
| A5   | 下扫噪音1（Downstroke 1） |
| A#5  | 上扫噪音1（Upstroke 1）   |
| B5   | 下扫噪音2（Downstroke 2） |
| C6   | 上扫噪音2（Upstroke 2）   |
| F6   | 刮弦噪音（Pick Scrape）   |





## 吉他技巧与复音连奏（Articulations & Poly Legato）

- 点一下就行





- 标准音   （Sustain） C0  
  - E1-C#5

- 自然泛音（Natural Harmonic）    C#0 
  - E2-B4   范围最小
- 手掌闷音（Palm Mute）D0 
  - E1-C#5
  -  力度越小，压制程 度越大。同时按下C0和D0后，大力度音符为标准音，小力度音符为手掌闷音
- 无头滑音与无尾滑音（Slide In from below & Slide Out  downwards）     D#0
  - F#1-C#5 
  - D#0 在**音符前**则触収无头滑音；在**音符中**则触収无尾滑音





- 连奏滑音(复音连奏) - Legato Slide (Poly Legato)    E0

  - F1-C#5 

  - 规则不单音相同，但滑向单音时只需按下目标音中的最高音，滑向低音只需要 按下最低音。
  - **起始音和目标音的音符必须有叠加。**
  - **起始音和目标音需在同弦上.**
  - **切换键E0必须在起始音前。** 
  - **大力度E0触发的滑音会改变把位，小力度不改变。**
  - 平滑滑音（Slide Smoother）: 大于二度的滑音，目标音的力度决定滑音的速度，力度越大，速度越快。
  - 自动滑音（Auto Slide）
    -  自劢连奏模式为“自动滑音”。 
    - 起始音和目标音的音符必须有叠加。 
    - 起始音和目标音需在同弦上。 
    - 在乐器演奏模式下。





- 击勾弦  F0 
  - E1-C#5 
  - **大力度F0触发的滑音会改变把位，小力度不改变。**
  - **起始音和目标音需在同弦上.**
  - **切换键F0必须在起始音前。** 
  - **起始音和目标音的音符必须有叠加**。
