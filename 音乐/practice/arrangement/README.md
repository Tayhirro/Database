# 编曲实践

## 1. 一句话
- 编曲=把旋律/和声/节奏的“想法”变成可演奏、可制作、可呈现的结构与配器选择。

## 2. 最小工具箱
- 结构：段落（intro/verse/chorus/bridge/outro）
- 配器：谁负责旋律/和声/低音/节奏/装饰
- 密度：什么时候“加”，什么时候“留白”
