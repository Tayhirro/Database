# 音乐实践

导航：[[音乐/00-音乐索引|音乐索引]]｜[[音乐/practice/索引|实践索引]]

本目录只放“怎么做”：

- `composition/`：旋律与和声的创作抓手。
- `rhythm/`：鼓组、律动和风格节奏训练。
- `arrangement/`：段落、配器、密度与留白。
- `production/`：音色与声音塑形、FL Studio、混音和母带。

概念定义与系统理论统一放在 `theory/`，避免在这里再复制一套乐理。
