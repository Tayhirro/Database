# 音乐-乐器-钢琴

## 1. 一句话
- 钢琴能同时承担旋律、和声与低音，是“最通用的编配底座”之一。

## 2. 在作品中的常见角色
- 和声铺底（分解和弦/柱式和弦）
- 旋律伴奏与对话
- 低音支撑（左手低音线）
