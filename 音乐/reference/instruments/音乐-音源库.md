# 音乐-音源库

导航：[[音乐/00-音乐索引|音乐索引]]｜[[音乐/reference/instruments/索引|乐器与音源索引]]｜[[音乐/practice/production/音色|音色与效果器]]

## 1. 定位与边界

本页集中记录**虚拟乐器与软件音源**，按乐器家族分类，在同一页持续追加，不为每款插件单独建立笔记。

- **现实乐器页**：解释乐器本身的构造、发声原理、音域和演奏法。
- **音源条目**：记录软件名称、厂商、采样或合成方式、现实原型、演奏法、声音特点和编曲用途。
- **制作页面**：记录 EQ、压缩、失真、混响等后期处理方法，见 [[音乐/practice/production/音色|音色与效果器]]。

> [!important] 不要混淆现实原型与软件音源
> 例如 Fender Stratocaster 50 周年纪念版是现实中的电吉他；AGSC 是以它的声音为采样目标、通过 MIDI 驱动的虚拟电吉他音源。

## 3. 分类条目

### 电吉他音源

#### AGSC — Ample Guitar SC

##### 基本信息

| 字段 | 内容 |
| --- | --- |
| 简称 | AGSC |
| 全称 | Ample Guitar SC |
| 厂商 | Ample Sound |
| 类型 | 采样型虚拟电吉他音源 |
| 现实／采样原型 | Fender Stratocaster 50th Anniversary Guitar |
| 拾音位置采样 | Neck、Neck + Middle、Funk（Middle + Bridge）、Bridge |
| 主要用途 | 清音节奏、Funk 切分、流行分解、布鲁斯与摇滚旋律 |

官方对 AGSC 的定位是把 Fender Stratocaster 50 周年纪念版的声音带入制作环境。Stratocaster 类型的声音通常明亮、通透、攻击清楚；最终结果仍会受到拾音位置、演奏法、力度、放大器和箱体的共同影响。

##### 拾音位置

| 采样库 | 常见听感 | 常见用途 |
| --- | --- | --- |
| Neck（琴颈） | 较圆润、温暖，低中频更充足 | 旋律、柔和和弦、布鲁斯独奏 |
| Neck + Middle（琴颈＋中间） | 清亮、有弹性，带典型 Strat 组合拾音色彩 | 清音分解、流行伴奏、轻放克 |
| Funk（中间＋琴桥） | 明亮、短促、颗粒清楚 | Funk 切分、闷音节奏、清音扫弦 |
| Bridge（琴桥） | 高频与攻击感最突出 | Rock Riff、失真节奏、穿透型 Solo |

四组采样库代表同一类吉他的不同拾音位置，不是四种不同吉他。

##### 采样演奏法

| 演奏法 | 含义与用途 |
| --- | --- |
| Sustain | 标准持续音，用于普通旋律与和弦 |
| Palm Mute | 手掌闷音，用于紧凑节奏和 Riff |
| Natural Harmonic | 自然泛音，声音明亮、空灵 |
| Hammer On & Pull Off | 击弦与勾弦，用于同弦连奏 |
| Legato Slide | 连奏滑弦，保留两个音之间的滑动过程 |
| Slide In / Slide Out | 滑入与滑出，用于起音和收尾 |
| Pop | 较强的弹拨／爆发型起音 |
| Pinch Harmonic | 人工泛音，产生尖锐、突出的高次谐波 |
| Slide Guitar | 滑棒式连续滑音色彩 |

此外，官方资料列有复音连奏、平滑滑音、降调至 D1、左手演奏噪声、Riffer、Strummer、Guitar Pro 文件读取，以及内置放大器、箱体和基础效果器。

##### 编写与混音提醒

1. 先决定声部是节奏、铺底、Hook 还是 Solo，再选择拾音位置。
2. MIDI 要考虑弦位、把位和同弦发音限制；滑弦、击勾弦与闷音应服务于乐句。
3. 避免所有音符完全等力度、等时值和过度量化，否则容易产生机械感。
4. Strat 类型音色较亮，要留意与人声齿音、镲片和明亮合成器的中高频重叠。
5. 先把演奏写自然，再选择清音、过载或失真的放大器与效果链。

- [Ample Guitar SC Main Panel Manual（官方手册）](https://www.amplesound.net/en/Main_Panel_Manual-AGSC.pdf)

#### AGTC — Ample Guitar TC

##### 基本信息

| 字段 | 内容 |
| --- | --- |
| 简称 | AGTC |
| 全称 | Ample Guitar TC |
| 厂商 | Ample Sound |
| 类型 | 采样型虚拟电吉他音源 |
| 现实／采样原型 | Fender Telecaster（John English Masterbuilt） |
| 拾音位置采样 | Neck、Bridge |
| 主要用途 | Country、Funk、流行清音、Indie、Blues、Rock |

官方对 AGTC 的定位是把一把由 John English 制作的 Fender Masterbuilt Telecaster 声音带入制作环境。Telecaster 类型的声音以直接、清楚的起音和典型 **Twang** 感见长，比 AGSC 更容易形成干脆、靠前的节奏轮廓。

##### 拾音位置

| 采样库 | 常见听感 | 常见用途 |
| --- | --- | --- |
| Neck（琴颈） | 较温暖、圆润，仍保留清晰轮廓 | Blues 旋律、柔和伴奏、较厚的清音 |
| Bridge（琴桥） | 明亮、硬朗、起音突出，Twang 感明显 | Country 拨弦、Funk 切分、Rock 节奏与 Solo |

##### 演奏法与功能

官方列出的 10 类演奏法为 Sustain、Palm Mute、Natural Harmonic、Hammer On & Pull Off、Legato Slide、Slide In、Slide Out、Pop、Pinch Harmonic 和 Dead Note。还支持复音连奏、平滑滑音、降调至 D1 与左手演奏噪声。

##### 编写与混音提醒

- Country 或 Funk 节奏要利用时值、重音和弱拍变化表现弹性，单靠明亮预设不会自动产生风格。
- 琴桥采样的攻击感很强，与军鼓、踩镲或明亮钢琴同拍时容易互相遮挡，可先从节奏错位和音区分工解决。
- 过度失真会掩盖 Telecaster 的瞬态和 Twang；需要保留琴型特征时，优先尝试清音、轻压缩或低增益过载。

##### 资料来源

- [Ample Sound：Electric Guitar - AGTC（官方产品页）](https://www.amplesound.net/en/pro-pd.asp?id=20)
- [Ample Guitar TC Main Panel Manual（官方手册）](https://www.amplesound.net/en/Main_Panel_Manual-AGTC.pdf)

#### AGVC — Ample Guitar VC

##### 基本信息

| 字段 | 内容 |
| --- | --- |
| 简称 | AGVC |
| 全称 | Ample Guitar VC |
| 厂商 | Ample Sound |
| 类型 | 采样型虚拟电吉他音源 |
| 现实／采样原型 | Gibson SG Vintage 61 electric guitar |
| 拾音位置采样 | Neck、Bridge |
| 主要用途 | 20 世纪 70—80 年代复古摇滚、Blues Rock、Hard Rock、Riff 与 Solo |

官方将 AGVC 定位为 Gibson SG Vintage 61 电吉他音源，并明确强调 20 世纪 70—80 年代的复古 Rock'n'Roll。相较 AGSC、AGTC 的清亮单线圈取向，SG 类型声音通常更厚、更集中于中频，推动过载或失真后更容易形成有重量的 Riff 和 Solo。

##### 拾音位置

| 采样库 | 常见听感 | 常见用途 |
| --- | --- | --- |
| Neck（琴颈） | 厚实、圆润、延音感较强 | Blues Rock 旋律、复古 Solo、厚和弦 |
| Bridge（琴桥） | 更硬、更亮，失真后轮廓清楚 | Rock Riff、强力和弦、穿透型 Solo |

##### 演奏法与功能

官方列出的 10 类演奏法与 AGTC 相同：Sustain、Palm Mute、Natural Harmonic、Hammer On & Pull Off、Legato Slide、Slide In、Slide Out、Pop、Pinch Harmonic 和 Dead Note。还支持复音连奏、平滑滑音、降调至 D1 与左手演奏噪声。

##### 编写与混音提醒

- AGVC 更适合中频驱动的复古摇滚语境；使用高增益前先判断作品是否真的需要现代金属式的紧致度。
- 双轨节奏吉他应使用两遍有细微差异的演奏，而不是简单复制同一条 MIDI 后左右声像展开。
- 中频较厚时要与人声、军鼓主体和其他和声乐器分配音区，避免只用大幅度 EQ 硬挖空间。

##### 资料来源

- [Ample Sound：Electric Guitar - AGVC（官方产品页）](https://www.amplesound.net/en/pro-pd.asp?id=34)
- [Ample Guitar VC Main Panel Manual（官方手册）](https://www.amplesound.net/en/Main_Panel_Manual-AGVC.pdf)

### 原声吉他音源

#### AGM — Ample Guitar M

##### 基本信息

| 字段 | 内容 |
| --- | --- |
| 简称 | AGM |
| 全称 | Ample Guitar M |
| 厂商 | Ample Sound |
| 类型 | 采样型虚拟原声吉他音源 |
| 现实／采样原型 | Martin D-41 Acoustic Guitar |
| 演奏采样库 | Fingerstyle、Pick、Strum |
| 主要用途 | 指弹、分解和弦、扫弦、Singer-Songwriter、民谣与流行伴奏 |

官方对 AGM 的定位是把 Martin D-41 原声吉他的声音带入制作环境。它与三款电吉他音源的关键区别不是“更干净”，而是声音身份中直接包含木质琴体、空气感和可调节的原声共鸣，不需要经过电吉他放大器才能成立。

##### 演奏采样库

| 采样库 | 常见听感 | 常见用途 |
| --- | --- | --- |
| Fingerstyle | 起音较柔和，手指与琴弦细节更明显 | 指弹、分解和弦、抒情伴奏 |
| Pick | 起音清楚、颗粒更统一 | 流行分解、节奏型、需要清晰轮廓的旋律 |
| Strum | 面向完整和弦扫弦及上下扫变化 | 民谣、Singer-Songwriter、流行和摇滚原声伴奏 |

##### 演奏法与功能

官方列出的 9 类演奏法为 Sustain、Palm Mute、Natural Harmonic、Hammer On & Pull Off、Legato Slide、Slide In、Slide Out、Pop 和 Slide Guitar。还支持复音连奏、平滑滑音、降调至 D1、左手演奏噪声与可调节原声共鸣。

##### 编写与混音提醒

- 先选择 Fingerstyle、Pick 或 Strum，再编写相应声部；三者的发音逻辑不能只靠替换预设互相代替。
- 扫弦要保留上下扫方向、弦间时间差、力度梯度和和弦换把空隙，避免把钢琴柱式和弦直接照搬成吉他。
- 原声共鸣过多会占据低中频并使伴奏浑浊；先调整演奏与共鸣量，再决定是否使用 EQ。
- 与人声同场时，可通过分解节奏、开放和弦音区与留白建立关系，不必一开始就削薄琴体声音。

##### 资料来源

- [Ample Sound：Acoustic Guitar - AGM（官方产品页）](https://www.amplesound.net/en/pro-pd.asp?id=4)
- [Ample Guitar M Main Panel Manual（官方手册）](https://www.amplesound.net/en/Main_Panel_Manual-AGM.pdf)
