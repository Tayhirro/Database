# 音乐参考资料

导航：[[音乐/00-音乐索引|音乐索引]]｜[[音乐/reference/索引|参考索引]]

本目录放描述音乐对象的参考维度：

- `genres/`：风格、传统和历史谱系。
- `instruments/`：声音来源、演奏方法和常见角色。

曲式不是参考分类，统一放在 [[音乐/theory/05-form/索引|曲式索引]]。
