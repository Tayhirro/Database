# 正态分布（Normal Distribution / Gaussian Distribution）

## 定义

正态分布（又称高斯分布）是连续概率分布的一种，其概率密度函数呈钟形曲线。

若随机变量 $X$ 服从均值为 $\mu$、方差为 $\sigma^2$ 的正态分布，记为：

$$X \sim N(\mu, \sigma^2)$$

## 概率密度函数（PDF）

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

其中：
- $\mu$：均值（期望），决定分布的中心位置
- $\sigma$：标准差，决定分布的宽度/分散程度
- $\sigma^2$：方差

## 标准正态分布

当 $\mu = 0$，$\sigma = 1$ 时，称为**标准正态分布**：

$$Z \sim N(0, 1)$$

其概率密度函数简化为：

$$\phi(z) = \frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}}$$

## 基本性质

### 1. 期望与方差

| 统计量 | 公式 |
|--------|------|
| 期望 $E[X]$ | $\mu$ |
| 方差 $Var(X)$ | $\sigma^2$ |
| 标准差 $SD(X)$ | $\sigma$ |
| 中位数 | $\mu$ |
| 众数 | $\mu$ |

### 2. 对称性

关于均值 $\mu$ 对称：$f(\mu + x) = f(\mu - x)$

### 3. 累积分布函数（CDF）

$$\Phi(x) = P(X \leq x) = \int_{-\infty}^{x} \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(t-\mu)^2}{2\sigma^2}} dt$$

标准正态分布的CDF记为 $\Phi(z)$，没有闭式解，通常查表或使用数值方法计算。

## 重要性质与定理

### 1. 线性变换性质

若 $X \sim N(\mu, \sigma^2)$，则对任意常数 $a, b$（$a \neq 0$）：

$$aX + b \sim N(a\mu + b, a^2\sigma^2)$$

**证明**：

**均值**：
$$E[aX + b] = aE[X] + b = a\mu + b$$

**方差**：
$$Var(aX + b) = Var(aX) = a^2Var(X) = a^2\sigma^2$$

**特例（标准化）**：
$$Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$$

### 2. 可加性

若 $X_1 \sim N(\mu_1, \sigma_1^2)$ 和 $X_2 \sim N(\mu_2, \sigma_2^2)$ 独立，则：

$$X_1 + X_2 \sim N(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)$$

**推广**：$\sum_{i=1}^{n} X_i \sim N(\sum_{i=1}^{n}\mu_i, \sum_{i=1}^{n}\sigma_i^2)$

### 3. 中心极限定理（CLT）

设 $X_1, X_2, ..., X_n$ 是独立同分布的随机变量，$E[X_i] = \mu$，$Var(X_i) = \sigma^2 < \infty$，则：

$$\frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \xrightarrow{d} N(0, 1) \quad \text{当 } n \to \infty$$

即样本均值 $\bar{X}$ 近似服从 $N(\mu, \frac{\sigma^2}{n})$。

## 68-95-99.7 法则

对于正态分布，数据落在均值附近特定范围内的概率：

| 区间 | 概率 |
|------|------|
| $[\mu - \sigma, \mu + \sigma]$ | $\approx 68.27\%$ |
| $[\mu - 2\sigma, \mu + 2\sigma]$ | $\approx 95.45\%$ |
| $[\mu - 3\sigma, \mu + 3\sigma]$ | $\approx 99.73\%$ |

## 与其他分布的关系

| 分布 | 关系 |
|------|------|
| **卡方分布** | 若 $Z_1, ..., Z_k \overset{iid}{\sim} N(0,1)$，则 $\sum_{i=1}^{k} Z_i^2 \sim \chi^2(k)$ |
| **t分布** | 若 $Z \sim N(0,1)$，$V \sim \chi^2(k)$，则 $\frac{Z}{\sqrt{V/k}} \sim t(k)$ |
| **F分布** | 若 $U \sim \chi^2(d_1)$，$V \sim \chi^2(d_2)$，则 $\frac{U/d_1}{V/d_2} \sim F(d_1, d_2)$ |
| **对数正态分布** | 若 $\log X \sim N(\mu, \sigma^2)$，则 $X$ 服从对数正态分布 |

## 应用场景

### 1. 机器学习
- **误差建模**：假设噪声服从正态分布
- **高斯过程**：基于正态分布的非参数模型
- **变分推断**：使用正态分布近似后验

### 2. 深度学习
- **权重初始化**：Xavier/Glorot初始化利用正态分布
- **批量归一化**：假设特征服从正态分布
- **VAE**：隐变量假设服从标准正态分布

### 3. 统计推断
- **假设检验**：t检验、z检验基于正态假设
- **置信区间**：大样本下统计量近似正态
- **回归分析**：最小二乘估计的正态假设

### 4. 实际现象
- 测量误差
- 人体身高、体重等生理指标
- 考试成绩分布
- 测量仪器噪声

## 代码示例

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

# 生成正态分布随机数
samples = np.random.normal(loc=0, scale=1, size=1000)

# 计算概率密度函数
x = np.linspace(-5, 5, 100)
pdf = stats.norm.pdf(x, loc=0, scale=1)

# 计算累积分布函数
cdf = stats.norm.cdf(x, loc=0, scale=1)

# 标准化
X = np.random.normal(loc=5, scale=2, size=1000)
Z = (X - np.mean(X)) / np.std(X)  # Z ~ N(0, 1)
```
