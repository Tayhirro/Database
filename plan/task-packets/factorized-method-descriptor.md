# 任务包：分层方法标签与采样状态显式化

## 任务目标

- 将第 2 节的 2.1—2.5 明确限定为“单条精化链内部的近端更新机制”。
- 用 `计算拓扑 × 近端更新机制 × 候选 / 采样状态 × 评价或反馈来源` 描述完整方法，避免二级机制标签覆盖单解、群体更新、独立多链和采样方式等性质。
- 在跨维度索引中显式保留候选或采样状态。

## 必须满足的判据

- 保留 2.1—2.5 的现有名称、编号和案例。
- $N$ 只计算在搜索过程中作为解参与更新、选择或跨轮传递的候选；仅用于估计梯度、熵或统计量的瞬时样本不得自动把单解优化改判为群体搜索。
- 区分一次性 Best-of-$N$、$N$ 条独立精化链、单解随机局部求解和反馈耦合群体更新。
- 只有跨候选信息共同改变下一轮候选或 proposal state 时，才令 $C=1$ 并归入 Adaptive Population Scaling。
- 2.x 标签不得被表述为方法的完整类别标签。

## 拒绝条件

- 删除或合并现有 2.x 类别。
- 把“使用采样”直接等同于 Width 或 Population。
- 把独立多起点优化误写为单解 Sequential Depth。
- 把只做一次评分选择的候选集误写为反馈耦合群体搜索。
- 修改现有论文事实、链接或用户指定的分类名称。

- 检查五个一级标题和 2.1—2.5 标题顺序未变。

- 检查跨维度索引新增候选 / 采样状态列，且所有数据行列数一致。
- 检查关键方法行仍存在，Obsidian 嵌入语法数量与修改前一致。
