# 任务包：2.2 Rethinking / Iterative Reasoning 文献补充

## Scope

- 检索与测试时动作规划、VLA 或 embodied agent 中的串行 reasoning-state refinement 相关论文。
- 仅把满足“同一决策内，上一轮语义 / 推理状态进入下一轮 reasoning 或 rewriting”的工作作为 2.2 正例。
- 将一次性 CoT、独立 critique、树搜索和真实环境反馈方法写入边界，不混作纯 Rethinking。

## Files to read

- `Database/任务-new.md` 第 2.2、2.3、4、5 节
- 一手论文页面、摘要或全文

## Evidence/data inputs

- Agent Reach / Exa 候选检索结果
- arXiv、会议论文页或作者项目页中的题名、摘要、方法说明
- 文档既有分类判据

## Required artifacts

- 至少一篇强匹配的 2.2 论文案例；若不存在，则明确记录证据不足，不强行补入。
- 每篇纳入论文对应的 evidence-map 行。
- 2.2 段落蓝图与 evidence coverage 审核。
- 正文中的链接、方法摘要、分类理由和排除边界。

## Rejection checks

- 不因论文使用 chain-of-thought 就自动视为多轮测试时精化。
- 有独立 scorer、critic 或 critique-to-revision 数据流的工作不得写成纯 Rethinking。
- tree-of-thought、MCTS 等显式分支不得写入第 2 类。
- 动作执行后根据新观测反思的工作不得写成同一决策内的 2.2。
- 不使用二手博客支撑核心机制主张，不编造录用信息、指标或论文结论。

## Validation commands

- 验证每个链接可访问，题名、作者、日期或会议元数据与一手来源一致。
- 检查每个正文机制主张均映射到 evidence map。
- 检查新增案例位于 2.2 与 2.3 之间，原有标题和案例顺序不被破坏。
- 检查跨维度索引新增对应方法行且列数一致。
- 检查 Obsidian embed 和 Markdown 表格结构未损坏。

- 状态：完成。

- 排除边界：ISR-LLM（Verifier-Guided）。
- 索引结果：新增 2 行，共 32 个方法条目。
