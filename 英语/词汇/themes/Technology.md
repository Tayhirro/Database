| debug | /diːˈbʌɡ/ | 调试 | Debug the code to find errors. |
| compile | /kəmˈpaɪl/ | 编译 | Compile the source code. |
| deploy | /dɪˈplɔɪ/ | 部署 | Deploy the application to production. |
