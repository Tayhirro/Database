# 词汇（Vocabulary）笔记组织说明（可扩展 & 速查）

导航：[english/README.md](../README.md) ｜[english/英语索引.md](../英语索引.md) ｜本分支：[english/词汇/索引.md](索引.md) ｜[english/词汇/概念图.md](概念图.md)

这部分按"面向对象/类型系统"的方式组织：
- `Word`：单词对象（词形、音标、词性、释义、例句）
- `WordRoot`：词根对象（形式、含义、来源、衍生词）
- `Affix`：词缀对象（前缀/后缀、功能、常用组合）
- `WordFamily`：单词家族（同根词群、词形变化）
- `Theme`：主题词汇（场景分类、专业领域）

常用操作（记忆法、构词规则、搭配规律）作为 `modules/` 里的可复用工具箱；例句与练习独立放在 `examples/` 与 `exercises/`。

## 建议学习路线（缺哪块补哪块）
1. **词根词缀系统**：掌握高频词根、前缀、后缀
2. **核心词汇**：按主题学习常用词汇
3. **构词规律**：理解派生、复合等构词方法
4. **搭配扩展**：学习常用词组和固定搭配
5. **语境应用**：通过例句理解词汇用法
