# 词汇概念图

> 展示词汇学习的各模块关系与路径

## 1. 词汇构建体系

```
词根词缀 (Roots & Affixes)
    ↓
    ├─ 词根 (Root) ─→ 核心含义
    ├─ 前缀 (Prefix) ─→ 修饰/方向/数量
    └─ 后缀 (Suffix) ─→ 词性/功能
    ↓
单词家族 (Word Family)
    ↓
    ├─ 派生词 (Derivatives)
    ├─ 复合词 (Compounds)
    └─ 转化词 (Conversions)
    ↓
主题词汇 (Thematic Vocabulary)
    ↓
搭配与应用 (Collocations & Usage)
```

## 2. 学习路径

### 路径1：词根记忆法
```
学习词根 → 掌握前后缀 → 推导单词家族 → 扩展主题词汇
```

### 路径2：主题扩展法
```
选择主题 → 核心词汇 → 相关搭配 → 例句应用
```

### 路径3：构词分析法
```
分析单词结构 → 识别词根词缀 → 理解词义 → 记忆巩固
```

## 3. 核心模块连接

- **词根词缀** ↔ **单词家族**：通过词根词缀快速扩展词汇
- **主题词汇** ↔ **搭配规律**：主题场景中的常用搭配
- **记忆法** ↔ **单词学习**：使用记忆技巧提高效率
- **构词法** ↔ **词义推导**：通过结构理解词义
