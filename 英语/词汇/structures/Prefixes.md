# 常用前缀 (Common Prefixes)

> 前缀通常改变单词的意思或方向，不改变词性

## 使用说明
- **前缀**：前缀形式
- **含义**：核心意思
- **例词**：包含该前缀的常用单词

---

## 否定前缀

### un- = not (不，非)
- 例词：
  - unable (不能的) = un + able
  - unhappy (不快乐的) = un + happy
  - uncertain (不确定的) = un + certain
  - unfair (不公平的) = un + fair

### in-, im-, il-, ir- = not (不，非)
- 说明：在不同字母前有变体
- 例词：
  - incorrect (不正确的) = in + correct
  - impossible (不可能的) = im + possible
  - illegal (非法的) = il + legal
  - irregular (不规则的) = ir + regular

### dis- = not, opposite (不，相反)
- 例词：
  - disagree (不同意) = dis + agree
  - disappear (消失) = dis + appear
  - disadvantage (缺点) = dis + advantage
  - disconnect (断开) = dis + connect

### non- = not (非)
- 例词：
  - nonprofit (非营利的) = non + profit
  - nonsense (胡说) = non + sense
  - nonstop (不停的) = non + stop

## 方向/位置前缀

### pre- = before (在...之前)
- 例词：
  - preview (预览) = pre + view
  - predict (预测) = pre + dict
  - prepare (准备) = pre + pare
  - prefix (前缀) = pre + fix

### post- = after (在...之后)
- 例词：
  - postpone (推迟) = post + pone
  - postgraduate (研究生) = post + graduate
  - postwar (战后的) = post + war

### pro- = forward, before (向前，在前)
- 例词：
  - progress (进步) = pro + gress
  - project (项目) = pro + ject
  - propose (提议) = pro + pose
  - promote (促进) = pro + mote

### re- = again, back (再，回)
- 例词：
  - return (返回) = re + turn
  - review (复习) = re + view
  - rebuild (重建) = re + build
  - react (反应) = re + act

### ex- = out (出，外)
- 例词：
  - export (出口) = ex + port
  - exit (出口) = ex + it
  - external (外部的) = ex + ternal
  - exclude (排除) = ex + clude

### in-, im- = in, into (进入)
- 例词：
  - include (包括) = in + clude
  - import (进口) = im + port
  - input (输入) = in + put
  - inside (内部) = in + side

## 程度/强度前缀

### super- = above, over (超过，在上)
- 例词：
  - superior (优越的) = super + ior
  - superman (超人) = super + man
  - supermarket (超市) = super + market
  - supervise (监督) = super + vise

### sub- = under, below (在下，次)
- 例词：
  - subway (地铁) = sub + way
  - submarine (潜水艇) = sub + marine
  - submit (提交) = sub + mit
  - subtract (减去) = sub + tract

### over- = too much, above (过度，在上)
- 例词：
  - overcome (克服) = over + come
  - overflow (溢出) = over + flow
  - overlook (俯瞰) = over + look

### under- = below, not enough (在下，不足)
- 例词：
  - understand (理解) = under + stand
  - underground (地下) = under + ground
  - underestimate (低估) = under + estimate

## 关系前缀

### co-, con-, com- = together, with (共同，一起)
- 例词：
  - cooperate (合作) = co + operate
  - connect (连接) = con + nect
  - combine (结合) = com + bine
  - community (社区) = com + munity

### inter- = between, among (在...之间)
- 例词：
  - international (国际的) = inter + national
  - internet (互联网) = inter + net
  - interact (互动) = inter + act
  - interview (面试) = inter + view

### trans- = across, beyond (穿过，越过)
- 例词：
  - transport (运输) = trans + port
  - translate (翻译) = trans + late
  - transfer (转移) = trans + fer
  - transform (转变) = trans + form

---

## 学习建议
1. 掌握高频否定前缀（un-, in-, dis-）
2. 理解方向前缀的空间含义
3. 注意前缀的变体形式（如 in-/im-/il-/ir-）
4. 将同类前缀归类学习
