# 常用词根 (Common Roots)

> 词根是单词的核心，掌握词根可以快速扩展词汇量

## 使用说明
- **词根**：词根形式（可能有变体）
- **含义**：核心意思
- **来源**：拉丁语(L)、希腊语(Gr)、古英语(OE)等
- **例词**：包含该词根的常用单词

---

## A-C

### act, ag = do, drive (做，驱动)
- 来源：Latin
- 例词：
  - act (行动) = act
  - active (积极的) = act + ive
  - agent (代理人) = ag + ent
  - action (行动) = act + ion
  - react (反应) = re + act

### aud = hear (听)
- 来源：Latin
- 例词：
  - audio (音频) = aud + io
  - audience (观众) = aud + ience
  - auditorium (礼堂) = aud + itor + ium
  - audible (可听见的) = aud + ible

### bio = life (生命)
- 来源：Greek
- 例词：
  - biology (生物学) = bio + logy
  - biography (传记) = bio + graph + y
  - antibiotic (抗生素) = anti + bio + tic

### cap, cept, ceive = take, hold (拿，抓)
- 来源：Latin
- 例词：
  - capture (捕获) = cap + ture
  - accept (接受) = ac + cept
  - receive (收到) = re + ceive
  - concept (概念) = con + cept

### ced, cess = go, yield (走，让步)
- 来源：Latin
- 例词：
  - proceed (前进) = pro + ceed
  - success (成功) = suc + cess
  - access (进入) = ac + cess
  - excess (过度) = ex + cess

## 学习建议
1. 先掌握高频词根（如 spec, port, duct 等）
2. 通过词根分析单词结构，加深理解
3. 建立词根卡片，定期复习
4. 将同词根的单词归类学习
