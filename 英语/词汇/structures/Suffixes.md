# 常用后缀 (Common Suffixes)

> 后缀通常改变单词的词性，有时也会影响词义

## 使用说明
- **后缀**：后缀形式
- **功能**：词性转换功能
- **例词**：包含该后缀的常用单词

---

## 名词后缀

### -tion, -sion, -ation = 表示行为、状态、结果
- 例词：
  - action (行动) = act + ion
  - decision (决定) = decide + sion
  - education (教育) = educate + ation
  - information (信息) = inform + ation

### -ment = 表示行为、状态、结果
- 例词：
  - movement (运动) = move + ment
  - development (发展) = develop + ment
  - government (政府) = govern + ment
  - achievement (成就) = achieve + ment

### -ness = 表示状态、性质（加在形容词后）
- 例词：
  - happiness (幸福) = happy + ness
  - kindness (善良) = kind + ness
  - darkness (黑暗) = dark + ness
  - weakness (弱点) = weak + ness

### -er, -or = 表示"做...的人/物"
- 例词：
  - teacher (教师) = teach + er
  - worker (工人) = work + er
  - actor (演员) = act + or
  - director (导演) = direct + or

### -ist = 表示"从事...的人"
- 例词：
  - artist (艺术家) = art + ist
  - scientist (科学家) = science + ist
  - pianist (钢琴家) = piano + ist
  - journalist (记者) = journal + ist

### -ance, -ence = 表示状态、性质
- 例词：
  - importance (重要性) = import + ance
  - difference (差异) = differ + ence
  - performance (表演) = perform + ance
  - confidence (信心) = confide + ence

### -ity, -ty = 表示性质、状态
- 例词：
  - ability (能力) = able + ity
  - society (社会) = soci + ety
  - security (安全) = secure + ity
  - community (社区) = common + ity

---

## 形容词后缀

### -able, -ible = 表示"能够...的，可...的"
- 例词：
  - acceptable (可接受的) = accept + able
  - possible (可能的) = poss + ible
  - comfortable (舒适的) = comfort + able
  - visible (可见的) = vis + ible

### -ful = 表示"充满...的"
- 例词：
  - beautiful (美丽的) = beauty + ful
  - useful (有用的) = use + ful
  - careful (小心的) = care + ful
  - powerful (强大的) = power + ful

### -less = 表示"没有...的"
- 例词：
  - homeless (无家可归的) = home + less
  - useless (无用的) = use + less
  - careless (粗心的) = care + less
  - endless (无尽的) = end + less

### -ous, -ious = 表示"具有...性质的"
- 例词：
  - famous (著名的) = fame + ous
  - dangerous (危险的) = danger + ous
  - curious (好奇的) = cur + ious
  - ambitious (有抱负的) = ambit + ious

### -ive = 表示"有...性质的"
- 例词：
  - active (积极的) = act + ive
  - creative (创造性的) = create + ive
  - effective (有效的) = effect + ive
  - positive (积极的) = posit + ive

### -al = 表示"...的"
- 例词：
  - national (国家的) = nation + al
  - natural (自然的) = nature + al
  - personal (个人的) = person + al
  - traditional (传统的) = tradition + al

### -ic, -ical = 表示"...的"
- 例词：
  - economic (经济的) = economy + ic
  - basic (基本的) = base + ic
  - historical (历史的) = history + ical
  - practical (实用的) = practice + ical

---

## 动词后缀

### -ize, -ise = 表示"使...化，做..."
- 例词：
  - realize (意识到) = real + ize
  - organize (组织) = organ + ize
  - modernize (现代化) = modern + ize
  - recognize (认出) = re + cognize

### -fy, -ify = 表示"使...化"
- 例词：
  - satisfy (满足) = satis + fy
  - simplify (简化) = simple + ify
  - classify (分类) = class + ify
  - identify (识别) = ident + ify

### -en = 表示"使..."
- 例词：
  - shorten (缩短) = short + en
  - strengthen (加强) = strength + en
  - widen (加宽) = wide + en
  - deepen (加深) = deep + en

---

## 副词后缀

### -ly = 表示"以...方式"（形容词→副词）
- 例词：
  - quickly (快速地) = quick + ly
  - carefully (小心地) = careful + ly
  - easily (容易地) = easy + ly
  - fortunately (幸运地) = fortunate + ly

### -ward(s) = 表示"向...方向"
- 例词：
  - forward (向前) = for + ward
  - backward (向后) = back + ward
  - upward (向上) = up + ward
  - afterward (之后) = after + ward

---

## 其他常用后缀

### -logy = 表示"学科"
- 例词：
  - biology (生物学) = bio + logy
  - psychology (心理学) = psycho + logy
  - technology (技术) = techno + logy
  - sociology (社会学) = socio + logy

### -ship = 表示"状态，关系"
- 例词：
  - friendship (友谊) = friend + ship
  - leadership (领导) = leader + ship
  - relationship (关系) = relation + ship
  - membership (会员资格) = member + ship

### -hood = 表示"状态，时期"
- 例词：
  - childhood (童年) = child + hood
  - neighborhood (邻里) = neighbor + hood
  - adulthood (成年) = adult + hood
  - likelihood (可能性) = likely + hood

## 学习建议
1. 掌握名词、形容词后缀的区别
2. 理解后缀的词性转换功能
3. 注意同词根加不同后缀的词性变化
4. 练习词性转换（如：act → action → active → actively）
