# 搭配规律 (Collocations)

> 英语中固定或常用的词组搭配

## 1. 动词搭配 (Verb Collocations)

### 1.1 Make vs Do

**Make (制作、使成为)**:
```
make a decision (做决定)
make a mistake (犯错)
make progress (取得进步)
make a plan (制定计划)
make money (赚钱)
make an effort (努力)
make a difference (有影响)
make sense (有意义)
make friends (交朋友)
make a phone call (打电话)
```

**Do (做、执行)**:
```
do homework (做作业)
do business (做生意)
do research (做研究)
do exercise (做运动)
do one's best (尽力)
do damage (造成损害)
do good (做好事)
do harm (造成伤害)
do a favor (帮忙)
do the dishes (洗碗)
```

**区别**:
- Make: 强调"创造、产生结果"
- Do: 强调"执行、完成动作"

## 2. 形容词搭配 (Adjective Collocations)

### 2.1 Strong vs Weak

**不说**: very rain ❌  
**应说**: heavy rain ✓ (大雨)

**Strong 类搭配**:
```
强度高的形容词:
  strong wind (强风)
  heavy rain (大雨)
  severe problem (严重问题)
  deep sleep (熟睡)
  intense heat (酷热)
```

**Weak 类搭配**:
```
强度低的形容词:
  light rain (小雨)
  gentle breeze (微风)
  slight problem (小问题)
  mild weather (温和的天气)
```

---

### 2.2 常用形容词搭配

**Big/Large/Great**:
```
big/large:
  big house (大房子)
  large company (大公司)
  large amount (大量)
  
great:
  great success (巨大成功)
  great pleasure (非常荣幸)
  great importance (极其重要)
```

**High/Tall**:
```
high:
  high price (高价)

  high speed (高速)
  high temperature (高温)
  
tall:
  tall building (高楼)

```

### 5.1 常用短语动词

```

give up (放弃)
go on (继续)

work out (解决；锻炼)
```

### 5.2 可分离 vs 不可分离

**可分离** (可以插入宾语):
```
turn off the light ✓
turn the light off ✓

put on your coat ✓
put your coat on ✓
```

**不可分离** (宾语必须在后):
```
look after the children ✓
look the children after ❌

run into a friend ✓
run a friend into ❌
```

## 7. 学习策略

### 识别搭配
1. 阅读时注意词组
2. 标记常见搭配
3. 查词典时看例句
4. 记录固定搭配

### 练习方法
1. **搭配卡片**: 制作搭配卡片复习
2. **造句练习**: 用搭配造句
3. **替换练习**: 找同义搭配
4. **错误分析**: 纠正中式英语

### 常见错误

**中式英语 → 地道英语**:
```
❌ open the phone → ✓ turn on the phone
❌ close the phone → ✓ turn off the phone
❌ eat medicine → ✓ take medicine
❌ say a lie → ✓ tell a lie
❌ make sports → ✓ do sports / play sports
❌ see a movie → ✓ watch a movie / see a film
```
