# 构词法 (Word Formation)

> 英语中新词的形成方法

## 1. 派生法 (Derivation)

**定义**: 通过添加前缀或后缀改变词义或词性

### 1.1 前缀派生
**功能**: 通常改变词义，不改变词性

**示例**:
```
happy (快乐的) → unhappy (不快乐的)
possible (可能的) → impossible (不可能的)
like (喜欢) → dislike (不喜欢)
view (看) → preview (预览)
```

### 1.2 后缀派生
**功能**: 通常改变词性

**示例**:
```
名词 → 形容词:
  danger (n. 危险) → dangerous (adj. 危险的)
  care (n. 关心) → careful (adj. 小心的)

形容词 → 名词:
  happy (adj. 快乐的) → happiness (n. 幸福)
  dark (adj. 黑暗的) → darkness (n. 黑暗)

动词 → 名词:
  move (v. 移动) → movement (n. 运动)
  develop (v. 发展) → development (n. 发展)

形容词 → 副词:
  quick (adj. 快的) → quickly (adv. 快速地)
  careful (adj. 小心的) → carefully (adv. 小心地)
```

### 1.3 同时使用前后缀
**示例**:
```
courage (勇气)
  → encourage (en + courage) 鼓励
  → encouragement (en + courage + ment) 鼓励(n.)
  → encouraging (en + courage + ing) 鼓舞人心的
  → discourage (dis + en + courage) 使沮丧
```

## 2. 复合法 (Compounding)

**定义**: 将两个或多个词组合成一个新词

### 2.1 名词复合
**模式**: 名词 + 名词
```
book + shop → bookshop (书店)
class + room → classroom (教室)
tooth + brush → toothbrush (牙刷)
sun + light → sunlight (阳光)
```

**模式**: 形容词 + 名词
```
black + board → blackboard (黑板)
green + house → greenhouse (温室)
high + way → highway (高速公路)
```

**模式**: 动词 + 名词
```
swim + suit → swimsuit (泳衣)
wash + room → washroom (洗手间)
play + ground → playground (操场)
```

### 2.2 形容词复合
**模式**: 副词 + 过去分词
```
well + known → well-known (著名的)
highly + developed → highly-developed (高度发达的)
```

**模式**: 形容词 + 名词 + -ed
```
warm + heart + ed → warm-hearted (热心的)
kind + heart + ed → kind-hearted (善良的)
```

### 2.3 动词复合
**模式**: 副词 + 动词
```
over + look → overlook (俯瞰，忽视)
under + stand → understand (理解)
```

## 3. 转化法 (Conversion)

**定义**: 词性改变但词形不变

### 3.1 名词 → 动词
```
water (n. 水) → water (v. 浇水)
email (n. 电子邮件) → email (v. 发邮件)
book (n. 书) → book (v. 预订)
hand (n. 手) → hand (v. 递给)
```

### 3.2 动词 → 名词
```
look (v. 看) → look (n. 看，外表)
try (v. 尝试) → try (n. 尝试)
visit (v. 访问) → visit (n. 访问)
walk (v. 走) → walk (n. 散步)
```

### 3.3 形容词 → 动词
```
clean (adj. 干净的) → clean (v. 清洁)
empty (adj. 空的) → empty (v. 倒空)
dry (adj. 干的) → dry (v. 弄干)
```

### 3.4 形容词 → 名词
```
poor (adj. 贫穷的) → the poor (n. 穷人)
rich (adj. 富有的) → the rich (n. 富人)
young (adj. 年轻的) → the young (n. 年轻人)
```

## 4. 缩略法 (Abbreviation)

### 4.1 首字母缩略 (Acronym)
```
UNESCO (联合国教科文组织)
  = United Nations Educational, Scientific and Cultural Organization
NASA (美国国家航空航天局)
  = National Aeronautics and Space Administration
AI (人工智能)
  = Artificial Intelligence
```

### 4.2 截短法 (Clipping)
```
examination → exam (考试)
advertisement → ad (广告)
laboratory → lab (实验室)
mathematics → math (数学)
```

### 4.3 混成法 (Blending)
```
breakfast + lunch → brunch (早午餐)
smoke + fog → smog (烟雾)
motor + hotel → motel (汽车旅馆)
information + entertainment → infotainment (资讯娱乐)
```

---

## 5. 逆构法 (Back-formation)

**定义**: 从一个词删除假想的词缀形成新词

```
editor (编辑) → edit (编辑v.)
television (电视) → televise (电视播放)
enthusiasm (热情) → enthuse (使热情)
donation (捐赠) → donate (捐赠v.)
```

---

## 6. 专有名词转化 (Eponym)

**定义**: 人名、地名等转化为普通词汇

```
sandwich → 三明治 (来自 Sandwich 伯爵)
boycott → 抵制 (来自 Captain Boycott)
Xerox → 复印 (来自施乐公司)
google → 搜索 (来自 Google)
```

---

## 7. 拟声法 (Onomatopoeia)

**定义**: 模仿声音创造词汇

```
动物叫声:
  meow (喵) - 猫叫
  woof (汪) - 狗叫
  moo (哞) - 牛叫

其他声音:
  buzz (嗡嗡声)
  click (咔哒声)
  splash (扑通声)
  bang (砰的一声)
```

## 应用技巧

### 学习策略
1. **识别构词模式**: 看到新词先分析结构
2. **掌握常用词缀**: 词根词缀是基础
3. **理解词性转换**: 熟悉派生规律
4. **积累词族**: 同时学习相关词汇

### 实践方法
1. 看到单词先拆分: un-believe-able
2. 推测词义: 不-相信-能的 → 难以置信的
3. 验证并记忆
4. 扩展词族: believe, belief, believable, unbelievable

---

## 练习建议

1. **词根词缀练习**: 每天学习 5-10 个词根/词缀
2. **词族扩展**: 每个单词扩展 3-5 个同族词
3. **构词分析**: 分析文章中的生词结构
4. **创造练习**: 尝试用已知词缀创造新词
