## 面向对象设计说明

这部分按"面向对象/类型系统"的方式组织：
- `Word`：单词对象（词形、音标、词性、释义、词源）
- `WordRoot`：词根对象（词根形式、含义、来源语言）
- `WordAffix`：词缀对象（前缀/后缀、功能、常用组合）
- `Phrase`：短语对象（固定搭配、习语）
- `Sentence`：句子对象（例句、语法结构）

常用操作（记忆法、构词法、搭配）作为 `modules/` 里的可复用工具箱；例句与练习独立放在 `examples/` 与 `exercises/`。
