# 语法（Grammar）笔记组织说明

导航：[english/README.md](../README.md) ｜[english/英语索引.md](../英语索引.md) ｜本分支：[english/语法/索引.md](索引.md) ｜[english/语法/概念图.md](概念图.md)

这部分按"面向对象/类型系统"的方式组织：
- `Sentence`：句子对象（主谓宾结构、句型分类）
- `Clause`：从句对象（定语从句、状语从句、名词性从句）
- `Tense`：时态对象（时间+体态的组合）
- `Voice`：语态对象（主动/被动）
- `Mood`：语气对象（陈述/祈使/虚拟）

常用操作（句型分析、错误纠正、搭配规律）作为 `modules/` 里的可复用工具箱；例句与练习独立放在 `examples/` 与 `exercises/`。

## 学习路线建议
1. **基础句型**：五大基本句型（SV/SVO/SVC/SVOO/SVOC）
2. **时态系统**：理解时间+体态的组合逻辑
3. **语态转换**：主动与被动语态
4. **从句结构**：定语从句 → 状语从句 → 名词性从句
5. **特殊句式**：强调/倒装/虚拟语气
6. **常见错误**：规避中式英语典型问题
