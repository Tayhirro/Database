## 1. 核心概念依赖链

```
Word (单词)
  ├─ WordForm (词形): 单复数、时态变化
  ├─ Pronunciation (发音): 音标、重音
  ├─ Etymology (词源)
  │   ├─ WordRoot (词根)
  │   ├─ Prefix (前缀)
  │   └─ Suffix (后缀)
  ├─ Meaning (释义)
  │   ├─ Denotation (字面义)
  │   └─ Connotation (引申义/语境义)
  └─ Usage (用法)
      ├─ Collocation (搭配)
      ├─ Phrase (短语)
      └─ Sentence (句子)
```

## 2. 模块关系

### 2.1 词汇构建路径
```
词根词缀系统 (Roots & Affixes)
    ↓
构词法 (Word Formation)
    ↓
单词家族 (Word Family)
    ↓
主题词汇 (Thematic Vocabulary)
    ↓
语境应用 (Contextual Usage)
```

### 2.2 语法理解路径
```
词性 (Parts of Speech)
    ↓
短语结构 (Phrase Structure)
    ↓
句子成分 (Sentence Elements)
    ↓
句型 (Sentence Patterns)
    ↓
语篇 (Discourse)
```

## 3. 跨分支连接

- **词汇 ↔ 语法**：词性决定语法功能，语法结构影响词义理解
- **词根 → 词汇扩展**：通过词根词缀系统快速扩充词汇量
- **搭配 → 语法**：固定搭配体现语法规则
- **例句 → 记忆**：语境化学习提升记忆效果

## 4. 常用学习组合

1. **词根记忆法**：词根 + 前缀/后缀 → 单词家族 → 主题词汇
2. **搭配学习法**：高频词 + 常用搭配 → 固定短语 → 例句
3. **主题扩展法**：主题词汇 → 相关搭配 → 场景句型
4. **语法强化法**：词性 → 句子成分 → 句型 → 复杂句式
