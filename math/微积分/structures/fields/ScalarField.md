# 标量场（Scalar Field）

## 1. 一句话
- 标量场就是“每个位置一个数”：本质是函数 `f: Ω -> R`。

## 2. 接口：数据 + 约束（像类型签名）
- 定义域（空间/区域）：`Ω ⊆ R^n`（也可以是曲面/流形上的区域）
- 值域：`R`（或 `C`）
- 正则性（可选但很关键）：
  - 连续：`f ∈ C(Ω)`
  - 可微：`f ∈ C^1(Ω)`（能谈梯度）
  - 二阶可微：`f ∈ C^2(Ω)`（能谈拉普拉斯）

## 3. 例子与反例
- 温度场：`T(x,y) ∈ R`
- 密度场/势能场：`ρ(x)`、`U(x)`
- 工程对照：灰度图像 `I(u,v)` 就是离散标量场（网格上的函数）

## 4. 你能对它做什么（最常用操作）
- 代数运算（闭包）：
  - `(f+g)(x)=f(x)+g(x)`
  - `(af)(x)=a f(x)`
  - `(fg)(x)=f(x)g(x)`
- 微分运算（需要正则性）：
  - 梯度：`∇f`（得到向量场）
  - 拉普拉斯：`Δf = ∇·∇f`
  - 入口：见 [math/微积分/modules/Operators.md](../../modules/Operators.md)

## 5. 与向量场的关系（最常用的一条边）
- `f` 的梯度场 `∇f` 是一个向量场；它指向“增长最快的方向”，长度是“最大增长率”。
