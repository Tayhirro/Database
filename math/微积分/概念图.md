# 概念图（微积分 / 向量分析）

导航：[math/README.md](../README.md) ｜[math/索引.md](../索引.md) ｜本分支：[math/微积分/README.md](README.md) ｜[math/微积分/索引.md](索引.md)

> 读法：先分清“对象是什么”（标量场/向量场），再看“能对它做什么操作”（梯度/散度/旋度/拉普拉斯）。

## 1. 两类核心对象（像两种类型）
- 标量场 `f(x)`：见 [math/微积分/structures/fields/ScalarField.md](structures/fields/ScalarField.md)
- 向量场 `v(x)`：见 [math/微积分/structures/fields/VectorField.md](structures/fields/VectorField.md)

## 2. 常用操作（模块接口）
- `∇f`：标量场 -> 向量场（梯度）
- `∇·v`：向量场 -> 标量场（散度）
- `∇×v`：向量场 -> 向量场/标量（旋度，取决于维度）
- `Δf = ∇·∇f`：标量场 -> 标量场（拉普拉斯）
- 入口：见 [math/微积分/modules/Operators.md](modules/Operators.md)

## 3. 工程对照（把“场”落到张量形状）
- 图像灰度 `x ∈ R^{H×W}`：标量场（离散网格上）
- 光流/位移 `f ∈ R^{H×W×2}`：二维向量场（离散网格上）
