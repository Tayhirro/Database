# 概念图（微积分：主框架 + 插件）

导航：[math/README.md](../README.md) ｜[math/索引.md](../索引.md) ｜本分支：[math/微积分/README.md](README.md) ｜[math/微积分/索引.md](索引.md)

> 读法：先看主线（极限→导数→积分→级数→ODE），再把需要的插件挂上去（例如“场/向量分析”）。

## 1. 主框架：对象（先不绑定子主题）
- 标量函数 `f: D -> R`：见 [math/微积分/structures/functions/ScalarFunction.md](structures/functions/ScalarFunction.md)
- 向量值函数 `g: D -> R^m`：见 [math/微积分/structures/functions/VectorValuedFunction.md](structures/functions/VectorValuedFunction.md)
- 参数曲线 `γ: I -> R^n`：见 [math/微积分/structures/geometry/ParametricCurve.md](structures/geometry/ParametricCurve.md)

## 2. 主框架：模块接口栈
- `Limits`：极限/连续 → [math/微积分/modules/Limits.md](modules/Limits.md)
- `Differentiation`：导数/梯度/Jacobian（局部线性化）→ [math/微积分/modules/Differentiation.md](modules/Differentiation.md)
- `Integration`：积分（连续求和/总量）→ [math/微积分/modules/Integration.md](modules/Integration.md)
- `Series`：级数/Taylor（局部近似/误差）→ [math/微积分/modules/Series.md](modules/Series.md)
- `ODE`：`x'(t)=F(x,t)`（变化规律）→ [math/微积分/modules/ODE.md](modules/ODE.md)

## 3. 插件：场/向量分析（你补充的“场”在这里）
- 标量场/向量场是“把位置当输入”的函数对象：
  - 标量场：见 [math/微积分/structures/fields/ScalarField.md](structures/fields/ScalarField.md)
  - 向量场：见 [math/微积分/structures/fields/VectorField.md](structures/fields/VectorField.md)
- 向量分析算子：`∇/div/curl/Δ` → [math/微积分/modules/VectorOperators.md](modules/VectorOperators.md)

## 4. 工程对照（把“场”落到张量形状）
- 灰度图像 `x ∈ R^{H×W}`：离散标量场
- 光流/位移 `f ∈ R^{H×W×2}`：离散二维向量场
