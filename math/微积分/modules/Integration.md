# 积分（Integration）

## 1. 一句话
- 积分把“累加”严谨化：面积/体积/总量/期望的共同语言。

## 2. 一元积分（接口级）
- `∫_a^b f(x) dx`：对区间的“连续求和”
- 微积分基本定理（接口级）：导数与积分互为逆操作（在合适条件下）

## 3. 多元积分与换元（扩展点）
- `∫∫_Ω f dA`、`∫∫∫ f dV`
- 换元公式会引入 Jacobian（链接到 `Differentiation`）

## 4. 与场插件的连接（扩展点）
- 线积分/曲面积分/体积分（后续可插 Green/Stokes/散度定理）
