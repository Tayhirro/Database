# 微分算子速查：梯度 / 散度 / 旋度 / 拉普拉斯（Operators）

## 1. 统一记号（先把类型搞清楚）
- 标量场：`f: Ω -> R`
- 向量场：`v: Ω -> R^n`，`v=(v_1,...,v_n)`
- 变量：`x=(x_1,...,x_n)`

## 2. 梯度（gradient）：标量场 -> 向量场
若 `f ∈ C^1`，定义
- `∇f = (∂f/∂x_1, ..., ∂f/∂x_n)`

直觉：指向增长最快方向；大小是最大方向导数。

## 3. 散度（divergence）：向量场 -> 标量场
若 `v ∈ C^1`，定义
- `∇·v = Σ_{i=1}^n ∂v_i/∂x_i`

直觉：源/汇强度（“往外流”多还是“往里吸”多）。

## 4. 旋度（curl）：向量场 -> 向量场/标量
### 4.1 三维（`n=3`）
若 `v=(v_1,v_2,v_3) ∈ C^1`，定义
- `∇×v = ( ∂v_3/∂x_2 - ∂v_2/∂x_3,  ∂v_1/∂x_3 - ∂v_3/∂x_1,  ∂v_2/∂x_1 - ∂v_1/∂x_2 )`

### 4.2 二维（`n=2`，常用“标量旋度”）
对 `v=(v_1,v_2)`，常定义一个标量
- `curl(v) := ∂v_2/∂x_1 - ∂v_1/∂x_2`

直觉：局部“绕着转”的强度与方向。

## 5. Jacobian（雅可比）：向量场的局部线性化
若 `v ∈ C^1`，定义矩阵
- `J_v(x) = [∂v_i/∂x_j]_{i,j}`

用途：局部近似 `v(x+δ) ≈ v(x) + J_v(x) δ`。

## 6. 拉普拉斯（Laplacian）：标量场 -> 标量场
若 `f ∈ C^2`，定义
- `Δf = ∇·∇f = Σ_{i=1}^n ∂^2 f/∂x_i^2`

直觉：和“扩散/平滑/曲率”相关（PDE 里最常见的算子之一）。

## 7. 常见组合关系（记两条最常用的）
- `∇f` 是向量场；再取散度得到 `Δf`
- 若 `v = ∇f`（梯度场），则在光滑条件下常有 `∇×v = 0`（“无旋”）
