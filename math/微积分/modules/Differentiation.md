# 导数与微分（Differentiation）

## 1. 一句话
- 导数/微分把“局部变化”变成可计算对象：一元是斜率，多元是最好的线性近似。

## 2. 一元导数（`R -> R`）
对 `f: R -> R`，定义
- `f'(a) = lim_{h->0} (f(a+h)-f(a))/h`
- 二阶导：`f''(x) = (f'(x))'`

## 3. 多元：偏导/梯度/Jacobian（最小接口）
- 偏导：`∂f/∂x_i`
- 梯度：`∇f = (∂f/∂x_1,...,∂f/∂x_n)`
- Jacobian：`J_g(x) = [∂g_i/∂x_j]`
- Hessian：`H_f(x) = [∂^2 f/(∂x_i∂x_j)]`

## 4. 核心性质（插件入口）
- 局部线性化：`f(x+δ) ≈ f(x) + ∇f(x)·δ`
- 链式法则：复合函数导数（后续可再拆插件）
