# 概念图（概率论）

导航：[math/README.md](../README.md) ｜[math/数学索引.md](../数学索引.md) ｜本分支：[math/概率论/README.md](README.md) ｜[math/概率论/索引.md](索引.md)

## 1. 核心对象
- `ProbabilitySpace (Ω, F, P)`：定义事件与概率
- `RandomVariable X`：把 `Ω` 上的不确定性映射到数值空间
- `Distribution P_X`：`X` 在数值空间上的“推前”概率
- `StochasticProcess {X_t}`：按时间索引的一族随机变量，固定 `t` 是随机变量，固定 `ω` 是样本路径
P_X(A) := P(X ∈ A) = P(X^{-1}(A))
其中 X^{-1}(A) = { ω ∈ Ω : X(ω) ∈ A } 是把 S 里的事件“拉回”到 Ω，再用原概率 P 去算；算出来的数被当作 S 上事件 A 的概率，这一步就是“推前”。

## 2. 常用“操作/关系”
- 期望：`E[X]`（线性、可积性条件）
- 条件：`P(A|B)`、`E[X|G]`（信息 σ-代数 `G`）
- 独立：事件独立、随机变量独立
- 收敛：依概率/几乎处处/分布收敛（与极限定理相关）

## 3. 连续时间随机过程
- 随机过程：`{X_t}` 是一族按时间索引的随机变量，`dX_t` 先理解成小时间增量；见 [structures/StochasticProcess.md](structures/StochasticProcess.md)
- 随机过程类型入口：具体过程类型放在 [processes/README.md](processes/README.md)
- 布朗运动：`W_{t+Δt}-W_t ~ N(0, Δt)`，把离散高斯扰动推广到连续时间；见 [processes/BrownianMotion.md](processes/BrownianMotion.md)
- SDE 主线：`dX_t=f(X_t,t)dt+g(t)dW_t`，其中 `dW_t` 对应 `sqrt(Δt)ε`；从单粒子小步规则继续走到转移核、Fokker-Planck 和 PF-ODE；见 [modules/SDE.md](modules/SDE.md)
- 细节附录：随机积分见 [modules/StochasticIntegral.md](modules/StochasticIntegral.md)；转移核、Dirac delta 和测试函数/弱形式见 [modules/SDEToFokkerPlanck.md](modules/SDEToFokkerPlanck.md)
- 扩散项来源：`dW_t ~ sqrt(dt)`，所以 `(dW_t)^2=dt`，这会在 Fokker-Planck 方程里留下二阶扩散项

这条线的父子/依赖关系可以压缩成：

```text
ProbabilitySpace
  -> RandomVariable
      -> Distribution
      -> StochasticProcess
          -> BrownianMotion
              -> SDE 主线
                  -> Fokker-Planck
                      -> PF-ODE / Diffusion

附录：
  SDE 主线 -> StochasticIntegral
  SDE 主线 -> SDEToFokkerPlanck
```

## 6. 走向数理统计
- 当你开始问“给了一个样本 batch，怎么估计总体的 `μ`、`σ^2`，这些估计有多不稳”，主题就已经从概率论切到数理统计。
- 概率论负责提供：
  - `bar X`、`S^2` 这类统计量的分布基础
  - 正态分布、`t` 分布、`chi^2` 分布、CLT 这类近似与精确工具
- 进一步见 [math/数理统计/README.md](../数理统计/README.md)
