# 应用笔记（Probability Applications）

这里放概率论概念在机器学习、生成模型、训练目标中的应用。它不同于 `modules/`：

- `modules/` 放可复用的概率论工具、定理和推导套路；
- `applications/` 放这些工具在具体模型或训练目标中的使用方式。
