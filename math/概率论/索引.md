# 术语索引（概率论）

导航：[math/README.md](../README.md) ｜[math/数学索引.md](../数学索引.md) ｜本分支：[math/概率论/README.md](README.md) ｜[math/概率论/概念图.md](概念图.md)

> 用法：先按关键词找；重要条目会逐步补全链接。

## B
- Borel σ-代数 `B(R^d)`：`R^d` 上的“可测集合族”，使得随机变量 `X: (Ω, F) -> (R^d, B(R^d))` 有严格定义。
- 布朗运动 / 维纳过程（Brownian motion / Wiener process）：连续时间随机过程，核心增量为 `W_{t+Δt}-W_t ~ N(0, Δt)`；→ [processes/BrownianMotion.md](processes/BrownianMotion.md)

## C
- 条件概率（Conditional probability）：`P(A|B) = P(A,B)/P(B)`，已知 B 发生时 A 的概率；→ [modules/ChainRule.md](modules/ChainRule.md)
- 条件期望（Conditional expectation）：`E[Y|X]` 是已知 X 后对 Y 的最优预测，本质是 X 的函数；→ [modules/ConditionalExpectation.md](modules/ConditionalExpectation.md)
- 条件方差（Conditional variance）：`Var(Y|X)` 是已知 X 后 Y 的剩余离散程度；→ [modules/MomentsMeasures.md](modules/MomentsMeasures.md)
- 条件独立（Conditional independence）：`X ⟂ Y | Z` 表示给定 `Z` 后，`X` 与 `Y` 的联合条件分布分解；→ [modules/Independence.md](modules/Independence.md)
- 链式法则（Chain rule / 乘法法则）：`P(A,B) = P(A|B)P(B)`，分解联合概率的核心工具；→ [modules/ChainRule.md](modules/ChainRule.md)

## D
- Dirac delta（狄拉克 delta）：连续情形里的“选择器”，满足 `∫δ(y-x)h(x)dx=h(y)`；用于把 `p_t(y)` 写成“不动转移核”作用在 `p_t(x)` 上；主线见 [modules/SDE.md](modules/SDE.md)，细节见 [modules/SDEToFokkerPlanck.md](modules/SDEToFokkerPlanck.md)
- 分布（Distribution / law）：随机变量在值域空间上诱导出的概率测度；基础结构见 [structures/Distribution.md](structures/Distribution.md)，常见分布条目见 [distributions/README.md](distributions/README.md)

## E
- 期望（Expectation）：随机变量的加权平均；→ [modules/Expectation.md](modules/Expectation.md)

## F
- 方差（Variance）：离散程度度量，`Var(X) = E[X^2] - (E[X])^2`；→ [modules/MomentsMeasures.md](modules/MomentsMeasures.md)
- Fokker-Planck 方程：把 SDE 的单粒子随机运动翻译成密度 `p_t(x)` 的演化方程；主线见 [modules/SDE.md](modules/SDE.md)，细节见 [modules/SDEToFokkerPlanck.md](modules/SDEToFokkerPlanck.md)
- 峰度（Kurtosis）：分布尾部厚度，正态分布峰度为 3；→ [modules/MomentsMeasures.md](modules/MomentsMeasures.md)

## I
- 独立性（Independence）：`X ⟂ Y` 表示联合分布分解为边缘分布之积；→ [modules/Independence.md](modules/Independence.md)

## J
- 交叉熵（Cross entropy）：`H(p,q)=-E_p[log q]`；one-hot 分类时等价于真实类别的负对数似然；→ [applications/LikelihoodCrossEntropy.md](applications/LikelihoodCrossEntropy.md)

## L
- 拉普拉斯分布 / 双指数分布（Laplace / Double Exponential）：尖峰+厚尾，常对应 `L1` 损失；→ [distributions/LaplaceDistribution.md](distributions/LaplaceDistribution.md)

## P
- 偏度（Skewness）：分布对称性度量；→ [modules/MomentsMeasures.md](modules/MomentsMeasures.md)
- 概率密度（probability density）：连续分布的局部浓度；区域概率由 `P(X∈A)=∫_A p(x)dx` 得到；→ [structures/Distribution.md](structures/Distribution.md)
- 概率质量（probability mass）：某个点或区域里总共有多少概率；连续情形下通常是区域上的密度积分，不是新的基本单位；→ [structures/Distribution.md](structures/Distribution.md)
- 概率空间（Probability space）：`(Ω, F, P)`，其中 `F` 是 σ-代数，`P(Ω)=1`；→ [structures/ProbabilitySpace.md](structures/ProbabilitySpace.md)
- 归一化（normalization）：把“非负函数”变成合法概率分布的步骤；例题见 [math/概率论/examples/Examples.md](examples/Examples.md)。

## Q
- 全期望公式（Law of total expectation / Tower property）：`E[Y] = E[E[Y|X]]`；→ [modules/IteratedExpectation.md](modules/IteratedExpectation.md)
- 全方差公式（Law of total variance）：`Var(Y)=E[Var(Y|X)]+Var(E[Y|X])`，把总方差拆成组内与组间；→ [modules/MomentsMeasures.md](modules/MomentsMeasures.md)

## R
- 随机变量（Random variable）：可测函数 `X: (Ω, F) -> (R^d, B(R^d))`；→ [structures/RandomVariable.md](structures/RandomVariable.md)
- 随机过程（Stochastic process）：按时间索引的一族随机变量 `{X_t}`，可把 `X_t` 理解成“时刻 t 的随机状态”；→ [structures/StochasticProcess.md](structures/StochasticProcess.md)
- 随机积分（Stochastic integral）：`∫ g(s)dW_s` 是对布朗增量的加权累加，若 `g` 确定则方差为 `∫ g(s)^2ds`；主线见 [modules/SDE.md](modules/SDE.md)，细节见 [modules/StochasticIntegral.md](modules/StochasticIntegral.md)
- 随机微分方程（SDE）：`dX_t=f(X_t,t)dt+g(t)dW_t` 表示小步增量规则，不是普通导数方程；→ [modules/SDE.md](modules/SDE.md)
- 弱形式 / 测试函数（weak form / test function）：不直接处理尖核极限，而是通过所有 `∫φ(x)p(x)dx` 的变化反推出密度方程；主线见 [modules/SDE.md](modules/SDE.md)，细节见 [modules/SDEToFokkerPlanck.md](modules/SDEToFokkerPlanck.md)

## S
- σ-代数（sigma-algebra）：对补集与可数并封闭的集合族；用于定义“可测事件”。
- 似然 / 负对数似然（Likelihood / NLL）：最大似然训练、自回归分解和 one-hot 交叉熵的关系；→ [applications/LikelihoodCrossEntropy.md](applications/LikelihoodCrossEntropy.md)

## X
- 协方差（Covariance）：线性相关性度量，`Cov(X,Y) = E[XY] - E[X]E[Y]`；→ [modules/MomentsMeasures.md](modules/MomentsMeasures.md)
- 协方差矩阵（Covariance matrix）：多元随机变量的协方差矩阵 `Σ`，`Σ_{ij} = Cov(X_i, X_j)`；→ [modules/MomentsMeasures.md](modules/MomentsMeasures.md)
- 相关系数（Correlation coefficient）：归一化协方差，`ρ(X,Y) = Cov(X,Y)/(σ_X σ_Y)`，取值 [-1,1]；→ [modules/MomentsMeasures.md](modules/MomentsMeasures.md)

## Y
- 原像 / 逆像（Preimage / Inverse image）：`X^{-1}(A)=\{\omega\in\Omega:X(\omega)\in A\}`，表示集合在映射下的原像；→ [structures/RandomVariable.md](structures/RandomVariable.md)

## Z
- 正态分布 / 高斯分布（Normal / Gaussian）：连续钟形分布，布朗运动和高斯噪声的基础分布；→ [distributions/正态分布.md](distributions/正态分布.md)
- 转移核（transition kernel）：`q_{\Delta t}(y|x)`，表示当前在 `x` 时下一小步落到 `y` 附近的条件密度；主线见 [modules/SDE.md](modules/SDE.md)，细节见 [modules/SDEToFokkerPlanck.md](modules/SDEToFokkerPlanck.md)
