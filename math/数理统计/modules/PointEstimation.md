# 点估计与估计不确定度（Point Estimation & Uncertainty）

## 1. 一句话
- 从一个 batch 去估计总体里的 `μ`、`σ^2` 时，估计值本身会随抽样变化而波动；这种波动就是“估计不确定度”。

## 2. 基本设定
- 设 `X_1,...,X_n` 是从某个总体分布里抽出来的样本，常先假设它们是 `iid`
- 总体参数：
  - 均值 `μ = E[X]`
  - 方差 `σ^2 = Var(X)`
- 你手上的一个 batch，只是这套随机机制的一次实现
- 所以从这个 batch 算出的量不是“真值”，而是估计量 `T(X_1,...,X_n)`

## 3. 估计 `μ` 和 `σ^2` 的最常见统计量
- 样本均值：
  - `bar X = (1/n) sum_{i=1}^n X_i`
- 样本方差（无偏版本）：
  - `S^2 = (1/(n-1)) sum_{i=1}^n (X_i-bar X)^2`
- 样本标准差：
  - `S = sqrt(S^2)`

## 4. 为什么会有“不确定度”
- 如果你重复抽很多次大小同为 `n` 的 batch，每次都会得到一个新的 `bar X`、`S^2`
- 因而 `bar X`、`S^2` 自己也是随机变量
- 它们在重复抽样下形成的分布，叫做抽样分布（sampling distribution）

## 5. 样本均值的抽样波动
- 对 `bar X`，有：
  - `E[bar X] = μ`
  - `Var(bar X) = σ^2 / n`
- 所以样本均值的标准误（standard error）是：
  - `SE(bar X) = sqrt(Var(bar X)) = σ / sqrt(n)`
- 真实 `σ` 通常未知，所以实践里常用：
  - `hat SE(bar X) = S / sqrt(n)`

## 6. 样本方差的抽样波动
- `S^2` 也是随机的；你换一个 batch，估出来的方差也会变
- 若总体正态，则有精确结果：
  - `((n-1)S^2) / σ^2 ~ chi^2_{n-1}`
- 这说明：
  - `S^2` 的不确定度也能被量化
  - 但它不像 `bar X` 那样只靠一个简单的 `σ/sqrt(n)` 公式就能说完
- 若你关心的是 `σ` 而不是 `σ^2`，通常会更常借助 bootstrap 来给区间和标准误

## 7. 置信区间：把“不确定度”写成区间
- 对 `μ`：
  - 若总体正态且 `σ` 未知，则
    - `(bar X - μ) / (S / sqrt(n)) ~ t_{n-1}`
  - 因而一个常见的 `1-α` 置信区间是
    - `bar X ± t_{n-1,1-α/2} * S / sqrt(n)`
- 对 `σ^2`（正态总体）：
  - `[((n-1)S^2)/chi^2_{1-α/2,n-1}, ((n-1)S^2)/chi^2_{α/2,n-1}]`
- 对 `σ`：
  - 把上面区间两端开平方即可

## 8. 一个最重要的区分
- 数据的标准差 `S`：
  - 描述样本点本身有多分散
- 估计量的标准误 `SE(bar X)`：
  - 描述“我对总体均值的估计有多不稳”
- 这两个量不一样；`S` 大不一定代表 `SE(bar X)` 大，因为 `SE(bar X)` 还会被 `sqrt(n)` 除掉

## 9. 在“一个 batch 估计均值和方差”里的直觉
- batch 越小，`bar X` 和 `S^2` 的波动越大，不确定度越高
- batch 越大，`bar X` 更稳定，因为 `SE(bar X) ~ 1/sqrt(n)`
- 在神经网络里，如果你拿 mini-batch 去估计均值/方差，这种随机波动会直接体现为 batch statistics 的噪声

## 10. 什么时候要想到重抽样
- 若统计量很简单（均值、方差）且分布假设可接受，优先用解析公式
- 若统计量复杂、难推标准误，或你想直接从样本近似抽样分布，优先想到 bootstrap
- 若你想快速看 estimator 的 bias / variance 近似，可看 jackknife
- 进一步见 [math/数理统计/modules/Resampling.md](Resampling.md)

## 11. 常见坑
- 把样本方差当成估计不确定度本身
- 忘记 `S^2` 的无偏版本分母是 `n-1`，不是 `n`
- 把“这个 batch 的统计量”误当成“总体真参数”
- 看见“留一法”就直接等同于 LOOCV，而没区分是在估计参数不确定度还是评估模型误差
