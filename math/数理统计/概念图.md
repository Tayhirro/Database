# 概念图（数理统计）

导航：[math/README.md](../README.md) ｜[math/数学索引.md](../数学索引.md) ｜本分支：[math/数理统计/README.md](README.md) ｜[math/数理统计/索引.md](索引.md)

## 1. 核心对象链
- 数据生成分布 `P_θ`
- 随机样本 `X_1,...,X_n`
- 统计量 / 估计量 `T_n = T(X_1,...,X_n)`
- 抽样分布：`T_n` 在重复抽样下的分布
- 不确定度量化：标准误、置信区间、bias / variance

## 2. 最常用的一条线
- 总体均值 `μ` / 方差 `σ^2`
- 样本均值 `bar X` / 样本方差 `S^2`
- `SE(bar X)`、`CI(μ)`、`CI(σ^2)`
- 入口见 [math/数理统计/modules/PointEstimation.md](modules/PointEstimation.md)

## 3. 两类“估计不确定度”的路线
- 解析路线：直接推 `E[T_n]`、`Var(T_n)`、渐近正态、`t` / `chi^2` 分布
- 重抽样路线：Jackknife / Bootstrap
- 入口见 [math/数理统计/modules/Resampling.md](modules/Resampling.md)

## 4. 容易混淆但目标不同
- 参数估计：关心 `μ`、`σ^2`、分位数等未知总体量
- 模型评估：关心预测误差 / 泛化误差
- LOOCV 看起来像“留一法”，但它主要属于模型验证，不是参数标准误的主方法

## 5. 与其他分支的连接
- 概率论 → 数理统计：概率论给出样本与统计量的分布基础；数理统计在此基础上做反推
- 正态分布 / CLT：很多均值估计、置信区间近似都依赖正态近似；见 [math/概率论/distributions/正态分布.md](../概率论/distributions/正态分布.md)
- 线性代数：协方差矩阵、最小二乘、回归估计都直接落在线代对象上
