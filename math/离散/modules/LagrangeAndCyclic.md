# Lagrange 定理与循环群（Lagrange & Cyclic Groups）

## 1. 群的阶与元素的阶

- **群的阶**：`|G|` = 群中元素的个数。有限则称有限群，否则称无限群。
- **元素的阶**：`ord(a) = min{ n≥1 | a^n = e }`；若不存在正整数使 `a^n = e`，则称 `a` 为无限阶。
- 元素的阶 = 它生成的循环子群的阶：`ord(a) = |<a>|`

## 2. Lagrange 定理

若 `G` 是有限群，`H ≤ G`，则：

- `|H|` 整除 `|G|`，即 `|G| = [G:H] · |H|`
- 其中 `[G:H]` = `H` 在 `G` 中的**指数**（`H` 的左陪集个数 = 右陪集个数）

推论：
- 有限群中每个元素的阶整除群的阶：`ord(a) | |G|`
- 若 `|G| = n`，则对所有 `a∈G` 有 `a^n = e`
- 素数阶群一定是循环群（因为子群阶只能是 1 或 `p`，任何非单位元都生成整个群）

## 3. 循环群（cyclic group）

若存在 `g∈G` 使 `G = { g^k | k∈Z } = <g>`，则称 `G` 为**循环群**，`g` 为**生成元**。

### 3.1 分类
- 无限循环群：`<g> ≅ (Z, +)`（生成元无限阶）
- `n` 阶有限循环群：`<g> ≅ (Z/nZ, +)`（生成元阶为 `n`）

### 3.2 循环群的子群
- **循环群的子群仍然是循环群**
- `Z` 的子群形如 `nZ`（`n≥0`），每个非零子群由最小正整数生成
- `Z/nZ` 的子群与 `n` 的正因子一一对应：`d | n` 对应子群 `<n/d>` 阶为 `d`
- 例：`Z/12Z` 的子群有 `<0>, <6>, <4>, <3>, <2>, <1> = Z/12Z`，阶分别为 `1, 2, 3, 4, 6, 12`

### 3.3 生成元的个数
- `Z/nZ` 的生成元个数 = `φ(n)`（Euler 函数）
- `k` 是 `Z/nZ` 的生成元 ⟺ `gcd(k, n) = 1`

## 4. Euler 函数 φ（与循环群的连接）

- `φ(n)` = 小于 `n` 且与 `n` 互素的正整数个数
- `φ(p) = p-1`（`p` 素数）
- `φ(p^k) = p^k - p^{k-1}`
- `gcd(m,n)=1` 时 `φ(mn) = φ(m)φ(n)`（积性）
- Euler 定理：`gcd(a,n)=1` 时 `a^{φ(n)} ≡ 1 (mod n)`
