# 偏序关系 / Hasse 图 / 格（Partial Order & Lattice）

## 1. 偏序关系（partial order）

集合 `X` 上的二元关系 `≤` 称为偏序，如果满足：
- **自反**：`x ≤ x`
- **反对称**：`x ≤ y` 且 `y ≤ x ⇒ x = y`
- **传递**：`x ≤ y, y ≤ z ⇒ x ≤ z`

配对 `(X, ≤)` 称为**偏序集（poset）**。

> 对比等价关系：偏序把"对称"换成"反对称"，从"视为同一"变成"分出大小"。

### 1.1 常见术语
- **可比**：`x ≤ y` 或 `y ≤ x`（至少一个成立）
- **不可比**：既不 `x ≤ y` 也不 `y ≤ x`
- **全序（线序）**：任意两个元素都可比（例：`(R, ≤)` 通常意义下的大小）
- **极大元**：不存在 `y` 使 `x < y`（`<` 表示 `≤` 且 `≠`）
- **最大元**：对所有 `y` 都有 `y ≤ x`（若存在则唯一）
- **极小元 / 最小元**：对偶定义

## 2. Hasse 图

有限偏序集的标准画法：
- 每个元素画一个点
- 若 `x < y` 且中间没有 `z` 使 `x < z < y`（即 `y` **覆盖** `x`），则画一条从 `x` 到 `y` 的线段，`y` 在上方
- 省略自反边（自己到自己）和传递边（可由路径推出的边）

### 2.1 例子
- 幂集 `(P({1,2,3}), ⊆)`：底部 `∅`，顶部 `{1,2,3}`，中间三层分别是单元素集、双元素集
- 整除关系 `({1,2,3,4,6,12}, |)`：底部 `1`，顶部 `12`，按素因子分层

## 3. 格（lattice）

偏序集 `(L, ≤)` 称为格，如果任意两个元素 `a, b` 都有：
- **上确界（join）**：`a ∨ b` = 最小的 `c` 使 `a ≤ c` 且 `b ≤ c`
- **下确界（meet）**：`a ∧ b` = 最大的 `c` 使 `c ≤ a` 且 `c ≤ b`

### 3.1 例子
- 幂集格：`(P(S), ⊆)`，`A ∨ B = A ∪ B`，`A ∧ B = A ∩ B`
- 整除格：`(N, |)`，`a ∨ b = lcm(a,b)`，`a ∧ b = gcd(a,b)`
- 反例：偏序集 `{a,b,c,d}` 中 `a,b` 有两个不可比的上界但没有最小上界 ⇒ 不是格

### 3.2 格的代数定义（等价视角）
也可以不从偏序出发，而直接从运算定义格：

集合 `L` 配两个二元运算 `∨`（join）和 `∧`（meet），满足：
- 交换律：`a ∨ b = b ∨ a`，`a ∧ b = b ∧ a`
- 结合律：`a ∨ (b ∨ c) = (a ∨ b) ∨ c`，`a ∧ (b ∧ c) = (a ∧ b) ∧ c`
- 吸收律：`a ∨ (a ∧ b) = a`，`a ∧ (a ∨ b) = a`

从代数定义可以反推偏序：`a ≤ b ⟺ a ∨ b = b`

### 3.3 特殊格
- **有界格**：存在最大元 `1`（top）和最小元 `0`（bottom）
- **分配格**：`a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c)` 成立（幂集格是分配格）
- **模格**：`a ≤ c ⇒ a ∨ (b ∧ c) = (a ∨ b) ∧ c`（分配格 ⇒ 模格）
- **补格**：有界格中每个元素都有补元（`a ∨ a' = 1, a ∧ a' = 0`）
- **布尔代数**：有界 + 分配 + 补（经典例子：命题逻辑 / 集合的幂集）

## 4. 对偶原理

偏序集 `(X, ≤)` 的对偶是 `(X, ≥)`（把所有关系反转）。
格的任何定理，把 `∨` 和 `∧` 互换、`≤` 和 `≥` 互换，仍然成立。
