# 多项式环（Polynomial Ring）

## 1. 一句话

`R[x]` 是从环 `R` 出发构造的"带一个形式变量 `x`"的环；当 `R` 是域时，`R[x]` 可以做带余除法，从而成为 Euclidean Domain。

## 2. 接口：数据 + 公理

- 底层集合：形如 `a_0 + a_1 x + ... + a_n x^n` 的形式表达式，`a_i ∈ R`，`n ∈ N`
- 运算：
  - 加法：逐项相加
  - 乘法：卷积（`(fg)_k = Σ_{i+j=k} a_i b_j`）
- 公理：继承 `R` 的环公理；若 `R` 交换则 `R[x]` 交换；若 `R` 有 `1` 则 `R[x]` 有 `1`

## 3. 继承与对比

- 父类：`R` 是环时 `R[x]` 也是环；`R` 交换则 `R[x]` 交换；`R` 整环则 `R[x]` 整环
- 子类：`R` 是域时 `R[x]` 是 Euclidean Domain（`φ(f) = deg(f)`）
- 对比：
  - `R[x]` vs 多项式函数：形式多项式 ≠ 多项式函数（有限域上不同多项式可能给出相同函数）
  - `R[x]` vs `R[[x]]`（形式幂级数环）：`R[x]` 只允许有限项

## 4. 例子与反例

- 例子：`Z[x]`（整数系数多项式）、`Q[x]`（有理系数）、`R[x]`（实系数）、`F_p[x]`（有限域上）
- 例子：`k[x,y]` = `k[x][y]`（多变量，迭代构造）
- 反例：`Z/6Z[x]` 不是整环（因为 `Z/6Z` 不是整环）

## 5. 常见构造

### 5.1 次数（degree）
- `deg(f)` = 最高次非零项的次数；`deg(0) = -∞`（约定）
- `deg(fg) ≤ deg(f) + deg(g)`；整环上取等号

### 5.2 带余除法（域上）
若 `F` 是域，`f, g ∈ F[x]`，`g ≠ 0`，则存在唯一的 `q, r ∈ F[x]` 使：
- `f = qg + r`，且 `r = 0` 或 `deg(r) < deg(g)`

这使得 `F[x]` 成为 Euclidean Domain，从而也是 PID 和 UFD。

### 5.3 因式定理与根
- `a` 是 `f(x)` 的根 ⟺ `(x-a) | f(x)`
- `n` 次多项式在域中至多有 `n` 个根

### 5.4 不可约多项式
- `f ∈ F[x]` 不可约：`f` 非零非可逆，且不能写成两个更低次多项式的乘积
- 一次多项式恒不可约
- `R[x]` 中二次/三次多项式：不可约 ⟺ 无实根
- **Eisenstein 判别法**（`Z[x]` 上）：若存在素数 `p` 使 `p` 整除所有非首项系数、`p` 不整除首项系数、`p²` 不整除常数项，则多项式在 `Q[x]` 上不可约

### 5.5 Gauss 引理
- `Z[x]` 中的本原多项式（系数的 gcd = 1）在 `Z[x]` 上不可约 ⟺ 在 `Q[x]` 上不可约
- 推论：`R` 是 UFD ⇒ `R[x]` 也是 UFD

## 6. 态射视角

- 环同态 `φ: R → S` 可以"逐系数"延拓为 `φ̃: R[x] → S[x]`
- **赋值同态**：固定 `a ∈ R`，映射 `ev_a: R[x] → R`，`f ↦ f(a)` 是环同态
- `F[x]/(f)` 的构造：若 `f` 不可约，则 `F[x]/(f)` 是域（这是构造有限域的核心方法）

## 7. 速查

- `F` 域 ⇒ `F[x]` 是 ED ⇒ PID ⇒ UFD
- 带余除法：`f = qg + r`，`deg(r) < deg(g)`
- `n` 次多项式至多 `n` 个根
- `(x-a) | f(x)` ⟺ `f(a) = 0`
- Eisenstein：`p` 整除非首项、`p∤` 首项、`p²∤` 常数项 ⇒ 不可约
- `f` 不可约 ⇒ `F[x]/(f)` 是域
- Gauss 引理：`R` 是 UFD ⇒ `R[x]` 是 UFD
