# 运行全链路（Spring Boot：启动 → 运行 → 结束）

## 一句话
运行全链路将应用划分为“启动/运行/结束”三段，并提供到各段条目页的导航入口。

## 严格定义
将一次应用进程的生命周期抽象为三段序列：
- 启动：从 `main()` 到应用 ready
- 运行：对外提供服务与执行后台任务
- 结束：从关闭信号到资源回收完成

## 接口：数据 + 约束
- 数据：进程入口（`main()`）、运行时配置（`Environment`）、容器（`ApplicationContext`）。
- 约束：运行段与结束段的具体细节依赖应用形态（Web/非 Web）与所启用的模块（WebServer、消息、定时任务等）。

## 地图（总览）

```
启动：
  main()
    -> SpringApplication.run(...)
         -> prepareEnvironment(...)
         -> createApplicationContext()
         -> prepareContext(...)
         -> context.refresh()
         -> runners / ready

运行：
  WebServer 接管请求（servlet/reactive）
  Scheduler/Async/消息消费等后台任务运行

结束：
  JVM shutdown hook / 外部信号
    -> context.close()
         -> 销毁单例、发布关闭事件、释放资源
```
