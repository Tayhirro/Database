# 启动流程（Spring Boot：从 `SpringApplication.run` 到 ready）

## 一句话
启动流程是 `SpringApplication` 对“环境准备、上下文创建、refresh、runner 执行、就绪信号”的阶段化编排。

## 严格定义
给定主配置源 `primarySources` 与启动参数 `args`，启动过程可视为一次函数调用
$$
\texttt{SpringApplication.run(primarySources, args)} \to \texttt{ConfigurableApplicationContext},
$$
其内部按阶段构造 `Environment`、创建 `ApplicationContext`、触发 `refresh()`，并在成功后发布就绪相关事件。

## 接口：数据 + 约束
- 输入：
  - 主配置源（`primarySources`，例如 `@SpringBootApplication` 标注的类）
  - 启动参数 `args`（命令行参数）
- 输出：
  - `ConfigurableApplicationContext`（成功时）
  - 失败异常（失败时，可能伴随失败事件与资源回收）
- 约束：
  - 具体事件名称与扩展点加载细节与 Boot 版本相关（Boot 2.x 与 3.x 的资源与 SPI 列表存在差异）。

## 阶段（Phase）

### Phase 0：入口
- `main()` → `SpringApplication.run(primarySources, args)`  
  关联条目：`SpringApplication` 见 [springboot/modules/SpringApplication.md](../modules/SpringApplication.md)。

### Phase 1：构造与扩展点装配
- 构造 `SpringApplication` 实例：记录 `primarySources`、推断 `WebApplicationType`、加载启动期扩展点集合（例如 listeners/initializers 等）
  - 扩展点发现机制：见 [springboot/modules/SpringFactories.md](../modules/SpringFactories.md)

### Phase 2：Environment 准备（外部化配置聚合）
- 构造/配置 `Environment`
- 聚合配置源（命令行、系统属性、环境变量、配置文件等），解析 profile 与属性
  - 外部化配置：见 [springboot/modules/ExternalizedConfiguration.md](../modules/ExternalizedConfiguration.md)

### Phase 3：ApplicationContext 创建与准备
- 按 `WebApplicationType` 选择 `ConfigurableApplicationContext` 的实现并创建
- 将 `Environment` 绑定到 context
- 执行 `ApplicationContextInitializer`（refresh 之前的 context 变换）
  - `ApplicationContext`：见 [springboot/modules/ApplicationContext.md](../modules/ApplicationContext.md)

### Phase 4：`context.refresh()`（Spring Framework 容器刷新）
- 调用 `AbstractApplicationContext.refresh()`（模板方法）
- 在 refresh 的配置类解析与 BeanDefinition 注册阶段导入自动配置（auto-configuration）
  - 自动配置：见 [springboot/modules/AutoConfiguration.md](../modules/AutoConfiguration.md)

### Phase 5：启动后回调与就绪信号
- 执行 `ApplicationRunner` / `CommandLineRunner`
- 发布 started/ready 等生命周期事件（事件名称与阶段边界随版本略有差异）
  - 生命周期事件：见 [springboot/modules/ApplicationLifecycleEvents.md](../modules/ApplicationLifecycleEvents.md)

## 关系：上级/下级/等价/特例/推广
- 上级：应用生命周期（启动/运行/停止）。
- 下级：`Environment`、`ApplicationContext`、自动配置、扩展点发现、生命周期事件。
- 特例：Web 应用会包含嵌入式 WebServer 的创建与绑定（见 [springboot/modules/EmbeddedWebServer.md](../modules/EmbeddedWebServer.md)）。
