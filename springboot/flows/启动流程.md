# 启动流程（Spring Boot：从 `SpringApplication.run` 到 ready）

## 一句话
启动流程是 `SpringApplication` 对“环境准备、上下文创建、refresh、runner 执行、就绪信号”的阶段化编排。

## 严格定义
给定主配置源 `primarySources` 与启动参数 `args`，启动过程可视为一次函数调用
$$
\texttt{SpringApplication.run(primarySources, args)} \to \texttt{ConfigurableApplicationContext},
$$
其内部按阶段构造 `Environment`、创建 `ApplicationContext`、触发 `refresh()`，并在成功后发布就绪相关事件。

## 接口：数据 + 约束
- 输入：
  - 主配置源（`primarySources`，例如 `@SpringBootApplication` 标注的类）
  - 启动参数 `args`（命令行参数）
- 输出：
  - `ConfigurableApplicationContext`（成功时）
  - 失败异常（失败时，可能伴随失败事件与资源回收）
- 约束：
  - 具体事件名称与扩展点加载细节与 Boot 版本相关（Boot 2.x 与 3.x 的资源与 SPI 列表存在差异）。

## 阶段（Phase）

| Phase  | 阶段名称           | 说明                              | 关键操作                                                                   | 对应 Listener 回调                       | 对应事件                                  |
| ------ | -------------- | ------------------------------- | ---------------------------------------------------------------------- | ------------------------------------ | ------------------------------------- |
| **0**  | 入口             | 启动开始，最早钩子                       | `main()` → `SpringApplication.run()`                                   | `listeners.starting()`               | `ApplicationStartingEvent`            |
| **1**  | 构造与扩展点装配       | 创建 SpringApplication 实例，加载扩展点   | 推断 `WebApplicationType`，从 `spring.factories` 加载 listeners/initializers | -                                    | -                                     |
| **2**  | Environment 准备 | 构造 Environment，聚合配置源            | 加载命令行参数、系统属性、配置文件，解析 profiles                                          | `listeners.environmentPrepared(env)` | `ApplicationEnvironmentPreparedEvent` |
| **3a** | Context 创建     | 按类型创建 ApplicationContext        | 创建 `AnnotationConfigServletWebServerApplicationContext` 等              | `listeners.contextPrepared(ctx)`     | `ApplicationContextInitializedEvent`  |
| **3b** | Context 准备     | 执行 Initializers，绑定 Environment  | 执行 `ApplicationContextInitializer`，关联 listeners                        | `listeners.contextLoaded(ctx)`       | `ApplicationPreparedEvent`            |
| **4**  | 容器刷新           | Spring Framework 容器刷新（Bean 实例化） | 调用 `context.refresh()`：BeanDefinition 注册、BFPP/BPP 执行、Bean 实例化          | -                                    | `ContextRefreshedEvent`               |
| **5a** | 启动完成           | 容器已就绪，Runner 未执行                | 刷新完成，所有非 lazy Bean 已实例化                                                | `listeners.started(context)`         | `ApplicationStartedEvent`             |
| **5b** | Runner 执行      | 用户自定义启动逻辑                       | 执行 `ApplicationRunner` / `CommandLineRunner`                           | -                                    | -                                     |
| **5c** | 服务就绪           | 应用完全就绪，对外服务                     | Runner 执行完毕，发布就绪信号                                                     | `listeners.running(context)`         | `ApplicationReadyEvent`               |

**阶段约束**：
- **Phase 0 (starting)**：最早钩子；此时 Environment/Context 均未创建，无法注入 Bean。
- **Phase 5a (started)**：Bean 已就绪但 Runner 未执行；适合预热、启动指标收集。
- **Phase 5c (running)**：Runner 已执行完毕；适合发送"服务已上线"通知。

## 关系：上级/下级/等价/特例/推广
- 上级：应用生命周期（启动/运行/停止）。
- 下级：`Environment`、`ApplicationContext`、自动配置、扩展点发现、生命周期事件。
