# 概念图（springboot / 跨模块）

> 读法：本页只画“主干连接边”，细节落在各自页面里。

## 1. 分层对象（从入口到运行态）
- 应用入口（Boot）→ `SpringApplication`：见 [springboot/modules/SpringApplication.md](modules/SpringApplication.md)
- `SpringApplication` → `ApplicationContext`：见 [springboot/modules/ApplicationContext.md](modules/ApplicationContext.md)
- `ApplicationContext` → Bean 定义/实例化/生命周期（refresh 过程）：见 [springboot/flows/启动流程.md](flows/启动流程.md)
- `ApplicationContext` → Environment / 外部化配置：见 [springboot/modules/ExternalizedConfiguration.md](modules/ExternalizedConfiguration.md)
- `ApplicationContext` → 事件（ApplicationEvent）与监听器：见 [springboot/modules/ApplicationLifecycleEvents.md](modules/ApplicationLifecycleEvents.md)

## 2. 启动与自动配置（Boot 编排与导入）
- 启动链路：`SpringApplication.run()` → `prepareEnvironment()` → `createApplicationContext()` → `prepareContext()` → `context.refresh()` → runners → ready（见 [springboot/flows/启动流程.md](flows/启动流程.md)）
- 自动配置（Auto-Configuration）：`@EnableAutoConfiguration` → 导入候选 auto-config → 条件过滤（见 [springboot/modules/AutoConfiguration.md](modules/AutoConfiguration.md)）
- 扩展点发现（Boot 2.x）：`SpringFactoriesLoader` → `META-INF/spring.factories`（见 [springboot/modules/SpringFactories.md](modules/SpringFactories.md)）
- 扩展点发现（Boot 3.x）：`AutoConfiguration.imports` / `SpringFactoriesLoader`（按工件与类型拆分，见 [springboot/modules/SpringFactories.md](modules/SpringFactories.md)）

## 3. Web 应用形态（可选）
- `WebApplicationType` → `ConfigurableApplicationContext` 实现选择：见 [springboot/modules/SpringApplication.md](modules/SpringApplication.md)
- 嵌入式 WebServer（Servlet/Reactive）：见 [springboot/modules/EmbeddedWebServer.md](modules/EmbeddedWebServer.md)
