## 3. 启动与自动配置（Boot 编排与导入）
- 启动链路：`SpringApplication.run()` → `prepareEnvironment()` → `createApplicationContext()` → `prepareContext()` → `context.refresh()` → `callRunners()` → ready（见 [springboot/flows/启动流程.md](flows/启动流程.md)）
  - `callRunners()` → `ApplicationRunner`（结构化参数）：见 [modules/core/bootstrap/interface/ApplicationRunner.md](modules/core/bootstrap/interface/ApplicationRunner.md)
  - `callRunners()` → `CommandLineRunner`（原始参数数组）：见 [modules/core/bootstrap/interface/CommandLineRunner.md](modules/core/bootstrap/interface/CommandLineRunner.md)
  - `ApplicationRunner.run()` 接收 `ApplicationArguments`（见 [modules/core/bootstrap/class/ApplicationArguments.md](modules/core/bootstrap/class/ApplicationArguments.md)）
- 自动配置（Auto-Configuration）：`@EnableAutoConfiguration` → 导入候选 auto-config → 条件过滤（见 [modules/config/mechanism/AutoConfiguration.md](modules/config/mechanism/AutoConfiguration.md)）
- Starter 依赖 → 自动配置：starter 依赖引入 autoconfigure 及其候选列表声明资源（见 [modules/extension/mechanism/Starters.md](modules/extension/mechanism/Starters.md)）
- 扩展点发现（Boot 2.x）：`SpringFactoriesLoader` → `META-INF/spring.factories`（见 [modules/extension/mechanism/SpringFactoriesLoader.md](modules/extension/mechanism/SpringFactoriesLoader.md)）
- 扩展点发现（Boot 3.x）：`AutoConfiguration.imports` / `SpringFactoriesLoader`（按工件与类型拆分，见 [modules/extension/mechanism/SpringFactoriesLoader.md](modules/extension/mechanism/SpringFactoriesLoader.md)）
