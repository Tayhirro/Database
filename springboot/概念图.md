# 概念图（springboot / 跨模块）

> 读法：本页只画“主干连接边”，细节落在各自页面里。

## 1. 主干链路

- 启动链路：`SpringApplication.run()` → `createApplicationContext()` → `prepareContext()` → `refresh()` → `ApplicationReadyEvent`
- 扩展点发现（Boot 2.x）：`SpringFactoriesLoader` → `META-INF/spring.factories`
- 容器点火：`AbstractApplicationContext.refresh()`（模板方法）负责把 Bean 世界真正“点起来”
