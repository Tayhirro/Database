## 2. 分层对象（从入口到运行态）
- 应用入口（Boot）→ `SpringApplication`：见 [modules/core/bootstrap/SpringApplication.md](modules/core/bootstrap/SpringApplication.md)
- `SpringApplication` → `SpringApplicationRunListeners`（RunListener 分发器）：见 [modules/core/bootstrap/SpringApplicationRunListeners.md](modules/core/bootstrap/SpringApplicationRunListeners.md)
- `SpringApplicationRunListeners` → `SpringApplicationRunListener`（阶段回调接口）：见 [modules/core/bootstrap/SpringApplicationRunListener.md](modules/core/bootstrap/SpringApplicationRunListener.md)
- `SpringApplication` → `ApplicationContext`：见 [modules/core/context/ApplicationContext.md](modules/core/context/ApplicationContext.md)
- `SpringApplication` → `EventPublishingRunListener`（事件广播）：见 [modules/core/bootstrap/EventPublishingRunListener.md](modules/core/bootstrap/EventPublishingRunListener.md)
  - 接口定义：`SpringApplicationRunListener`（见 [modules/core/bootstrap/SpringApplicationRunListener.md](modules/core/bootstrap/SpringApplicationRunListener.md)）
- `EventPublishingRunListener` → `initialMulticaster`（早期多播器：`SimpleApplicationEventMulticaster`）：见 [modules/core/bootstrap/EventPublishingRunListener.md](modules/core/bootstrap/EventPublishingRunListener.md)
- `ApplicationContext` → `applicationEventMulticaster`（事件多播器：`ApplicationEventMulticaster`）：见 [modules/core/events/ApplicationEventMulticaster.md](modules/core/events/ApplicationEventMulticaster.md)
- `ApplicationEventMulticaster` → `AbstractApplicationEventMulticaster`（抽象实现）：见 [modules/core/events/AbstractApplicationEventMulticaster.md](modules/core/events/AbstractApplicationEventMulticaster.md)
- `AbstractApplicationEventMulticaster` → `SimpleApplicationEventMulticaster`（子类实现）：见 [modules/core/events/SimpleApplicationEventMulticaster.md](modules/core/events/SimpleApplicationEventMulticaster.md)
- `ApplicationContext` → Bean 定义/实例化/生命周期（refresh 过程）：见 [springboot/flows/启动流程.md](flows/启动流程.md)
- `ApplicationContext` → Environment / 外部化配置：见 [modules/core/context/Environment.md](modules/core/context/Environment.md)
  - 外部化配置机制：见 [modules/config/ExternalizedConfiguration.md](modules/config/ExternalizedConfiguration.md)
  - 外部化配置 → 配置属性绑定（`@ConfigurationProperties`）：见 [modules/config/ConfigurationProperties.md](modules/config/ConfigurationProperties.md)
- `ApplicationContext` → 事件（ApplicationEvent）与监听器：见 [modules/core/events/ApplicationLifecycleEvents.md](modules/core/events/ApplicationLifecycleEvents.md)
  - 监听器接口：`ApplicationListener`（见 [modules/core/events/ApplicationListener.md](modules/core/events/ApplicationListener.md)）
- `ApplicationContext.refresh()` → 监听器注册与装配（写入多播器注册表）：见 [modules/core/events/ApplicationListenerRegistration.md](modules/core/events/ApplicationListenerRegistration.md)
- 观察者模式（Observer Pattern）→ `ApplicationListener` / `ApplicationEventMulticaster`：见 [modules/patterns/ObserverPattern.md](modules/patterns/ObserverPattern.md)

## 3. 启动与自动配置（Boot 编排与导入）
- 启动链路：`SpringApplication.run()` → `prepareEnvironment()` → `createApplicationContext()` → `prepareContext()` → `context.refresh()` → runners → ready（见 [springboot/flows/启动流程.md](flows/启动流程.md)）
- 自动配置（Auto-Configuration）：`@EnableAutoConfiguration` → 导入候选 auto-config → 条件过滤（见 [modules/config/AutoConfiguration.md](modules/config/AutoConfiguration.md)）
- Starter 依赖 → 自动配置：starter 依赖引入 autoconfigure 及其候选列表声明资源（见 [modules/extension/Starters.md](modules/extension/Starters.md)）
- 扩展点发现（Boot 2.x）：`SpringFactoriesLoader` → `META-INF/spring.factories`（见 [modules/extension/SpringFactoriesLoader.md](modules/extension/SpringFactoriesLoader.md)）
- 扩展点发现（Boot 3.x）：`AutoConfiguration.imports` / `SpringFactoriesLoader`（按工件与类型拆分，见 [modules/extension/SpringFactoriesLoader.md](modules/extension/SpringFactoriesLoader.md)）
