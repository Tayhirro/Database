# 术语索引（Execution）

导航：[README.md](README.md)

## B
- Bytecode（字节码）：JVM 指令集。见 [bytecode/Bytecode.md](bytecode/Bytecode.md)

## C
- C1Compiler（C1 编译器）：快速编译的 Client 编译器。见 [jit/C1Compiler.md](jit/C1Compiler.md)
- C2Compiler（C2 编译器）：深度优化的 Server 编译器。见 [jit/C2Compiler.md](jit/C2Compiler.md)

## H
- HotSpotDetection（热点探测）：识别热点代码的机制。见 [jit/HotSpotDetection.md](jit/HotSpotDetection.md)

## I
- Interpreter（解释器）：逐条解释执行字节码。见 [interpreter/Interpreter.md](interpreter/Interpreter.md)

## J
- JIT（即时编译）：将热点字节码编译为机器码。见 [jit/JIT.md](jit/JIT.md)

## L
- LocalVariableTable（局部变量表）：栈帧中存放局部变量的空间。见 [bytecode/LocalVariableTable.md](bytecode/LocalVariableTable.md)

## O
- OperandStack（操作数栈）：栈帧中的操作数栈。见 [bytecode/OperandStack.md](bytecode/OperandStack.md)
- Optimization（编译优化）：JIT 优化技术。见 [jit/Optimization.md](jit/Optimization.md)

## S
- StackFrame（栈帧）：方法调用的栈帧结构。见 [bytecode/StackFrame.md](bytecode/StackFrame.md)

## T
- TieredCompilation（分层编译）：C1 + C2 协作编译。见 [jit/TieredCompilation.md](jit/TieredCompilation.md)
