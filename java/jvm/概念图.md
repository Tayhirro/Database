# 概念图（JVM）

> 概念依赖与层级关系。

## 总览

```
JVM
├── Runtime（运行时）
│   ├── structure（内存结构）
│   │   ├── Heap
│   │   ├── MethodArea → Metaspace (JDK 8+)
│   │   ├── JVMStack
│   │   ├── NativeMethodStack
│   │   ├── ProgramCounter
│   │   └── DirectMemory
│   └── threading（线程）
│       ├── JvmRuntimeThreads
│       ├── GCThreads
│       ├── CompilerThreads
│       ├── ReferenceHandlerThread
│       ├── FinalizerThread
│       └── SignalDispatcherThread
│
├── ClassLoading（类加载）
│   ├── mechanism
│   │   ├── ClassLoadingProcess
│   │   │   ├── Loading
│   │   │   ├── Linking (Verification → Preparation → Resolution)
│   │   │   └── Initialization
│   └── classloader
│       ├── ClassLoader
│       ├── BootstrapClassLoader
│       ├── ExtensionClassLoader
│       ├── AppClassLoader
│       ├── ParentDelegation
│       └── ContextClassLoader
│
├── Execution（执行引擎）
│   ├── interpreter
│   │   └── Interpreter
│   ├── jit
│   │   ├── JIT
│   │   ├── C1Compiler
│   │   ├── C2Compiler
│   │   ├── TieredCompilation ← C1 + C2
│   │   ├── HotSpotDetection
│   │   └── Optimization
│   └── bytecode
│       ├── Bytecode
│       ├── StackFrame
│       ├── LocalVariableTable
│       └── OperandStack
│
├── GC（垃圾回收）
│   ├── mechanism
│   │   ├── GCOverview
│   │   ├── ReachabilityAnalysis
│   │   ├── GCRoots
│   │   ├── ReferenceTypes (Strong → Soft → Weak → Phantom)
│   │   ├── SafePoint
│   │   ├── CardTable
│   │   └── RememberedSet
│   ├── algorithm
│   │   ├── MarkSweep
│   │   ├── Copying
│   │   ├── MarkCompact
│   │   └── GenerationalGC ← 分代 = Young + Old
│   └── collector
│       ├── Serial
│       ├── ParNew
│       ├── ParallelScavenge
│       ├── CMS ← MarkSweep
│       ├── G1 ← Region-based
│       ├── ZGC ← Colored Pointers
│       └── Shenandoah
│
├── Memory（内存模型）
│   ├── JMM
│   ├── HappensBefore
│   ├── Volatile
│   ├── Synchronized
│   └── MemoryBarrier
│
├── Object（对象模型）
│   ├── ObjectLayout
│   ├── ObjectHeader
│   │   ├── MarkWord
│   │   └── KlassPointer
│   ├── ObjectCreation
│   └── ObjectAccess
│
├── Tuning（调优）
│   ├── parameters
│   │   ├── HeapParameters
│   │   ├── GCParameters
│   │   └── JITParameters
│   ├── tools
│   │   ├── jps / jstat / jmap / jstack / jcmd
│   │   ├── jconsole
│   │   └── VisualVM
│   └── analysis
│       ├── GCLog
│       ├── HeapDump
│       └── ThreadDump
│
└── Native（本地接口）
    ├── JNI
    └── NativeMemory
```

## 跨分支关系

| 源 | 关系 | 目标 |
|---|---|---|
| ClassLoading | 加载到 | MethodArea |
| Execution | 读取 | Bytecode |
| JIT | 使用 | CompilerThreads |
| GC | 作用于 | Heap |
| GC | 使用 | GCThreads |
| SafePoint | 暂停 | 应用线程 |
| ObjectHeader.MarkWord | 存储 | 锁状态、GC 年龄 |
| Synchronized | 关联 | MarkWord |
| jstack | 观测 | JvmRuntimeThreads |
| HeapDump | 分析 | Heap |
