# 概念图（Runtime）

导航：[README.md](README.md) | [索引.md](索引.md)

> 本页只画“层级/依赖关系边”，不展开解释。

## 分层

- Runtime → 结构（structure）
  - Runtime → Heap
  - Runtime → MethodArea / Metaspace
  - Runtime → JVMStack / NativeMethodStack / ProgramCounter
  - Runtime → DirectMemory
- Runtime → 线程（threading）
  - Runtime → JvmRuntimeThreads
  - JvmRuntimeThreads → GCThreads / CompilerThreads
  - JvmRuntimeThreads → ReferenceHandlerThread / FinalizerThread / SignalDispatcherThread
- Runtime → 平台类（class）
  - Runtime（JVM runtime）→ `java.lang.Runtime`

## 跨分支关系

- `java.lang.Runtime` → GC Roots（静态引用根来源）：见 [../gc/mechanism/GCRoots.md](../gc/mechanism/GCRoots.md)
