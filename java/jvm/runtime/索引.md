# 术语索引（Runtime）

导航：[README.md](README.md)

## C
- CompilerThreads（编译器线程）：JIT 编译器的工作线程。见 [threading/CompilerThreads.md](threading/CompilerThreads.md)

## D
- DirectMemory（直接内存）：堆外内存，通过 NIO 分配。见 [structure/DirectMemory.md](structure/DirectMemory.md)

## F
- FinalizerThread（终结器线程）：执行 finalize() 的线程。见 [threading/FinalizerThread.md](threading/FinalizerThread.md)

## G
- GCThreads（GC 线程）：执行垃圾回收的线程。见 [threading/GCThreads.md](threading/GCThreads.md)

## H
- Heap（堆）：存放对象实例的内存区域。见 [structure/Heap.md](structure/Heap.md)

## J
- JVMStack（虚拟机栈）：线程私有，存放栈帧。见 [structure/JVMStack.md](structure/JVMStack.md)
- JvmRuntimeThreads（JVM 运行态线程）：JVM 内部服务线程集合。见 [threading/JvmRuntimeThreads.md](threading/JvmRuntimeThreads.md)

## M
- MethodArea（方法区）：存放类元信息。见 [structure/MethodArea.md](structure/MethodArea.md)
- Metaspace（元空间）：JDK 8+ 方法区实现。见 [structure/Metaspace.md](structure/Metaspace.md)

## N
- NativeMethodStack（本地方法栈）：执行 Native 方法的栈。见 [structure/NativeMethodStack.md](structure/NativeMethodStack.md)

## P
- ProgramCounter（程序计数器）：当前线程执行字节码的行号指示器。见 [structure/ProgramCounter.md](structure/ProgramCounter.md)

## R
- ReferenceHandlerThread（引用处理线程）：处理待处理引用的线程。见 [threading/ReferenceHandlerThread.md](threading/ReferenceHandlerThread.md)
- Runtime（java.lang.Runtime）：Java 进程运行时环境访问入口（`getRuntime()` 返回共享实例）。见 [class/Runtime.md](class/Runtime.md)

## S
- SignalDispatcherThread（信号分发线程）：处理进程信号的线程。见 [threading/SignalDispatcherThread.md](threading/SignalDispatcherThread.md)
