# GCThreads（GC 线程）

## 一句话
GC 线程是垃圾回收器在 JVM 运行态用于执行内存回收相关工作的线程集合，其线程数量、命名与执行阶段依赖所选 GC 算法与配置。

## 严格定义
在具体 JVM 实现中，垃圾回收器会使用一组线程执行回收相关任务；这些任务可能包含 stop-the-world 阶段的并行工作，以及并发阶段的标记/清理等（是否存在并发阶段取决于回收器）。线程转储工具常以特定名称模式展示这些线程（模式依实现与回收器不同）。

## 接口：数据 + 约束
- 数据（观测级）：
  - 线程名（例如包含 GC/Collector 标识的名称模式）
  - 线程状态与栈（反映当前处于并行/并发/等待等阶段）
- 输入：
  - 回收触发条件（分配压力、周期性触发等）
- 输出：
  - 堆内存状态更新（回收、整理、引用处理等副作用）
- 约束：
  - GC 线程的行为由回收器决定；本页不将某个回收器的阶段图固定为唯一形态。
