# G1（Garbage First）

## 一句话
G1（Garbage First）是一种以区域（region）划分堆并支持并发标记与分阶段回收的收集器实现（语义与可用性依 JVM 版本与实现而定）。

## 严格定义
在收集器语义中，G1 将堆划分为多个 region，并通过并发标记等机制估计各 region 的回收收益，使得一次回收可以选择一组 region 作为回收目标并在实现定义的停顿边界内完成必要工作。其分区/region-based 组织与 remembered set 等结构相关（见 [../mechanism/RememberedSet.md](../mechanism/RememberedSet.md)）。

## 接口：数据 + 约束
- 数据：
  - Region 集合与 region 状态（实现定义）
  - RSet/卡表等跨区引用跟踪结构（见 [../mechanism/RememberedSet.md](../mechanism/RememberedSet.md)、[../mechanism/CardTable.md](../mechanism/CardTable.md)）
- 输入：
  - 分配压力与触发条件
- 输出：
  - 回收后各 region 的空间变化与对象搬迁结果（若存在）
- 约束：
  - Region 选择策略、阶段划分与目标参数的语义依实现与版本变化。
