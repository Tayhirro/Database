# 术语索引（GC）

导航：[README.md](README.md) | [概念图.md](概念图.md)

## C
- CardTable（卡表）：跨代引用的写屏障数据结构。见 [structure/CardTable.md](structure/CardTable.md)
- Cleaner：Java 9+ 提供的清理工具，基于虚引用实现。见 [mechanism/ReferenceTypes.md](mechanism/ReferenceTypes.md)
- CMS：Concurrent Mark Sweep 收集器。见 [collector/CMS.md](collector/CMS.md)
- Copying（复制算法）：将存活对象复制到另一半空间。见 [algorithm/Copying.md](algorithm/Copying.md)

## D
- DirectMemory（直接内存/堆外内存）：不受 GC 管理的堆外内存，通过虚引用实现自动释放。见 [../runtime/structure/DirectMemory.md](../runtime/structure/DirectMemory.md)

## G
- G1：Garbage First 收集器。见 [collector/G1.md](collector/G1.md)
- GarbageCollector（垃圾收集器）：GC 的具体实现策略组合。见 [collector/GarbageCollector.md](collector/GarbageCollector.md)
- GCOverview（GC 概述）：垃圾回收机制总览，包含 GC 周期三阶段（可达性分析、引用处理、清除/压缩）。见 [mechanism/GCOverview.md](mechanism/GCOverview.md)
- GCRoots：可达性分析的根节点集合。见 [mechanism/GCRoots.md](mechanism/GCRoots.md)
- GenerationalGC（分代收集）：按年龄分代的收集策略。见 [algorithm/GenerationalGC.md](algorithm/GenerationalGC.md)

## M
- MarkCompact（标记-整理）：标记后移动存活对象。见 [algorithm/MarkCompact.md](algorithm/MarkCompact.md)
- MarkSweep（标记-清除）：标记后清除垃圾对象。见 [algorithm/MarkSweep.md](algorithm/MarkSweep.md)

## P
- ParallelScavenge：吞吐量优先的并行收集器。见 [collector/ParallelScavenge.md](collector/ParallelScavenge.md)
- ParNew：ParNew 收集器。见 [collector/ParNew.md](collector/ParNew.md)

## R
- ReachabilityAnalysis（可达性分析）：判断对象存活的算法，包含强/软/弱/虚/不可达五级可达性判定。见 [mechanism/ReachabilityAnalysis.md](mechanism/ReachabilityAnalysis.md)
- ReferenceProcessing（引用处理）：GC 周期第二阶段，处理软/弱/虚引用的 referent 清除与 ReferenceQueue 入队。见 [mechanism/ReferenceTypes.md](mechanism/ReferenceTypes.md)
- ReferenceTypes（引用类型）：强/软/弱/虚引用及其在 GC 中的处理规则。见 [mechanism/ReferenceTypes.md](mechanism/ReferenceTypes.md)
- Region（内存区域）：堆内存的逻辑或物理划分单元。见 [structure/Region.md](structure/Region.md)
- RememberedSet（记忆集）：记录跨区域引用。见 [structure/RememberedSet.md](structure/RememberedSet.md)

## S
- SafePoint（安全点）：线程暂停执行 GC 的位置。见 [mechanism/SafePoint.md](mechanism/SafePoint.md)
- Serial：Serial 收集器。见 [collector/Serial.md](collector/Serial.md)
- Shenandoah：Shenandoah 收集器。见 [collector/Shenandoah.md](collector/Shenandoah.md)

## Z
- ZGC：Z Garbage Collector。见 [collector/ZGC.md](collector/ZGC.md)
