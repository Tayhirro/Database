# VisualVM（综合分析工具）

## 一句话
VisualVM 是一类对 JVM 进程进行可视化监控与分析的工具，常用于查看线程、堆、GC 与性能采样等信息（具体能力依版本与插件而定）。

## 严格定义
对一个 JVM 进程，VisualVM 通过可用的连接机制（本地进程附加、JMX 等）获取运行态信息并呈现为可视化视图，同时可执行实现定义的分析动作（如采样、转储触发等）。其数据来源与能力集合依工具版本、JDK/JVM 版本与插件配置而变化。

## 接口：数据 + 约束
- 输入：
  - 目标 JVM 连接信息
  - 插件与采样配置（若使用）
- 输出：
  - 可视化分析视图与可选的转储/报告产物（副作用）
- 约束：
  - 能力与数据粒度依版本与插件变化；部分分析动作会引入额外开销。
