## 总览

```
Agent
├── LLM（大语言模型）
│   ├── Architecture
│   ├── Training
│   ├── Inference
│   ├── Alignment
│   └── ...（详见 llm/概念图.md）
│
├── Memory（记忆系统）
│   ├── short-term（短期记忆）
│   │   ├── ConversationBuffer
│   │   └── SlidingWindow
│   ├── long-term（长期记忆）
│   │   ├── EpisodicMemory ← 事件记忆
│   │   ├── SemanticMemory ← 知识记忆
│   │   └── ProceduralMemory ← 技能记忆
│   ├── external（外部记忆）
│   │   ├── VectorStore
│   │   ├── KnowledgeGraph
│   │   └── Database
│   └── systems（记忆系统）
│       ├── RAG ← 检索增强
│       ├── MemGPT ← 虚拟上下文管理
│       └── EverMemOS ← 持久化记忆OS
│
├── Planning（规划与推理）
│   ├── decomposition（任务分解）
│   │   ├── ChainOfThought
│   │   ├── TreeOfThoughts
│   │   └── GraphOfThoughts
│   ├── reflection（反思）
│   │   ├── Reflexion
│   │   ├── SelfRefine
│   │   └── SelfCritique
│   └── search（搜索）
│       ├── MCTS
│       └── BeamSearch
│
├── Tool（工具使用）
│   ├── api（API 调用）
│   │   ├── WebSearch
│   │   ├── Calculator
│   │   └── ExternalAPI
│   ├── code（代码执行）
│   │   ├── CodeInterpreter
│   │   └── Sandbox
│   └── frameworks
│       ├── Toolformer
│       ├── FunctionCalling
│       └── MCP ← Model Context Protocol
│
├── Action（行动执行）
│   ├── ActorInterface
│   ├── EnvironmentInteraction
│   └── FeedbackLoop
│
├── Perception（感知）
│   ├── TextInput
│   ├── VisionInput
│   ├── AudioInput
│   └── MultimodalFusion
│
├── Multi-Agent（多智能体）
│   ├── communication（通信）
│   │   ├── MessagePassing
│   │   ├── SharedMemory
│   │   ├── MCP ← Model Context Protocol（agent→工具/数据）
│   │   └── A2A ← Agent-to-Agent（agent↔agent）
│   ├── orchestration（编排层）
│   │   ├── Planning Unit ← 任务分解与执行顺序
│   │   ├── Policy Unit ← 治理约束与合规检查
│   │   ├── Execution & Control ← 并发管理与运行时调度
│   │   ├── State & Knowledge ← 状态维护与上下文供给
│   │   └── Quality & Operations ← 结果验证与性能优化
│   ├── agent-types（智能体类型）
│   │   ├── Worker Agent ← 执行层智能体（有状态/无状态）
│   │   └── Service Agent ← 服务层智能体（QA/诊断/修复）
│   ├── coordination（协调）
│   │   ├── Hierarchical
│   │   ├── Democratic
│   │   └── MarketBased
│   └── frameworks
│       ├── MetaGPT
│       ├── CrewAI
│       ├── AutoGen
│       └── CAMEL
│
├── Evaluation（评估）
│   ├── benchmarks
│   │   ├── AgentBench
│   │   ├── SWE-bench
│   │   ├── WebArena
│   │   └── GAIA
│   └── metrics
│       ├── TaskSuccessRate
│       ├── ToolAccuracy
│       └── PlanningEfficiency
│
└── Safety（安全）
    ├── Alignment
    ├── Controllability
    ├── Sandboxing
    └── HumanInTheLoop
```

---

## 跨模块关系

| 源 | 关系 | 目标 |
|---|---|---|
| LLM | 驱动 | Planning, Tool, Action |
| Memory | 提供上下文 | LLM |
| Planning | 生成 | Action 序列 |
| Tool | 扩展 | LLM 能力 |
| Perception | 输入 | LLM |
| Action | 影响 | Environment |
| Environment | 反馈 | Perception |
| Evaluation | 评估 | Agent 整体 |
| Safety | 约束 | Agent 整体 |

## Agent Loop

```
┌────────────────────────────────────────────────┐
│                  Agent Loop                     │
│                                                 │
│   Perceive → Think → Plan → Act → Observe      │
│       ↑                              ↓         │
│       └──────── Memory ←─────────────┘         │
└────────────────────────────────────────────────┘
```
