# 术语索引（Architecture）

导航：[README.md](README.md) | [概念图.md](概念图.md)

## A
- ALiBi（Attention with Linear Biases）：将相对位置偏置直接加到注意力分数。见 [Transformer/mechanics/ALiBi.md](Transformer/mechanics/ALiBi.md)
- Attention（注意力）：通过 Query-Key 相似度加权 Value 的信息聚合机制。见 [Transformer/structure/SelfAttention.md](Transformer/structure/SelfAttention.md)

## C
- CrossAttention（交叉注意力）：Query 来自一个序列，Key/Value 来自另一个序列。见 [Transformer/structure/CrossAttention.md](Transformer/structure/CrossAttention.md)

## F
- FFN（前馈网络）：对每个 token 独立作用的非线性变换。见 [Transformer/structure/FFN.md](Transformer/structure/FFN.md)

## G
- GQA（Grouped Query Attention）：Query 头分组共享 KV 头。见 [Transformer/variants/GQA.md](Transformer/variants/GQA.md)

## L
- LayerNorm：层归一化，沿特征维度减均值除标准差。见 [Transformer/mechanics/LayerNorm.md](Transformer/mechanics/LayerNorm.md)

## M
- Mamba：选择性状态空间模型。见 [SSM/Mamba.md](SSM/Mamba.md)
- MoE（Mixture of Experts）：稀疏激活的专家混合层，通过条件计算实现超大规模参数扩展。见 [Transformer/variants/MoE.md](Transformer/variants/MoE.md)
  - MoE性能挑战：分布式训练中的四大核心挑战及解决方案。见 [Transformer/variants/MoE-性能挑战.md](Transformer/variants/MoE-性能挑战.md)
- MQA（Multi-Query Attention）：所有 Query 头共享一套 KV。见 [Transformer/variants/MQA.md](Transformer/variants/MQA.md)

## P
- PreNorm：归一化置于子层输入端。见 [Transformer/mechanics/PreNorm.md](Transformer/mechanics/PreNorm.md)

## Q
- QKNorm：对 Q、K 向量分别归一化。见 [Transformer/mechanics/QKNorm.md](Transformer/mechanics/QKNorm.md)

## R
- ResidualConnection（残差连接）：跳跃连接。见 [Transformer/structure/ResidualConnection.md](Transformer/structure/ResidualConnection.md)
- RMSNorm：只做 scale 不做 shift 的归一化。见 [Transformer/mechanics/RMSNorm.md](Transformer/mechanics/RMSNorm.md)
- RoPE（Rotary Position Embedding）：旋转位置编码。见 [Transformer/mechanics/RoPE.md](Transformer/mechanics/RoPE.md)
- RWKV：线性复杂度的 RNN-Transformer 混合架构。见 [SSM/RWKV.md](SSM/RWKV.md)

## S
- SelfAttention（自注意力）：QKV 均来自同一序列。见 [Transformer/structure/SelfAttention.md](Transformer/structure/SelfAttention.md)
- Sinusoidal Position Encoding（正弦位置编码）：Transformer 原始位置编码方案。见 [Transformer/mechanics/正弦位置编码.md](Transformer/mechanics/正弦位置编码.md)
- Sparse Computation（稀疏计算）：条件执行计算模块以提升效率，如MoE。见 [Transformer/variants/稀疏计算vs稀疏查找.md](Transformer/variants/稀疏计算vs稀疏查找.md)
- Sparse Lookup（稀疏查找）：条件读取参数表，如Embedding。见 [Transformer/variants/稀疏计算vs稀疏查找.md](Transformer/variants/稀疏计算vs稀疏查找.md)
- SSM（State Space Model）：状态空间模型。见 [SSM/SSM.md](SSM/SSM.md)
- SwiGLU：Swish + GLU 的 FFN 变体。见 [Transformer/variants/SwiGLU.md](Transformer/variants/SwiGLU.md)

## T
- Transformer：基于注意力的序列建模架构。见 [Transformer/Transformer.md](Transformer/Transformer.md)
