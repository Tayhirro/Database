# RMSNorm

## 一句话

只做一件事：**把向量的模长拉到统一大小**。不减均值、不加偏置，所以向量的方向完全不变。说白了就是 [[LayerNorm]] 的极简版——砍掉了零中心化和平移，只保留最关键的 re-scaling。

## 公式

$$
y = \gamma \cdot \frac{x}{\text{RMS}(x) + \epsilon}
$$

其中均方根（Root Mean Square）：

$$
\text{RMS}(x) = \sqrt{\frac{1}{d}\sum_{i=1}^{d} x_i^2}
$$

RMS 和向量模长之间有一个简单的关系：

$$
\text{RMS}(x) = \frac{\|x\|_2}{\sqrt{d}}
$$

所以除以 RMS，本质上就是**把向量模长缩放到 $\sqrt{d}$**。

## 接口

| 符号 | 类型 | 约束 | 说明 |
|------|------|------|------|
| $x$ | $\mathbb{R}^d$ 或 $\mathbb{R}^{B \times L \times d}$ | 任意实数 | 输入特征，沿最后一维归一化 |
| $\gamma$ | $\mathbb{R}^d$ | 可学习，初始化为 1 | 逐元素缩放 |
| $\epsilon$ | $\mathbb{R}$ | 常数，默认 $10^{-6}$ | 防止除零 |

注意：没有 $\beta$（平移参数）。参数量只有 $d$，是 [[LayerNorm]] 的一半。

---

## RMSNorm 做了什么

RMSNorm 只做一步：**re-scaling（重新定尺度）**。不做 re-centering（重新定中心）。

$$
x' = \frac{x}{\text{RMS}(x)}
$$

每个分量除以同一个标量。这个操作在数学上叫**标量除法**，它有两个非常好的几何性质。

---

### 性质一：方向完全不变

标量除法不改变向量方向。这一点可以严格证明：

$$
\frac{x}{\text{RMS}(x)} = \frac{x}{\|x\|/\sqrt{d}} = \sqrt{d} \cdot \frac{x}{\|x\|}
$$

右边就是单位向量 $\hat{x}$ 乘以常数 $\sqrt{d}$。单位向量和原向量方向一致，乘常数也不改变方向，所以：

$$
\angle\!\left(x,\; \frac{x}{\text{RMS}(x)}\right) = 0
$$

归一化前后，向量夹角为零。

#### 为什么方向不变这么重要？

**语义方向即信息。** 在 Transformer 的隐层空间里，向量的方向编码了语义。"国王"和"王后"的向量方向相近（都跟"权力"有关），但和"苹果"的方向差很远。如果归一化操作把方向改了，就相当于在语义空间里把词的位置挪了——这不是你想要的。

RMSNorm 只调模长，方向不动，所以语义信息原封不动地传下去。

**余弦相似度不变。** 对任意两个向量 $a, b$，经 RMSNorm（不含 $\gamma$）后：

$$
\cos\!\left(\frac{a}{\text{RMS}(a)},\; \frac{b}{\text{RMS}(b)}\right) = \cos(a, b)
$$

Attention 机制的核心就是算 query 和 key 之间的相似度。如果归一化操作把向量间的相对关系搅乱了，Attention 的质量就会下降。RMSNorm 不会出这个问题。

**残差连接更直接。** Transformer 的残差路径是 $\text{output} = x + f(\text{Norm}(x))$。如果 Norm 改变了方向，残差相加时两个向量的方向不对齐，加出来的结果就会"漂"。RMSNorm 只缩放模长，残差路径上的方向始终一致，信号传递更干净。

---

### 性质二：模长统一归一化

RMSNorm 把所有输入向量的模长拉到同一个值 $\sqrt{d}$：

$$
\left\|\frac{x}{\text{RMS}(x)}\right\| = \left\|\frac{x}{\|x\|/\sqrt{d}}\right\| = \sqrt{d}
$$

不管原始向量模长是 0.1 还是 1000，归一化之后都是 $\sqrt{d}$。

#### 为什么要统一模长？

**防止 scale 爆炸/消失。** 在深层网络中，隐层向量的模长会随着层数增加而不断膨胀或缩小。如果不加控制，到后面几层信号要么大到溢出（NaN），要么小到消失（梯度为零）。每一层做一次模长归一化，就像在每个路口重新校准一下信号强度，保证它始终在合理范围内。

这也是归一化操作中**最核心的部分**。RMSNorm 论文的核心观点就是：**训练稳定性主要取决于 scale 是否可控，而不是均值是否为零。只要每层输入的能量（二阶矩/RMS）保持稳定，训练就能稳定。**

**各向同性缩放。** 每个分量被同一个标量缩放，没有任何一个分量被选择性地压大或压小。在数学上这叫**相似变换**（Similarity Transform）——保持角度、保持形状，只改变整体大小。对比 [[LayerNorm]] 的仿射变换（先平移再缩放，角度和形状都会变），相似变换对原始信息的"破坏"更小。

---

## 为什么敢省掉减均值？

这是 RMSNorm 最核心的设计决策。省掉减均值不是为了偷懒，而是基于一个关键观察：

### 原因一：Scale 问题比 Mean Shift 问题更致命

在 Transformer 这种深层网络中，研究者发现训练崩溃的主因是 **scale 爆炸/消失**（信号能量越来越大或越来越小），而不是 **mean shift**（整体偏移）。

均值偏移当然不好，但它不会直接导致训练崩溃——后续的线性层 $Wx + b$ 中的 bias $b$ 可以自然地吸收掉这种偏移。而 scale 问题如果不控制，几层之后数值就会溢出或归零。

RMSNorm 的立场：**只要保证每一层输入的 RMS（能量/二阶矩）稳定，训练就能稳定。均值是否为零，不是关键。**

### 原因二：Pre-LN 架构下减均值是冗余的

在现代 LLM 普遍采用的 Pre-LN 架构中：

```
x → Norm → Attention → +x → Norm → FFN → +x
```

归一化层的输入来自残差路径，而残差路径的输入在前一层已经被归一化过了。所以到了当前层，输入已经近似零均值（$\mu \approx 0$）。这时候再做一次减均值，算出来的 $\mu$ 接近于零，减了跟没减差不多——纯粹浪费算力。

### 原因三：减完又加回来，逻辑上有冗余

[[LayerNorm]] 的完整操作是：先减均值强制归零，最后又通过 $\beta$ 加回一个可学习的偏移。如果最终还是要让网络自己学一个偏移量，那中间那步强制归零就显得多此一举。

RMSNorm 的思路：与其先减后加，不如直接保留原始均值，只做缩放。如果模型确实需要某种偏移，让下游的线性层 $Wx + b$ 中的 $b$ 去学就好了。

### 原因四：减均值有副作用

从几何上看，减均值是把向量投影到与全 1 向量 $\mathbf{1}$ 正交的超平面上（$\sum x_i' = 0$ 的子空间）。如果原始向量的信息恰好蕴含在"所有值都很大且相近"这个模式中（即与 $\mathbf{1}$ 方向对齐），减均值会不可逆地把这部分信息抹掉。

而且减均值会改变向量方向（见上面的"性质一"），破坏语义信息和余弦相似度——这些都是 RMSNorm 不愿意付出的代价。

> [!tip] 一句话总结
> RMSNorm 认为：**"保持能量恒定"比"保持零均值"更关键**。减均值的收益（消除共模漂移）抵不上它的成本（改变方向、额外计算、信息损失），特别是在 Pre-LN 架构的深层网络中。

## 几何意义

RMSNorm 执行的是**相似变换**（Similarity Transform）：

```
原始向量  →  等比缩放到统一模长
            (除以 RMS)

方向不变，形状不变，只改变大小
```

### 数值走一遍

输入 $x = [2.0, -1.0, 3.0]$，$d = 3$，$\gamma = 1$：

| 步骤 | 计算 | 结果 |
|------|------|------|
| 平方和均值 | $(4 + 1 + 9) / 3$ | $4.67$ |
| RMS | $\sqrt{4.67}$ | $2.16$ |
| 归一化 | $x / 2.16$ | $[0.93, -0.46, 1.39]$ |
| 验证模长 | $\sqrt{0.93^2 + 0.46^2 + 1.39^2}$ | $\sqrt{3} = \sqrt{d}$ |
| 验证方向 | 各分量比例 $2:-1:3$ | 不变 |

### 2D 可视化

```
原始向量 x = [3, 1]，方向角 ≈ 18.4°

RMSNorm:
  RMS = √((9+1)/2) = √5 ≈ 2.24
  x / RMS = [1.34, 0.45]
  方向角 = arctan(0.45/1.34) ≈ 18.4°  ← 方向不变
  模长 = √(1.34² + 0.45²) = √2 = √d   ← 模长归一到 √d
```

## 计算开销

```
1. 计算 x²         → O(d)   逐元素平方
2. 求和并平均       → O(d)   一次 reduce-sum
3. 开方得 RMS      → O(1)
4. 除以 RMS        → O(d)   逐元素除法
5. 乘以 γ          → O(d)   逐元素乘法
总计: ~4d 次操作
```

省掉了 [[LayerNorm]] 中"算均值"和"减均值"两步（各 $O(d)$），在大规模分布式训练中还省掉了一次跨设备的 reduce 同步。

实测（d=4096）大约有 1.6x 的加速。训练周期以月计的大模型来说，这个节省很可观。

## 实现

```python
# PyTorch 手动实现（LLaMA 风格）
class RMSNorm(nn.Module):
    def __init__(self, d: int, eps: float = 1e-6):
        super().__init__()
        self.eps = eps
        self.weight = nn.Parameter(torch.ones(d))  # γ，初始化为全 1

    def forward(self, x):
        # rsqrt = 1/sqrt，一步完成开方和除法
        norm = x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps)
        return self.weight * norm.type_as(x)
```

几个实现细节：
- `rsqrt` 比先 `sqrt` 再除法快，少一次浮点运算
- `.type_as(x)` 保证半精度（fp16/bf16）训练时类型一致
- 没有 `bias` 参数，构造函数里也不需要

## 实验结论

来自原始论文（"Root Mean Square Layer Normalization", NeurIPS 2019 Workshop）：

- 在 Transformer 上和 [[LayerNorm]] 对比，**收敛速度和最终性能相当**
- 训练速度快约 7-15%
- 内存占用减少约 5-10%
- 在深层 Post-LN 结构中，RMSNorm 有时甚至**更稳定**（因为没有均值操作引入的额外方差）

这个结论后来被 LLaMA、PaLM、Mistral 等大模型的实践反复验证，RMSNorm 已经成为现代 LLM 的事实标准。

## 优势与局限

### 优势

- **方向保持**：不改变向量方向，语义信息和余弦相似度不受影响
- **计算高效**：省掉均值计算和减法，约 1.6x 加速
- **参数精简**：只有 $\gamma$，参数量减半
- **训练稳定**：梯度路径更短，不需要经过 $\mu$ 和 $\sigma^2$ 的链式法则
- **假设合理**：在 Pre-LN 架构中，输入已近似零均值，省掉减均值几乎无损

### 局限

- **依赖零均值假设**：如果输入的均值偏移确实很大（比如浅层网络、Post-LN 架构），不减均值可能导致归一化不充分
- **没有平移自由度**：没有 $\beta$ 参数，表达能力理论上弱于 [[LayerNorm]]（但实践中这个差异可以被下游线性层补偿）
- **不适合所有架构**：在 CNN、RNN 等非 Transformer 结构中，输入分布不一定满足零均值假设

## 适用场景

| 场景 | 原因 |
|------|------|
| Transformer Decoder（GPT/LLaMA） | Pre-LN 架构，输入已归一化，减均值冗余 |
| 大规模训练（>1B 参数） | 计算和内存节省在大规模下非常显著 |
| 需要保留语义方向 | 不改变向量方向 |
| 对训练速度敏感 | 约 1.6x 加速 |
