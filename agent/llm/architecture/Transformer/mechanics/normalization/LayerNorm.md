# LayerNorm

## 一句话

对每个样本的特征向量做**零中心化 + 方差归一化**，再通过可学习的 $\gamma$（缩放）和 $\beta$（平移）恢复表达能力。核心思想是：先把分布"拉正"（均值→0，方差→1），再让网络自己学该怎么调回去。

## 公式

$$
y = \gamma \cdot \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta
$$

其中：
- $\mu = \frac{1}{d}\sum_{i=1}^d x_i$（特征维度上的均值）
- $\sigma^2 = \frac{1}{d}\sum_{i=1}^d (x_i - \mu)^2$（特征维度上的方差）
- $\gamma, \beta \in \mathbb{R}^d$（可学习参数）
- $\epsilon$（防止除零的小常数，默认 $10^{-5}$）

## 接口

| 符号 | 类型 | 约束 | 说明 |
|------|------|------|------|
| $x$ | $\mathbb{R}^d$ 或 $\mathbb{R}^{B \times L \times d}$ | 任意实数 | 输入特征，沿最后一维归一化 |
| $\gamma$ | $\mathbb{R}^d$ | 可学习，初始化为 1 | 逐元素缩放 |
| $\beta$ | $\mathbb{R}^d$ | 可学习，初始化为 0 | 逐元素平移（偏置） |
| $\epsilon$ | $\mathbb{R}$ | 常数，默认 $10^{-5}$ | 数值稳定性 |

---

## LayerNorm 做了什么

LayerNorm 本质上做了两件事：**re-centering（重新定中心）** 和 **re-scaling（重新定尺度）**。下面逐步拆解。

### 第一步：零中心化（Zero-centering）

$$
x' = x - \mu = x - \bar{x}\mathbf{1}
$$

减去均值，把分布的中心拉到零点。这一步在统计学里叫 **"去均值"** 或 **"中心化"**。

#### 零中心化在干什么？

**1. 消除"共模漂移"（Common Mode Shift）**

如果前一层的输出整体偏了——比如所有维度同时偏大了 +5——减均值能把这种"集体偏移"一次性抹掉。不管输入整体偏到哪里去了，减完均值之后分布中心一定回到零点。

**2. 稳定方差计算**

方差的定义本身就依赖均值：$\sigma^2 = \frac{1}{d}\sum(x_i - \bar{x})^2$。如果不先减均值就直接算二阶矩 $\frac{1}{d}\sum x_i^2$，那算出来的不是方差，而是**包含了均值平方的二阶矩**。零中心化保证了后续的方差计算是"纯粹的离散程度"，不混入位置信息。

**3. 有利于梯度流动**

零均值的数据分布通常具有更好的对称性。对于激活函数（特别是 tanh、GELU 这类关于原点近似对称的函数），零中心的输入能让梯度在正负方向上更均匀，避免梯度始终偏向一个方向。

#### 零中心化的几何含义

从几何上看，减均值是把向量 $x$ **投影到与全 1 向量 $\mathbf{1}$ 正交的超平面上**：

$$
x' = x - \bar{x}\mathbf{1} \quad \Rightarrow \quad \sum_i x'_i = 0
$$

归一化后的向量一定满足各分量之和为零，也就是说它被限制在了一个 $(d-1)$ 维的子空间里。这意味着：
- 如果原始 $x$ 的信息主要蕴含在"所有值都很大且相近"这个模式中（即与 $\mathbf{1}$ 方向对齐），减均值会把这部分信息抹掉
- 向量的方向会发生改变——这是减均值**不可避免的副作用**

> [!note] 方向改变的直观例子
> 输入 $x = [3, 1]$，方向角约 $18°$。
> 减均值：$x - \mu = [3, 1] - 2 = [1, -1]$，方向角变成了 $-45°$。
> 方向从第一象限跑到了第四象限——这不是微调，是质变。

#### 零中心化的代价与争议

减均值并非"免费午餐"，它有明确的代价：

**计算成本**：需要额外一次 $O(d)$ 的求和（算均值）和一次 $O(d)$ 的减法。在大规模分布式训练（张量并行）中，这意味着多一次跨设备的 reduce 同步。

**信息损失**：把向量投影到 $\sum x_i = 0$ 的子空间，丢掉了沿 $\mathbf{1}$ 方向的分量。如果这个分量携带有用信息，那就是不可逆的损失。

**"先减后加"的矛盾**：LayerNorm 先减均值强制归零，最后又通过 $\beta$ 加回一个可学习的偏移。既然最终还是要平移，中间那步强制归零是否多此一举？这也是后来 [[RMSNorm]] 省掉减均值步骤的动机之一。

> [!tip] 什么时候零中心化真正有用？
> 当输入的共模漂移确实很大、且不可预测时（比如网络浅层、输入分布不稳定、Post-LN 架构），零中心化能有效"兜底"。但在深层 Pre-LN 架构中，前一层的归一化已经让输入近似零均值了，再做一次就比较冗余。

---

### 第二步：方差归一化（Re-scaling）

$$
x'' = \frac{x'}{\sqrt{\sigma^2 + \epsilon}}
$$

除以标准差，把分布的"宽度"压缩到单位尺度。

这一步解决的是 **scale 问题**：不同特征维度的数值范围可能差异很大（有的在 $[-100, 100]$，有的在 $[-0.01, 0.01]$），除以标准差后所有维度被拉到同一尺度，后续的权重矩阵不需要额外学习尺度适配。

归一化之后：
- 输出均值为 0（零中心化保证）
- 输出方差为 1（方差归一化保证）
- 分布被"标准化"到了 $\mathcal{N}(0, 1)$ 附近（如果原始分布近似高斯）

> [!important] Scale 稳定是训练稳定的关键
> 在深层网络中，**信号能量逐层爆炸或消失**才是训练崩溃的主因。方差归一化直接控制了每一层输出的能量水平，是归一化操作中最核心的部分。

---

### 第三步：可学习仿射变换

$$
y = \gamma \cdot x'' + \beta
$$

前两步把分布强行压成了标准化形状，但这可能"过度约束"了网络——也许某些层就是需要非零均值或非单位方差的输出。所以 LayerNorm 加了两组可学习参数：

- **$\gamma$（缩放）**：让网络自己决定每个特征维度需要多大的"尺度"
- **$\beta$（平移）**：让网络自己决定每个特征维度需要多大的"偏移"

这等于是说：我先帮你把分布标准化了，具体要怎么调，你自己学。

**参数量**：$2d$（$\gamma$ 和 $\beta$ 各 $d$ 维）。

---

## 几何意义

LayerNorm 整体执行的是一个**仿射变换**（Affine Transform）：

```
原始空间 → 投影到零均值子空间 → 缩放到单位方差 → 仿射变换到新位置
         (减 μ)                (除 σ)            (γ·x + β)
```

- **改变了向量方向**（减均值 = 向量减法）
- **改变了向量模长**（除以标准差 + 乘 $\gamma$）
- 相当于对特征空间做了一次坐标系变换

### 数值走一遍

输入 $x = [2.0, -1.0, 3.0]$，$d = 3$，假设 $\gamma = 1, \beta = 0$：

| 步骤 | 计算 | 结果 |
|------|------|------|
| 均值 | $(2 - 1 + 3) / 3$ | $\mu = 1.33$ |
| 中心化 | $x - 1.33$ | $[0.67, -2.33, 1.67]$ |
| 方差 | $(0.67^2 + 2.33^2 + 1.67^2) / 3$ | $\sigma^2 = 2.89$ |
| 标准差 | $\sqrt{2.89}$ | $\sigma = 1.70$ |
| 归一化 | 中心化结果 $/\ \sigma$ | $[0.39, -1.37, 0.98]$ |

可以验证：输出均值 $\approx 0$，方差 $\approx 1$。

---

## 计算开销

```
1. 计算均值 μ       → O(d)   一次 reduce-sum
2. 减均值 x - μ     → O(d)   逐元素减法
3. 计算方差 σ²      → O(d)   一次 reduce-sum
4. 除以标准差       → O(d)   逐元素除法
5. 仿射变换 γx + β  → O(d)   逐元素乘加
总计: ~5d 次操作
```

其中步骤 1 和 2 是 [[RMSNorm]] 省掉的部分。

## 实现

```python
# PyTorch 内置
layer_norm = nn.LayerNorm(d, eps=1e-5)

# 等价手动实现
def layer_norm(x, gamma, beta, eps=1e-5):
    mu = x.mean(-1, keepdim=True)
    sigma = x.std(-1, keepdim=True, unbiased=False)
    return gamma * (x - mu) / (sigma + eps) + beta
```

## 优势与局限

### 优势

- **鲁棒性强**：不管输入分布偏到哪里、尺度多大，都能拉回标准化状态。对于分布不稳定的场景（浅层网络、Post-LN 架构、非 Transformer 结构）特别可靠
- **表达能力完整**：$\gamma + \beta$ 提供了完整的仿射自由度，理论上可以恢复任意均值和方差
- **经典验证充分**：从 2016 年提出至今，在 BERT、GPT-2、ViT 等大量模型中得到验证

### 局限

- **计算冗余**：在 Pre-LN 架构的深层中，输入已经近似零均值，减均值接近空操作，但仍然消耗计算
- **方向改变**：减均值改变了向量方向，对于依赖方向信息的下游操作（如 Attention 中的余弦相似度）可能不理想
- **"先减后加"的冗余**：先强制归零（$-\mu$），最后又加回偏移（$+\beta$），存在逻辑上的重复

## 适用场景

| 场景 | 原因 |
|------|------|
| Transformer Encoder（BERT） | 经典选择，充分验证 |
| Post-LN 架构 | 输入未经归一化，需要完整的零中心化 |
| 输入分布偏移较大 | 零中心化能有效消除共模漂移 |
| 需要平移自由度 | $\beta$ 提供额外表达能力 |
| CNN / RNN | 输入不一定零均值，需要完整归一化 |
| 浅层网络 | 分布不稳定，零中心化的"兜底"作用更明显 |
