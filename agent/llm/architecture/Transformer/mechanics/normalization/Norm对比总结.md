## 一、核心区别速览

| 操作 | LayerNorm | RMSNorm |
|------|-----------|---------|
| 减均值（零中心化） | 做 | **不做** |
| 除以尺度量（方差/RMS） | 做 | 做 |
| 可学习缩放 $\gamma$ | 有 | 有 |
| 可学习平移 $\beta$ | 有 | **没有** |
| 归一化维度 | 特征维 | 特征维 |

%% 新增方法时追加列 %%

一句话：**LayerNorm 做"平移 + 缩放"（re-centering + re-scaling），RMSNorm 只做"纯缩放"（re-scaling only）。**

---

## 二、公式对比

### LayerNorm

$$
y = \gamma \cdot \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta
$$

### RMSNorm

$$
y = \gamma \cdot \frac{x}{\text{RMS}(x) + \epsilon}, \quad \text{RMS}(x) = \sqrt{\frac{1}{d}\sum x_i^2}
$$

%% 未来新增方法的公式在此追加 %%

### 组件分解

| 组件 | LayerNorm | RMSNorm |
|------|-----------|---------|
| 中心化（减均值） | $\mu = \frac{1}{d}\sum x_i$ | **无** |
| 缩放分母 | $\sqrt{\sigma^2 + \epsilon}$（标准差） | $\sqrt{\frac{1}{d}\sum x_i^2 + \epsilon}$（RMS） |
| 可学习缩放 | $\gamma$ | $\gamma$ |
| 可学习平移 | $\beta$ | **无** |

%% 新增方法时追加列 %%

注意 LayerNorm 用的是**方差**（二阶中心矩，减过均值的），RMSNorm 用的是**二阶原点矩**（没减均值的）。两者的关系是：

$$\text{Var}(x) = \text{E}[x^2] - (\text{E}[x])^2$$

当均值 $\mu \approx 0$ 时，方差 $\approx$ 二阶矩，两个分母几乎一样——这也是为什么在 Pre-LN 架构中两者效果差不多。

---

## 三、几何意义对比

这是各方法**最本质的区别**，也是最值得理解的部分。

### LayerNorm — 仿射变换（Affine Transform）

```
原始向量  →  投影到零均值子空间  →  缩放到单位方差  →  仿射到新位置
            (减 μ，方向改变)       (除 σ)             (γ·x + β)
```

- **改变方向**：减均值是向量减法，方向必然偏移
- **改变模长**：除标准差后再乘 $\gamma$
- 相当于**坐标系变换**——整个空间被搬了家

### RMSNorm — 相似变换（Similarity Transform）

```
原始向量  →  等比缩放到统一模长
            (除以 RMS，所有分量除以同一个标量)
```

- **保持方向**：标量除法，归一化前后夹角为零
- **归一化模长**：所有向量模长统一为 $\sqrt{d}$
- 相当于**各向同性缩放**——只调大小，不动方向

%% 未来新增方法的几何意义在此追加 %%

### 2D 可视化

输入 $x = [3, 1]$，方向角 $\approx 18.4°$：

```
LayerNorm:
  x - μ = [3,1] - 2 = [1, -1]
  方向角: arctan(-1/1) = -45°      ← 从 18° 变成 -45°，质变！

RMSNorm:
  x / RMS = [3,1] / √5 = [1.34, 0.45]
  方向角: arctan(0.45/1.34) ≈ 18.4° ← 方向不变
  模长: √(1.34² + 0.45²) = √2 = √d  ← 模长归一化到 √d
```

> [!important] 核心区别
> LayerNorm **改变方向**（仿射变换），RMSNorm **保持方向**（相似变换）。
> 在语义空间中，方向代表含义，模长代表强度。RMSNorm 只调强度不动含义。

## 四、计算开销对比

| 步骤 | LayerNorm | RMSNorm |
|------|-----------|---------|
| 算均值 $\mu$ | $O(d)$（一次 reduce） | 不需要 |
| 减均值 $x - \mu$ | $O(d)$ | 不需要 |
| 算方差/RMS | $O(d)$ | $O(d)$ |
| 除以标准差/RMS | $O(d)$ | $O(d)$ |
| 仿射变换 $\gamma x + \beta$ / 缩放 $\gamma x$ | $O(d)$ | $O(d)$ |
| **总操作** | ~$5d$ | ~$4d$ |
| **实测耗时**（d=4096） | ~12.5 μs | ~7.8 μs |
| **相对速度** | 1x | **~1.6x** |

%% 新增方法时追加列 %%

在大规模分布式训练（张量并行）中，省掉一次 reduce-mean 还额外省了一次**跨设备同步**，实际收益比纯计算量差异更大。训练周期以月计的大模型来说，这个节省很可观。

## 五、参数量对比

| 参数 | LayerNorm | RMSNorm |
|------|-----------|---------|
| 缩放 $\gamma$ | $d$ | $d$ |
| 平移 $\beta$ | $d$ | **0** |
| **总参数** | $2d$ | $d$ |

%% 新增方法时追加列 %%

实际影响（以 d=4096 为例）：

| 模型规模 | LayerNorm 参数 | RMSNorm 参数 | 节省 |
|----------|----------------|--------------|------|
| 7B（32层） | 262,144 | 131,072 | 50% |
| 70B（80层） | 655,360 | 327,680 | 50% |

参数量的节省在总参数量面前可以忽略不计（7B 模型省 13 万个参数），但少一组参数意味着少一条梯度路径，对训练稳定性有间接好处。

---

## 六、训练稳定性对比

| 维度 | LayerNorm | RMSNorm |
|------|-----------|---------|
| 梯度路径 | 经过 $\mu$ 和 $\sigma^2$ 的链式法则，路径较长 | 只经过 RMS，路径更短更直接 |
| 自由度 | $\gamma + \beta$（2d 参数），更大的调节空间 | 仅 $\gamma$（d 参数），更少的爆炸风险 |
| 零均值假设 | 不需要——显式减均值保证 | 需要——假设输入已近似零均值 |
| 实验结果 | 基线 | 训练速度快 7-15%，性能相当或更优 |

%% 新增方法时追加列 %%

RMSNorm 论文（NeurIPS 2019 Workshop）的实验结论：在 Transformer 上两者收敛速度和最终性能相当，但 RMSNorm 训练更快、内存更省。在深层 Post-LN 结构中，RMSNorm 有时甚至更稳定——因为没有均值操作引入的额外方差。

---

## 七、适用场景对比

| 场景 | 推荐 | 原因 |
|------|------|------|
| **Transformer Decoder**（GPT/LLaMA） | **RMSNorm** | Pre-LN 架构，输入已归一化，减均值是冗余计算 |
| **大规模训练**（>1B 参数） | **RMSNorm** | 计算/内存节省在大规模下收益显著 |
| **需要保留语义方向** | **RMSNorm** | 不改变向量方向，余弦相似度不变 |
| Transformer Encoder（BERT） | 两者均可 | RMSNorm 更快，LayerNorm 更经典 |
| 输入分布偏移较大 / Post-LN | **LayerNorm** | 需要零中心化来消除共模漂移 |
| 需要平移自由度 | **LayerNorm** | $\beta$ 提供额外表达能力 |
| CNN / RNN | **LayerNorm** | 输入不一定零均值，需要完整归一化 |
| 浅层网络 | **LayerNorm** | 分布不稳定，零中心化的"兜底"作用更明显 |

### 专题 A：要不要减均值（Zero-centering）

**涉及方法**：[[LayerNorm]]（做）、[[RMSNorm]]（不做）
%% 新增方法涉及此问题时，在此追加"涉及方法" %%
%% 例如 BatchNorm 也减均值，可以追加讨论它的减均值和 LayerNorm 有何不同 %%

#### 减均值在干什么

减均值的统计学术语叫**零中心化（Zero-centering）**：$x' = x - \bar{x}\mathbf{1}$

它的作用：
- **消除共模漂移**：如果前一层的输出整体偏了（比如所有维度同时 +5），减均值能一刀把这个"集体偏移"砍掉
- **稳定方差计算**：标准差的定义本身就需要先减均值，不减的话算出来的是二阶矩而不是方差
- **有利于梯度流动**：零均值的分布更对称，梯度不容易一直偏向正或负

#### 为什么 RMSNorm 省掉了这一步

**原因 A：Scale 问题才是训练崩溃的主因，Mean Shift 不是。**

在深层 Transformer 中，训练崩溃通常是因为信号能量（scale）逐层爆炸或消失，而不是因为均值偏了。均值偏移虽然不好，但后续线性层 $Wx + b$ 中的 bias $b$ 可以自然吸收掉这种偏移。RMSNorm 论文的核心观点：**只要保证每一层输入的 RMS（能量）稳定，训练就能稳定。均值是否为零，不关键。**

**原因 B：Pre-LN 架构下减均值接近空操作。**

```
Pre-LN 架构:
x → Norm → Attention → +x → Norm → FFN → +x
           ↑                        ↑
     前一层已经归一化过了，输入近似零均值
     再算一次均值 → μ ≈ 0 → 减了跟没减差不多
```

在 Pre-LN 架构中，归一化层的输入来自残差路径，已经被前一层归一化过。此时 $\mu \approx 0$，减均值就是花 $O(d)$ 的计算做一次"约等于零"的减法——纯粹浪费算力。

**原因 C：先减后加，逻辑上有冗余。**

LayerNorm 先减均值强制归零（$-\mu$），最后又通过 $\beta$ 加回一个可学习偏移（$+\beta$）。既然最终还要让网络自己学一个偏移量，中间那步强制归零就显得多此一举。不如像 RMSNorm 一样直接保留原始均值，让下游线性层的 bias 去学偏移。

**原因 D：减均值有副作用。**

从几何上看，减均值是把向量投影到与全 1 向量 $\mathbf{1}$ 正交的超平面上（$\sum x_i' = 0$ 的子空间）。这会：
- 改变向量方向（见上面的几何对比）
- 丢失沿 $\mathbf{1}$ 方向的信息（如果原始向量的"所有值都很大且相近"这个模式携带了有用信息，减均值会不可逆地抹掉它）

> [!tip] 总结
> RMSNorm 认为：**"保持能量恒定"比"保持零均值"更关键**，减均值的收益（消除共模漂移）抵不上它的成本（改方向、丢信息、费算力），尤其是在 Pre-LN 架构的深层网络中。
