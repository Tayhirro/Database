## 一、公式对比

### LayerNorm

$$
y = \gamma \cdot \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta
$$

### RMSNorm

$$
y = \gamma \cdot \frac{x}{\text{RMS}(x) + \epsilon}, \quad \text{RMS}(x) = \sqrt{\frac{1}{d}\sum x_i^2}
$$

%% 未来新增方法的公式在此追加 %%

### 组件分解对比

| 组件       | LayerNorm                    | RMSNorm                                   |
| -------- | ---------------------------- | ----------------------------------------- |
| 中心化（减均值） | $\mu = \frac{1}{d}\sum x_i$  | **无**                                     |
| 缩放分母     | $\sqrt{\sigma^2 + \epsilon}$ | $\sqrt{\frac{1}{d}\sum x_i^2 + \epsilon}$ |
| 可学习缩放    | $\gamma$                     | $\gamma$                                  |
| 可学习平移    | $\beta$                      | **无**                                     |
|          |                              |                                           |

## 二、几何意义对比

这是各方法**最本质的区别**。

### LayerNorm — 仿射变换（Affine Transform）

```
原始向量  →  平移到原点  →  缩放到单位方差  →  平移到新位置
            (减 μ)         (除 σ)             (加 β)
```

- **改变方向**：减均值是向量减法，方向发生偏移
- **改变模长**：除以标准差后再缩放
- 等价于坐标系变换

### RMSNorm — 相似变换（Similarity Transform）

```
原始向量  →  等比缩放到统一模长
            (除以 RMS)
```

- **保持方向**：标量除法，夹角为零
- **归一化模长**：所有向量模长统一为 $\sqrt{d}$
- 等价于各向同性缩放（Isotropic Scaling）

%% 未来新增方法的几何意义在此追加 %%

### 2D 可视化对比

输入向量 $x = [3, 1]$，方向角 $\approx 18.4°$：

```
LayerNorm:
  x - μ = [3,1] - 2 = [1, -1]
  方向角: arctan(-1/1) = -45°      ← 方向从 18° 变为 -45°

RMSNorm:
  x / RMS = [3,1] / √5 = [1.34, 0.45]
  方向角: arctan(0.45/1.34) ≈ 18.4° ← 方向不变
  模长: √(1.34² + 0.45²) = √2 = √d  ← 模长归一化
```

> [!important] 核心区别
> - LayerNorm **改变方向**（仿射变换）
> - RMSNorm **保持方向**（相似变换），只调整模长

## 三、计算开销对比

| 指标 | LayerNorm | RMSNorm |
|------|-----------|---------|
| 计算均值 | $O(d)$ | - |
| 减均值 | $O(d)$ | - |
| 计算方差/RMS | $O(d)$ | $O(d)$ |
| 除以标准差/RMS | $O(d)$ | $O(d)$ |
| 缩放 + 平移 | $O(d)$ | $O(d)$（仅缩放） |
| **总操作数** | ~$5d$ | ~$4d$ |
| **实测耗时**（d=4096） | ~12.5 μs | ~7.8 μs |
| **相对速度** | 1x | **~1.6x** |

## 四、参数量对比

| 参数 | LayerNorm | RMSNorm |
|------|-----------|---------|
| 缩放 $\gamma$ | $d$ | $d$ |
| 平移 $\beta$ | $d$ | **0** |
| **总参数** | $2d$ | $d$ |

## 五、训练稳定性对比

| 维度 | LayerNorm | RMSNorm |
|------|-----------|---------|
| 梯度路径 | 经过 $\mu$ 和 $\sigma^2$ 的链式法则 | 只经过 RMS，路径更短 |
| 自由度 | $\gamma + \beta$，更多可调参数 | 仅 $\gamma$，减少梯度爆炸风险 |
| 零均值假设 | 不需要（显式减均值） | 需要（假设输入近似零均值） |
| 实验结果 | 基线 | 训练速度快 7-15%，性能相当或更优 |

## 六、适用场景对比

| 场景 | 推荐方法 | 原因 |
|------|----------|------|
| **Transformer Decoder**（GPT/LLaMA） | **RMSNorm** | Pre-LN 架构，输入已归一化，减均值冗余 |
| **大规模训练**（>1B 参数） | **RMSNorm** | 计算/内存节省在大规模下收益显著 |
| **需要保留语义方向** | **RMSNorm** | 不改变向量方向 |
| Transformer Encoder（BERT） | 两者均可 | RMSNorm 更快，LayerNorm 更经典 |
| 输入分布偏移较大 | **LayerNorm** | 需要中心化消除偏移 |
| 需要平移自由度 | **LayerNorm** | $\beta$ 提供额外表达能力 |
| CNN / RNN | **LayerNorm** | 输入不一定零均值 |

## 核心记忆

```
┌─────────────────────────────────────────────────┐
│  RMSNorm = LayerNorm − μ − β                   │
│                                                  │
│  LayerNorm: 仿射变换 → 改方向 + 改模长           │
│  RMSNorm:   相似变换 → 保方向 + 归一化模长       │
│                                                  │
│  现代 LLM（Pre-LN）→ RMSNorm 是默认选择         │
└─────────────────────────────────────────────────┘
```
