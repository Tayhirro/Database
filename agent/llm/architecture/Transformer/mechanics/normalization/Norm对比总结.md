# LayerNorm vs RMSNorm 核心对比

## 一句话总结

- **LayerNorm**: 减均值 + 除标准差 + 缩放 + 平移（改变方向）
- **RMSNorm**: 只除以 RMS + 缩放（保持方向，只调整模长）

---

## 核心公式对比

### LayerNorm
```
y = γ · (x - μ) / √(σ² + ε) + β

其中:
μ = mean(x)     ← 减去均值（改变方向！）
σ² = var(x)     ← 方差
```

### RMSNorm
```
y = γ · x / RMS(x)

其中:
RMS(x) = √(mean(x²))  ← 只计算模长，不减均值
```

---

## RMSNorm 五大优势

### 1. ✅ 计算效率更高（省 40% 计算）

| 操作        | LayerNorm | RMSNorm   |
| --------- | --------- | --------- |
| 计算均值 μ    | ✓         | ✗         |
| 减去均值      | ✓         | ✗         |
| 计算方差 σ²   | ✓         | ✗         |
| 计算 RMS    | ✗         | ✓         |
| 除以标准差/RMS | ✓         | ✓         |
| **总操作数**  | 5d        | 3d        |
| **加速比**   | 1x        | **~1.6x** |
|           |           |           |

---

### 2. ✅ 保持向量方向（最重要！）

**LayerNorm（改变方向）**：
```
输入:  [3, 1]  (方向: 18°)
       ↓
减均值: [1, -1]  (方向: -45°)  ← 方向变了！
       ↓
输出:  归一化后
```

**RMSNorm（保持方向）**：
```
输入:  [3, 1]  (方向: 18°)
       ↓
除RMS: [0.95, 0.32]  (方向: 18°)  ← 方向不变！
       ↓
输出:  只缩放了模长
```

**为什么重要？**
- 保留**语义方向**（词向量的方向代表语义）
- **残差连接更稳定**（方向不偏移）
- **各向同性缩放**（数学上更优雅）

---

### 3. ✅ 参数更少（节省 50%）

| 参数 | LayerNorm | RMSNorm | 节省 |
|------|-----------|---------|------|
| 缩放 γ | d 维 | d 维 | 0 |
| 平移 β | d 维 | **无** | d 维 |
| **总计** | 2d | d | **50%** |

**实际例子（LLaMA-7B）**：
- d=4096，32 层
- LayerNorm: 2×4096×32 = 262,144 参数
- RMSNorm:  1×4096×32 = 131,072 参数
- **节省**: 131,072 参数

---

### 4. ✅ 训练更稳定

**原因**：
1. 无平移项 β → 减少梯度爆炸风险
2. 梯度路径更简单（不经过 μ 和 σ²）
3. 假设合理（Pre-LN 架构中，输入已近似零均值）

**实验结果**：
- 训练速度: 快 7-15%
- 模型性能: 与 LayerNorm 相当或更好
- 内存占用: 减少 5-10%

---

### 5. ✅ 适合现代 LLM

**为什么 GPT、LLaMA 都用 RMSNorm？**

1. **Pre-LN 架构**：
   ```
   x → LN → Attention → +x → LN → FFN → +x
               ↑                    ↑
          输入已归一化，再减均值是冗余的！
   ```

2. **大模型训练效率**：
   - GPT-3: 1750 亿参数，每步省 40% = 巨大加速
   - 训练数周到数月，每一点优化都关键

---

## 几何直观理解

### LayerNorm（仿射变换）
```
原始空间 → 平移到原点 → 缩放 → 平移到新位置
         (减均值)     (除σ)    (加β)
         
结果: 改变了坐标系，方向和位置都变了
```

### RMSNorm（相似变换）
```
原始空间 → 缩放
         (除RMS)
         
结果: 只调整大小，方向和相对位置不变
```

---

## 何时用哪个？

| 场景 | 推荐 | 原因 |
|------|------|------|
| **Transformer Decoder** (GPT/LLaMA) | **RMSNorm** | Pre-LN，输入已归一化 |
| **训练速度敏感** | **RMSNorm** | 省 40% 计算 |
| **需要保留语义方向** | **RMSNorm** | 不改变向量方向 |
| Transformer Encoder (BERT) | 两者都可 | RMSNorm 更快 |
| 输入分布不确定 | LayerNorm | 需要平移自由度 |

## 你的理解修正

### ✅ 正确的部分
1. **省计算力** - 正确！省约 40%
2. **RMSNorm 不改变方向** - 正确！

### ⚠️ 需要修正的部分
你说："LayerNorm 规范化了方向和长度"

**更准确的说法**：
- **LayerNorm**: **改变**方向（因为减均值），然后归一化
- **RMSNorm**: **保持**方向，只归一化长度

### 📌 关键理解
```
LayerNorm:  平移（改方向）+ 缩放（改长度）
RMSNorm:   只缩放（改长度），方向不变
```

**类比**：
- LayerNorm 像"移动并缩放向量"（仿射变换）
- RMSNorm 像"只缩放向量"（相似变换）
