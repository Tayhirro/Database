# Transformer 常见问题解答

## Q1: Q、K、V 到底是什么？怎么来的？

### 简单回答
- **Q (Query)**: 从输入 X 乘以权重矩阵 WQ 得到
- **K (Key)**: 从输入 X 乘以权重矩阵 WK 得到
- **V (Value)**: 从输入 X 乘以权重矩阵 WV 得到

```python
# 伪代码
Q = X @ WQ  # @ 表示矩阵乘法
K = X @ WK
V = X @ WV
```

### 类比理解
想象你在图书馆找书：
- **Q (Query)**: "我想找关于机器学习的书" ← 你的搜索请求
- **K (Key)**: 每本书的标签（"机器学习"、"深度学习"、"小说"）
- **V (Value)**: 每本书的实际内容

计算过程：
1. 你的 Query 和每本书的 Key 匹配，算出相关性分数
2. 用 Softmax 把分数转为概率（哪本书最相关）
3. 根据概率加权取书的 Value（内容）

## Q2: 为什么要 Q·K^T，而不是直接 Q·K？

### 维度问题

假设：
- Q 的维度：[seq_len, d_k]  例如 [5, 64]
- K 的维度：[seq_len, d_k]  例如 [5, 64]

如果直接 Q·K：
```
[5, 64] · [5, 64] = 无法计算！（维度不匹配）
```

转置后 Q·K^T：
```
[5, 64] · [64, 5] = [5, 5]  ✓ 正确！
```

### 结果含义

```
Q·K^T 的结果 [5, 5] 表示：
     词1  词2  词3  词4  词5
词1 [分数 分数 分数 分数 分数]  ← 词1对所有词的注意力
词2 [分数 分数 分数 分数 分数]  ← 词2对所有词的注意力
词3 [分数 分数 分数 分数 分数]
词4 [分数 分数 分数 分数 分数]
词5 [分数 分数 分数 分数 分数]
```

## Q3: 为什么要除以 √dk？

### 问题：不除以的话会怎样？

假设 d_k = 64，Q 和 K 的元素都是标准正态分布（均值0，方差1）：
- Q·K^T 的每个元素 ≈ 64 个随机数相乘累加
- 方差会变成 64 倍！
- 数值可能变得非常大（例如 50、100）

### Softmax 对大数值敏感

```python
import numpy as np

# 小数值
scores_small = [1, 2, 3]
softmax_small = [0.09, 0.24, 0.67]  # 差异较小

# 大数值（未缩放）
scores_large = [50, 100, 150]
softmax_large = [0.00, 0.00, 1.00]  # 梯度几乎为0！
```

除以 √dk 后：
```
scores_scaled = [50/8, 100/8, 150/8] = [6.25, 12.5, 18.75]
softmax_scaled = [0.0001, 0.0067, 0.9932]  # 梯度正常
```

### 总结
- 缩放防止 Softmax 饱和
- 保持梯度健康
- 训练更稳定

## Q4: 残差连接（Residual Connection）有什么用？

### 没有残差连接的问题

```
输入 X (例如: [1, 2, 3])
   ↓
层1 (例如: 变成 [0.5, 0.8, 1.2])
   ↓
层2 (例如: 变成 [0.3, 0.4, 0.6])
   ↓
层3 (例如: 变成 [0.1, 0.1, 0.2])  ← 信息逐渐丢失！
```

### 有残差连接

```
输入 X = [1, 2, 3]
   ↓
层1 输出 [0.5, 0.8, 1.2]
   ↓
X + 层1输出 = [1.5, 2.8, 4.2]  ← 原始信息保留！
   ↓
层2...
```

### 梯度传播

没有残差：
```
梯度需要经过：输出 → 层N → ... → 层2 → 层1 → 输入
每层都会衰减，可能变成 0
```

有残差：
```
梯度可以直接跳过：输出 → +（直通） → 输入
梯度至少有一条通畅的路径
```

## Q5: LayerNorm 和 BatchNorm 有什么区别？

### BatchNorm（在 CNN 中常用）

```
对每个特征，在批次维度上归一化

例如批次大小=3，特征维度=2：
   特征1  特征2
样本1 [1.0,  2.0]
样本2 [2.0,  4.0]
样本3 [3.0,  6.0]
         ↓ BatchNorm
对特征1归一化: mean([1, 2, 3]) = 2
对特征2归一化: mean([2, 4, 6]) = 4
```

### LayerNorm（在 Transformer 中常用）

```
对每个样本，在特征维度上归一化

   特征1  特征2  特征3
样本1 [1.0,  2.0,  3.0]  → 归一化这3个特征
样本2 [2.0,  4.0,  6.0]  → 归一化这3个特征
```

### 为什么 Transformer 用 LayerNorm？

1. **序列长度可变**：不同句子长度不同，BatchNorm 不适合
2. **独立性**：每个样本独立归一化，不依赖其他样本
3. **实验证明效果好**

## Q6: Multi-Head Attention 为什么比 Single-Head 好？

### 类比理解

Single-Head（单头）：
```
用一个视角看问题
例如：只看语法关系
```

Multi-Head（多头）：
```
用多个视角看问题
- Head 1: 看语法关系（主谓宾）
- Head 2: 看语义关系（同义词）
- Head 3: 看位置关系（远近）
- Head 4: 看其他模式
```

### 实验对比

```
Single-Head (d_model=512):
一个大矩阵学习所有关系

Multi-Head (8 heads, d_k=64):
8个小矩阵学习不同关系，然后拼接

结果：Multi-Head 效果更好！
```

### 原因

1. **表示能力更强**：8个头可以学到8种不同的模式
2. **参数效率高**：虽然总参数差不多，但多头组合更灵活
3. **可解释性强**：可以分析每个头学到了什么

## Q7: Transformer 的计算复杂度是多少？

### Self-Attention 的复杂度

```
Q·K^T 的复杂度：O(n² · d)

其中：
- n = 序列长度 (seq_len)
- d = 模型维度 (d_model)
```

### 为什么是 O(n²)？

```
Q·K^T 产生 [n, n] 的注意力矩阵
需要计算 n×n 个注意力分数
每个分数需要 d 次乘法
总共：n² · d 次操作
```

### 问题

长序列时（例如 n=1000）：
- 内存：需要存储 [1000, 1000] 的注意力矩阵
- 计算：1000² = 1,000,000 次计算

### 解决方案（优化版 Transformer）

1. **Sparse Attention**：只计算部分注意力（例如局部窗口）
2. **Linformer**：用线性投影降低复杂度到 O(n)
3. **Flash Attention**：优化内存访问模式

## Q8: 位置编码（Positional Encoding）是什么？

### 为什么需要位置编码？

Self-Attention 是**无序的**：
```
"我爱中国" 和 "中国爱我"
经过 Attention 后，如果不加位置信息，可能得到相同结果！
```

### 位置编码公式

```python
PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

其中：
- pos: 位置（第几个词，0, 1, 2, ...）
- i: 维度索引（0, 1, 2, ..., d_model/2）
```

### 示例

```
位置0: [sin(0), cos(0), sin(0), cos(0), ...]
位置1: [sin(1), cos(1), sin(1/100), cos(1/100), ...]
位置2: [sin(2), cos(2), sin(2/100), cos(2/100), ...]
```

### 如何使用？

```
Embedding + Positional Encoding

"我" 的向量 = [0.1, 0.3, 0.5, ...] + [sin(0), cos(0), ...]
"爱" 的向量 = [0.2, 0.4, 0.6, ...] + [sin(1), cos(1), ...]
```

## Q9: Encoder 和 Decoder 有什么区别？

### Encoder（编码器）

```
输入：源语言句子（例如："我爱中国"）
目标：生成上下文表示
特点：可以看到整个句子（双向）
```

### Decoder（解码器）

```
输入：目标语言句子（例如："I love China"）
目标：逐词生成翻译
特点：只能看到前面的词（单向）← Masked Attention
```

### 关键区别

| 特性 | Encoder | Decoder |
|------|---------|---------|
| Self-Attention | 双向（看所有词） | 单向（只看前面的词） |
| Masked | 否 | 是（Masked Attention） |
| Cross-Attention | 无 | 有（接收 Encoder 输出） |

### Masked Attention 是什么？

```
生成 "I love China" 时：
- 生成 "I"：只能看到 <start>
- 生成 "love"：只能看到 <start>, "I"
- 生成 "China"：只能看到 <start>, "I", "love"

实现方式：把未来位置的注意力分数设为 -∞
```

## Q10: Transformer 为什么这么强？

### 优点

1. **并行计算**：
   - RNN 必须逐词计算（t1 → t2 → t3）
   - Transformer 可以并行计算所有词

2. **长距离依赖**：
   - RNN 长距离信息会衰减
   - Transformer 通过 Attention 直接建立连接

3. **可扩展性**：
   - 参数越多，效果越好（GPT-3: 1750亿参数）
   - 数据越多，效果越好

### 缺点

1. **计算复杂度高**：O(n²)
2. **内存消耗大**：需要存储注意力矩阵
3. **长序列效率低**：序列越长，复杂度越高
