# Transformer 基础结构详解

## 一、整体架构流程

```
输入文本
   ↓
词嵌入 (Embedding) + 位置编码 (Positional Encoding)
   ↓
┌─────────────────────────────────────────────┐
│        Encoder（编码器，重复 N 层）          │
│  ┌──────────────────────────────────────┐  │
│  │   1. Multi-Head Self-Attention       │  │
│  │      ↓                                │  │
│  │   2. Add & Norm（残差连接 + LayerNorm）│  │
│  │      ↓                                │  │
│  │   3. Feed Forward Network (FFN)      │  │
│  │      ↓                                │  │
│  │   4. Add & Norm（残差连接 + LayerNorm）│  │
│  └──────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
   ↓
┌─────────────────────────────────────────────┐
│        Decoder（解码器，重复 N 层）          │
│  ┌──────────────────────────────────────┐  │
│  │   1. Masked Multi-Head Attention     │  │
│  │      ↓                                │  │
│  │   2. Add & Norm                      │  │
│  │      ↓                                │  │
│  │   3. Cross-Attention (接收 Encoder)   │  │
│  │      ↓                                │  │
│  │   4. Add & Norm                      │  │
│  │      ↓                                │  │
│  │   5. Feed Forward Network            │  │
│  │      ↓                                │  │
│  │   6. Add & Norm                      │  │
│  └──────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
   ↓
Linear + Softmax（输出概率分布）
   ↓
输出文本
```

## 二、核心模块详解

### 1. Self-Attention（自注意力机制）- 最核心！

#### 完整计算流程

```
输入序列 X (shape: [seq_len, d_model])
   │
   ├─────────┬─────────┬─────────┐
   ↓         ↓         ↓         ↓
 WQ 矩阵   WK 矩阵   WV 矩阵
   ↓         ↓         ↓
   Q         K         V
   │         │         │
   │    (转置 K^T)     │
   │         │         │
   └────→ Q·K^T ←─────┘
         ↓
   除以 √dk（缩放）
         ↓
    Softmax（归一化为概率）
         ↓
      注意力权重矩阵 (Attention Weights)
         │
         │    × V
         └────→ 输出
```

#### 详细步骤说明

```
第1步：生成 Q、K、V
─────────────────────
输入 X = [x1, x2, x3]  (假设序列长度为3)

Q = X · WQ   (Query: 查询向量，表示"我要找什么")
K = X · WK   (Key: 键向量，表示"我有什么")
V = X · WV   (Value: 值向量，表示"我的内容是什么")

维度：
- X:  [seq_len, d_model]         例如 [3, 512]
- WQ: [d_model, d_k]              例如 [512, 64]
- Q:  [seq_len, d_k]              例如 [3, 64]


第2步：计算注意力分数
─────────────────────
Attention Score = Q · K^T

例子：
Q = [[q1],    K^T = [k1, k2, k3]
     [q2],
     [q3]]

Q·K^T = [[q1·k1, q1·k2, q1·k3],    ← 第1个词对所有词的注意力
         [q2·k1, q2·k2, q2·k3],    ← 第2个词对所有词的注意力
         [q3·k1, q3·k2, q3·k3]]    ← 第3个词对所有词的注意力

含义：计算每个词对其他词的"相关性"


第3步：缩放（Scale）
─────────────────────
Score_scaled = Score / √dk

为什么要除以 √dk？
- 防止数值过大导致 Softmax 梯度消失
- dk 是 Q、K 的维度（例如 64）


第4步：Softmax 归一化
─────────────────────
Attention_weights = Softmax(Score_scaled)

例子：
原始分数: [3.2, 1.5, 0.8]
         ↓ Softmax
注意力权重: [0.7, 0.2, 0.1]  (总和为1，表示概率分布)

含义：每个词应该关注其他词的"程度"


第5步：加权求和（与 V 相乘）
─────────────────────
Output = Attention_weights · V

例子（针对第1个词）：
Output_1 = 0.7 * v1 + 0.2 * v2 + 0.1 * v3

含义：根据注意力权重，融合所有词的信息
```

### 2. Multi-Head Attention（多头注意力）

```
输入 X
   │
   ├────────┬────────┬────────┬────────┐
   │        │        │        │        │
 Head 1   Head 2   Head 3  ... Head h
   │        │        │        │        │
 (Q,K,V) (Q,K,V) (Q,K,V)   (Q,K,V)
   │        │        │        │        │
   ↓        ↓        ↓        ↓        ↓
Attention Attention ...    Attention
   │        │        │        │        │
   └────────┴────────┴────────┴────────┘
                  ↓
            Concat（拼接）
                  ↓
             线性变换 (WO)
                  ↓
               输出
```

**为什么要多头？**
- 不同的头可以学习不同的关系
- 例如：
  - Head 1: 学习语法关系（主谓宾）
  - Head 2: 学习语义关系（同义词）
  - Head 3: 学习位置关系（远近）

---

### 3. 残差连接（Residual Connection）+ LayerNorm

```
输入 X
   │
   ├──────────────────┐
   │                  │
   ↓                  │
Multi-Head           │
Attention            │ (跳跃连接)
   │                  │
   ↓                  │
  输出                │
   │                  │
   └──────→ + ←───────┘
            ↓
        LayerNorm
            ↓
          输出
```

**公式**：
```
LayerNorm(X + MultiHeadAttention(X))
```

**作用**：
1. **残差连接（+ X）**：
   - 防止梯度消失
   - 让信息更容易传递
   - 让模型更容易训练

2. **LayerNorm**：
   - 归一化，稳定训练
   - 加速收敛

---

### 4. Feed Forward Network（前馈神经网络）

```
输入
  ↓
Linear 1（升维，例如 512 → 2048）
  ↓
ReLU 激活函数
  ↓
Linear 2（降维，例如 2048 → 512）
  ↓
输出
```

**公式**：
```
FFN(x) = ReLU(x · W1 + b1) · W2 + b2
```

**作用**：
- 增加非线性变换能力
- 让模型学习更复杂的特征

## 四、关键概念总结

### 1. Q、K、V 是什么？

| 概念 | 英文 | 中文 | 类比 |
|------|------|------|------|
| Q | Query | 查询 | 我想找什么？（搜索关键词） |
| K | Key | 键 | 你有什么？（图书馆书籍标签） |
| V | Value | 值 | 你的内容是什么？（图书馆书籍内容） |

**举例**：
- 输入句子："我 爱 中国"
- Q: "我" 问：我应该关注哪些词？
- K: "我、爱、中国" 回答：我可以被关注
- V: "我、爱、中国" 提供：我的语义信息

### 2. Softmax 的作用

```
原始分数: [3.2, 1.5, 0.8]
         ↓
      Softmax
         ↓
注意力权重: [0.7, 0.2, 0.1]  (总和为1)
```

**作用**：
- 把分数转换为概率分布
- 强化重要的词，弱化不重要的词

### 3. 残差连接的作用

```python
# 没有残差连接（梯度消失风险）
output = Layer(input)

# 有残差连接（梯度可以直接传递）
output = input + Layer(input)
```

**好处**：
- 防止深层网络梯度消失
- 让信息更容易传递
- 训练更稳定

## 五、直观理解案例

### 案例：翻译 "我爱中国" → "I love China"

```
第1步：Embedding + 位置编码
────────────────────────
"我" → [0.1, 0.3, ..., 0.2]  + 位置信息
"爱" → [0.5, 0.2, ..., 0.8]  + 位置信息
"中国" → [0.3, 0.9, ..., 0.1] + 位置信息


第2步：Self-Attention
────────────────────────
计算 "我" 应该关注哪些词：
- "我" 对 "我" 的注意力：0.3
- "我" 对 "爱" 的注意力：0.5  ← 最大！
- "我" 对 "中国" 的注意力：0.2

结果：融合后的 "我" = 0.3*"我" + 0.5*"爱" + 0.2*"中国"


第3步：FFN
────────────────────────
进一步提取特征，增强表示能力


第4步：Decoder 生成
────────────────────────
根据编码后的信息，逐词生成：
"I" → "love" → "China"
```

## 六、维度变化总结

```
输入：[batch, seq_len, d_model]         例如 [32, 10, 512]
                                        32个句子，每句10个词，每词512维

Embedding + Pos Encoding
   ↓
Q, K, V: [batch, seq_len, d_k]          例如 [32, 10, 64]
                                        每个头的维度通常是 d_model / num_heads

Q · K^T: [batch, seq_len, seq_len]      例如 [32, 10, 10]
                                        注意力矩阵（10个词对10个词的注意力）

Softmax后 · V: [batch, seq_len, d_k]    例如 [32, 10, 64]

Multi-Head Concat: [batch, seq_len, d_model]  例如 [32, 10, 512]
                                        拼接所有头后恢复原维度

FFN: [batch, seq_len, d_model]          例如 [32, 10, 512]
                                        维度不变
```

## 七、关键参数

| 参数 | 典型值 | 说明 |
|------|--------|------|
| d_model | 512 | 模型维度 |
| num_heads | 8 | 多头注意力的头数 |
| d_k | 64 | 每个头的维度（d_model / num_heads） |
| d_ff | 2048 | FFN 中间层维度 |
| num_layers | 6 | Encoder/Decoder 层数 |
