# Transformer 核心流程（超简化版）

## 一、Self-Attention 完整流程（5步）

```
输入词：["我", "爱", "中国"]
           ↓
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第1步：生成 Q、K、V（通过矩阵乘法）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

输入 X    WQ矩阵   WK矩阵   WV矩阵
  ↓         ↓        ↓        ↓
  X · WQ = Q
  X · WK = K
  X · WV = V

结果：
Q = [q_我, q_爱, q_中国]  ← 查询："我要找什么"
K = [k_我, k_爱, k_中国]  ← 键："我有什么"
V = [v_我, v_爱, v_中国]  ← 值："我的内容"


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第2步：计算注意力分数 = Q · K^T
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

     K^T →  [k_我  k_爱  k_中国]
              ↓     ↓      ↓
Q ↓  q_我   [9.2   6.5    3.1]  ← "我"对各词的相关性
     q_爱   [6.5   10.0   7.8]  ← "爱"对各词的相关性
     q_中国 [3.1   7.8    8.9]  ← "中国"对各词的相关性

含义：数字越大，相关性越强


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第3步：缩放（除以 √dk）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Score_scaled = Score / √64 = Score / 8

[9.2   6.5   3.1]      [1.15  0.81  0.39]
[6.5   10.0  7.8]  →   [0.81  1.25  0.98]
[3.1   7.8   8.9]      [0.39  0.98  1.11]

目的：防止数值过大


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第4步：Softmax（转为概率分布）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[1.15  0.81  0.39]      [0.5   0.3   0.2]  ← 总和=1
[0.81  1.25  0.98]  →   [0.2   0.5   0.3]  ← 总和=1
[0.39  0.98  1.11]      [0.1   0.4   0.5]  ← 总和=1

含义：
- "我" 应该关注："我"50%，"爱"30%，"中国"20%
- "爱" 应该关注："我"20%，"爱"50%，"中国"30%
- "中国" 应该关注："我"10%，"爱"40%，"中国"50%


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第5步：加权求和 = Attention_weights · V
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

对于 "我" 这个词：
输出_我 = 0.5 * v_我 + 0.3 * v_爱 + 0.2 * v_中国

对于 "爱" 这个词：
输出_爱 = 0.2 * v_我 + 0.5 * v_爱 + 0.3 * v_中国

含义：根据注意力权重，融合所有词的信息

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 二、残差连接流程

```
输入 X = [x1, x2, x3]
   │
   ├────────────────────┐
   │                    │
   │                    │ (原始输入保留)
   ↓                    │
┌─────────────────┐     │
│ Self-Attention  │     │
└─────────────────┘     │
   │                    │
   ↓                    │
输出 Y = [y1, y2, y3]   │
   │                    │
   └────→ Y + X ←───────┘  ← 残差连接（Add）
           ↓
       LayerNorm  ← 归一化
           ↓
         输出
```

**为什么要加回原始输入？**
- 防止信息丢失
- 让梯度更容易传播
- 训练更稳定

```
    │   ┌─────────────────────┐
    │   │  Multi-Head         │

    │   └─────────────────────┘
    │                 │
    └───────→ + ←─────┘  ← 残差连接1
              ↓
          LayerNorm
              ↓
    ┌─────────┴────────┐

    │   └──────────────────┘
    │                  │
    └───────→ + ←──────┘  ← 残差连接2
              ↓
          LayerNorm
              ↓
            输出
```

## 四、Multi-Head Attention（多头注意力）

```
          输入 X
            │
    ┌───────┼───────┬───────┐
    │       │       │       │
    ↓       ↓       ↓       ↓
  Head1   Head2   Head3   Head4
  (Q,K,V) (Q,K,V) (Q,K,V) (Q,K,V)
    │       │       │       │
    ↓       ↓       ↓       ↓
  Attn1   Attn2   Attn3   Attn4
    │       │       │       │
    └───────┴───────┴───────┘
              ↓
          Concat（拼接）
              ↓
         线性变换 WO
              ↓
            输出
```

**每个头学什么？**
- Head 1: 主谓关系（"我" → "爱"）
- Head 2: 动宾关系（"爱" → "中国"）
- Head 3: 语义关系（同义词）
- Head 4: 位置关系（远近）

## 五、关键公式总结

### 1. Attention 公式

```
Attention(Q, K, V) = Softmax(Q·K^T / √dk) · V
                      ─────  ──────────   ─
                        │         │       │
                        │         │       └─ 加权求和
                        │         └───────── 缩放
                        └─────────────────── 归一化为概率
```

### 2. Multi-Head Attention 公式

```
MultiHead(Q, K, V) = Concat(head1, head2, ..., headh) · WO

其中：
headi = Attention(Q·WQi, K·WKi, V·WVi)
```

### 3. Encoder Layer 公式

```
# 第1个子层
X1 = LayerNorm(X + MultiHeadAttention(X))

# 第2个子层
X2 = LayerNorm(X1 + FFN(X1))
```

## 六、维度变化示例

假设：
- 批次大小 (batch_size) = 2
- 序列长度 (seq_len) = 5
- 模型维度 (d_model) = 512
- 头数 (num_heads) = 8
- 每个头维度 (d_k) = d_model / num_heads = 64

```
输入 X
[2, 5, 512]  ← 2个句子，每句5个词，每词512维
    ↓
生成 Q, K, V（每个头）
[2, 5, 64]   ← 每个头的维度是64
    ↓
Q · K^T
[2, 5, 5]    ← 注意力矩阵：5个词对5个词
    ↓
Softmax后 · V
[2, 5, 64]   ← 每个头的输出
    ↓
8个头拼接
[2, 5, 512]  ← 恢复原维度 (8 × 64 = 512)
    ↓
残差 + LayerNorm
[2, 5, 512]  ← 维度不变
    ↓
FFN (512 → 2048 → 512)
[2, 5, 512]  ← 维度不变
    ↓
残差 + LayerNorm
[2, 5, 512]  ← 最终输出
```

## 七、为什么要这样设计？

### 1. 为什么要 Q、K、V 分开？
- **灵活性**：可以学习不同的表示
- **可解释性**：Query（我要找什么）、Key（你有什么）、Value（你的内容）
- **效果好**：实验证明比单一向量效果好

### 2. 为什么要除以 √dk？
- 防止点积过大
- 防止 Softmax 梯度消失
- 稳定训练

### 3. 为什么要残差连接？
- 防止梯度消失
- 让信息更容易传递
- 训练更深的网络（原论文6层，现在可以几十层）

### 4. 为什么要 LayerNorm？
- 归一化，稳定训练
- 加速收敛
- 减少对初始化的依赖

## 八、快速记忆口诀

```
Self-Attention 五步走：
1. X 变 QKV（三兄弟）
2. Q·K 算分数（看关系）
3. 除根号 dk（防爆炸）
4. Softmax（变概率）
5. 乘以 V（加权和）

完整流程：
输入 → Attention → 加回去 → Norm
     → FFN → 加回去 → Norm → 输出
```
