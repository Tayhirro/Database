# 术语索引（Context）

导航：[README.md](README.md)

## C
- ContextWindow（上下文窗口）：模型可处理的最大 token 长度。见 [ContextWindow.md](ContextWindow.md)

## L
- LongContext-Attention（长上下文注意力）：分块注意力优化技术，包括DCA、StreamingLLM等，用于降低长序列O(L²)复杂度。见 [LongContext-Attention.md](LongContext-Attention.md)

## P
- PositionInterpolation（位置插值）：扩展位置编码范围。见 [PositionInterpolation.md](PositionInterpolation.md)

## R
- RAG（Retrieval-Augmented Generation）：检索增强生成。见 [RAG.md](RAG.md)

## S
- StreamingLLM：处理无限长输入的技术。见 [StreamingLLM.md](StreamingLLM.md)
