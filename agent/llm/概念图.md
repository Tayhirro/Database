## 跨分支关系

| 源 | 关系 | 目标 |
|---|---|---|
| Pretraining | 依赖 | Tokenizer |
| SFT | 前置于 | RLHF |
| LoRA | 结合 | Quantization → QLoRA |
| KVCache | 优化于 | PagedAttention |
| RoPE | 扩展于 | PositionInterpolation |
| CoT | 扩展于 | SelfConsistency |
| RLHF | 替代于 | DPO |
| FlashAttention | 加速 | SelfAttention |
