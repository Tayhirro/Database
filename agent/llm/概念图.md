## 训练流程

```
Pretraining → SFT → Alignment → [Reasoning] → [Agentic] → Production
    ↑           ↑        ↑            ↑             ↑
    │           │        │            │             │
  范式:     范式:SL   范式:RL/PO   范式:RL      范式:RL/SL
  SSL
```

## 跨分支关系

| 源 | 关系 | 目标 |
|---|---|---|
| Pretraining | 依赖 | Tokenizer |
| SFT | 前置于 | Alignment |
| Alignment | 前置于 | Reasoning / Agentic |
| LoRA | 结合 | Quantization → QLoRA |
| KVCache | 优化于 | PagedAttention |
| RoPE | 扩展于 | PositionInterpolation |
| CoT | 扩展于 | SelfConsistency |
| RLHF | 替代于 | DPO |
| FlashAttention | 加速 | SelfAttention |
| Agentic Training | 交叉引用 | [agent/tool/](../../tool/) |
