# 术语索引（Evaluation）

导航：[README.md](README.md)

## C
- CrossEntropy（交叉熵损失）：语言模型训练的核心损失函数，衡量预测分布与真实分布的差异。见 [CrossEntropy.md](CrossEntropy.md)

## G
- GSM8K：小学数学推理基准。见 [benchmarks/GSM8K.md](benchmarks/GSM8K.md)

## H
- HumanEval：代码生成基准。见 [benchmarks/HumanEval.md](benchmarks/HumanEval.md)

## M
- MMLU（Massive Multitask Language Understanding）：多任务理解基准。见 [benchmarks/MMLU.md](benchmarks/MMLU.md)
- MTBench：多轮对话基准。见 [benchmarks/MTBench.md](benchmarks/MTBench.md)

## P
- Perplexity（困惑度）：语言模型的概率评估指标。见 [Perplexity.md](Perplexity.md)

## S
- SafetyEval（安全性评估）：模型安全相关评测。见 [SafetyEval.md](SafetyEval.md)
