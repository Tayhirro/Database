# 术语索引（LLM 架构）

导航：[README.md](README.md) | [概念图.md](概念图.md)

> 用法：按首字母或关键词查找；点击链接跳转到对应模块页。

## A
- Attention（注意力）：通过 Query-Key 相似度加权 Value 的信息聚合机制。见 [modules/SelfAttention.md](modules/SelfAttention.md)

## F
- FFN / MLP（前馈网络）：Transformer 层中对每个 token 独立作用的非线性变换。见 [modules/FFN.md](modules/FFN.md)

## G
- GQA（Grouped Query Attention）：将 Query 头分组，每组共享一套 KV 头，平衡表达力与 KV-cache 开销。见 [modules/GQA.md](modules/GQA.md)
- GLU（Gated Linear Unit）：带门控的线性单元；SwiGLU 为其变体。见 [modules/FFN.md](modules/FFN.md)

## L
- LayerNorm（层归一化）：沿特征维度做 zero-mean unit-variance 归一化。见 [modules/RMSNorm.md](modules/RMSNorm.md)

## M
- MHA（Multi-Head Attention）：多头注意力，将 QKV 拆分成多个头并行计算后拼接。见 [modules/SelfAttention.md](modules/SelfAttention.md)
- MoE（Mixture of Experts）：用路由网络选择 k 个专家子网络处理每个 token。见 [modules/MoE.md](modules/MoE.md)
- MQA（Multi-Query Attention）：所有 Query 头共享同一套 KV；GQA 的极端情形。见 [modules/GQA.md](modules/GQA.md)

## P
- Pre-Norm：归一化放在子层输入端（Attention/FFN 之前）。见 [modules/PreNorm.md](modules/PreNorm.md)
- Post-Norm：归一化放在子层输出端（残差加法之后）。见 [modules/PreNorm.md](modules/PreNorm.md)

## Q
- QK-Norm：在 Attention 中对 Q、K 向量分别做归一化以稳定训练。见 [modules/QKNorm.md](modules/QKNorm.md)

## R
- RMSNorm（Root Mean Square Normalization）：只做 scale 不做 shift 的归一化；去掉 mean-centering。见 [modules/RMSNorm.md](modules/RMSNorm.md)
- RoPE（Rotary Position Embedding）：用旋转矩阵把绝对位置编码为 QK 的相对角度。见 [modules/RoPE.md](modules/RoPE.md)

## S
- Self-Attention（自注意力）：Query、Key、Value 均来自同一序列的 Attention。见 [modules/SelfAttention.md](modules/SelfAttention.md)
- SwiGLU：Swish 激活 + GLU 结构的 FFN 变体。见 [modules/FFN.md](modules/FFN.md)

## T
- Transformer：基于 Attention 的序列建模架构。见 [modules/Transformer.md](modules/Transformer.md)
