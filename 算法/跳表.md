# 跳表（Skip List）

跳表是一种基于链表的数据结构，通过添加多级索引实现快速查找、插入和删除，时间复杂度为 **O(log n)**。

---

## 核心思想

在有序链表的基础上，每隔几个节点提取一个节点建立索引层，形成多层结构。查询时从顶层开始，逐层向下缩小范围。

```
Level 3:  head ──────────────────────► 25 ─► null
              ↓
Level 2:  head ────────────► 12 ────────► 25 ─► null
              ↓                ↓
Level 1:  head ──────► 6 ──────► 12 ──► 19 ──► 25 ─► null
              ↓          ↓        ↓       ↓      ↓
Level 0:  head ──► 3 ──► 6 ──► 7 ──► 9 ──► 12 ──► 17 ──► 19 ──► 21 ──► 25 ──► 26 ──► null
              
查询 21 的路径：
- Level 3: 在 head，21 > 25? 否，停留在 head
- Level 2: 从 head，21 > 12? 是，跳到 12；21 > 25? 否，停留
- Level 1: 从 12，21 > 19? 是，跳到 19；21 > 25? 否，停留  
- Level 0: 从 19，21 > 21? 否，检查 19->next = 21 ✓ 命中！
```

## 完整实现（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

template<typename T, typename Compare = less<T>>
class SkipList {
    struct Node {
        T value;
        vector<Node*> next;  // next[i] 表示第 i 层的后继
        Node(T v, int level) : value(v), next(level, nullptr) {}
    };

    const int MAX_LEVEL = 16;
    const float P = 0.5;          // 晋升概率
    Compare cmp;
    
    Node* head;                   // 哨兵头节点，包含所有层
    int level;                    // 当前最大层数
    mt19937 rng{random_device{}()};
    
    // 随机生成层数：1~MAX_LEVEL，每层晋升概率 P
    int randomLevel() {
        int lvl = 1;
        while (uniform_real_distribution<float>(0, 1)(rng) < P && lvl < MAX_LEVEL)
            ++lvl;
        return lvl;
    }

public:
    SkipList() : level(1) {
        head = new Node(T{}, MAX_LEVEL);
    }
    
    ~SkipList() {
        Node* cur = head;
        while (cur) {
            Node* nxt = cur->next[0];
            delete cur;
            cur = nxt;
        }
    }

    // 查询：返回是否存在，并打印查找路径（调试用）
    bool search(T target, bool printPath = false) {
        Node* cur = head;
        vector<pair<int, T>> path;  // (层数, 当前值)
        
        // 自顶向下查找
        for (int i = level - 1; i >= 0; --i) {
            // 在当前层尽可能向右走
            while (cur->next[i] && cmp(cur->next[i]->value, target)) {
                cur = cur->next[i];
            }
            if (printPath) path.push_back({i, cur->value});
        }
        
        // 现在 cur 是底层中值小于 target 的最大节点
        cur = cur->next[0];
        bool found = (cur && !cmp(cur->value, target) && !cmp(target, cur->value));
        
        if (printPath) {
            cout << "查询 " << target << " 的路径（自顶向下）：\n";
            for (auto& [lv, val] : path) 
                cout << "  Level " << lv << ": 停在 " << val << "\n";
            cout << "  Level 0: 检查 " << (cur ? to_string(cur->value) : "nullptr") 
                 << " -> " << (found ? "命中" : "未命中") << "\n";
        }
        return found;
    }

    // 插入（仅用于构造示例数据）
    void insert(T val) {
        vector<Node*> update(MAX_LEVEL, nullptr);
        Node* cur = head;
        
        for (int i = level - 1; i >= 0; --i) {
            while (cur->next[i] && cmp(cur->next[i]->value, val))
                cur = cur->next[i];
            update[i] = cur;
        }
        
        cur = cur->next[0];
        if (!cur || cmp(val, cur->value) || cmp(cur->value, val)) {
            int newLevel = randomLevel();
            if (newLevel > level) {
                for (int i = level; i < newLevel; ++i)
                    update[i] = head;
                level = newLevel;
            }
            
            Node* newNode = new Node(val, newLevel);
            for (int i = 0; i < newLevel; ++i) {
                newNode->next[i] = update[i]->next[i];
                update[i]->next[i] = newNode;
            }
        }
    }

    // 可视化跳表结构
    void display() {
        cout << "\n=== 跳表结构 ===\n";
        for (int i = level - 1; i >= 0; --i) {
            cout << "Level " << i << ": ";
            Node* cur = head->next[i];
            while (cur) {
                cout << cur->value << " -> ";
                cur = cur->next[i];
            }
            cout << "null\n";
        }
        cout << "================\n";
    }
};

int main() {
    SkipList<int> sl;
    
    // 构造示例数据（插入时层数随机，结果可能不同）
    vector<int> data = {3, 6, 7, 9, 12, 17, 19, 21, 25, 26};
    for (int x : data) sl.insert(x);
    
    sl.display();
    
    // 示例 1：查询存在的值 21
    cout << "\n[示例 1] 查询存在的元素 21:\n";
    bool r1 = sl.search(21, true);
    cout << "结果: " << (r1 ? "存在" : "不存在") << "\n";
    
    // 示例 2：查询不存在的值 15
    cout << "\n[示例 2] 查询不存在的元素 15:\n";
    bool r2 = sl.search(15, true);
    cout << "结果: " << (r2 ? "存在" : "不存在") << "\n";
    
    return 0;
}
```

## 时间复杂度

| 操作 | 平均复杂度 | 最坏复杂度 |
|------|-----------|-----------|
| 查询 | O(log n) | O(n) |
| 插入 | O(log n) | O(n) |
| 删除 | O(log n) | O(n) |

**为什么是 O(log n)**：
- 每次晋升概率 P=0.5，期望层数为 1/(1-P) = 2
- 每层期望比较次数约为 1/P = 2
- 总层数期望为 log₁/ₚ(n) ≈ log₂(n)
- 所以总操作次数 ≈ 2 × log₂(n) = O(log n)

---

## 空间复杂度

- **最坏**：O(n × MAX_LEVEL) — 每个节点都到最高层
- **平均**：O(2n) = O(n) — 每个节点平均2层

---

## 与其他数据结构对比

| 数据结构 | 查询 | 插入 | 删除 | 实现难度 |
|---------|------|------|------|---------|
| 数组 | O(log n) | O(n) | O(n) | 简单 |
| 链表 | O(n) | O(1) | O(1) | 简单 |
| 平衡二叉树(AVL) | O(log n) | O(log n) | O(log n) | 复杂 |
| **跳表** | **O(log n)** | **O(log n)** | **O(log n)** | **简单** |
| 哈希表 | O(1) | O(1) | O(1) | 中等 |

**跳表优势**：
- 实现简单（比红黑树、AVL简单得多）
- 支持范围查询（哈希表不支持）
- 并发性能好（Redis使用跳表实现Sorted Set）

## 应用场景

1. **Redis Sorted Set** - 跳表 + 哈希表实现
2. **LevelDB** - MemTable使用跳表
3. **Lucene** - 倒排索引的跳表优化
4. **并发场景** - 无锁跳表实现
