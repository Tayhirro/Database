# 贝尔曼方程（Bellman Equation）

## 1. 一句话
Bellman 方程把"未来期望回报"写成"即时奖励 + 下一状态价值"的递推形式。

## 2. Bellman 期望方程（Evaluation）
用于评估**给定策略 pi** 的价值函数。

### V 的递推

$$
V^{\pi}(s) = \sum_a \pi(a|s) \left[ R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^{\pi}(s') \right]
$$

意思：在状态 s，按策略 pi 平均所有可选动作，每个动作带来即时奖励 R + 折扣后的下一状态期望值。

### Q 的递推

$$
Q^{\pi}(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) \sum_{a'} \pi(a'|s') Q^{\pi}(s',a')
$$

### 不写展开式的直观理解

Bellman 期望方程就是"现在 + 未来"的递归关系，不展开成无穷级数。因为 MDP 满足马尔可夫性，未来只取决于当前状态，所以能这样递推。

## 3. Bellman 最优方程（Optimality）
用于找**最优策略** pi*。

### 第一性原理：最优性原理（Bellman, 1957）
一个最优策略，它的子策略也是最优的。
如果在 (s,a) 之后，从 s' 开始你有一个最优策略，那后面的期望回报就是 max Q*，而不是按某个固定 pi 平均。
### 推导 Q* 最优方程

```
Q*(s,a) = E[ r + γ * (从 s' 开始能拿到的最好回报) | s,a ]
```
从 s' 开始，最优行为就是选那个让 Q* 最大的动作 a'。所以"最好回报" = max_{a'} Q*(s',a')。
代入即得：

$$
Q^{*}(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) \max_{a'} Q^{*}(s',a')
$$
max 出现的原因是**最优性原理的直接结果**：你假设后面会执行最优策略，而不是某个固定的 pi。

### V* 的最优方程（一般不直接用）

同理，但 V* 在一开始就选最好的动作：

$$
V^{*}(s) = \max_a \left[ R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^{*}(s') \right]
$$



### 怎么用
- Q* 已知后，最优策略直接取 greedy：$\pi^{*}(a|s) = \arg\max_a Q^{*}(s,a)$
- 不需要显式计算策略，也不需要期望方程里对动作的求和
- Q-learning 就是在学 Q*（用 max 近似）

## 4. 两个方程的区别

| | 期望方程 | 最优方程 |
|--|---------|---------|
| 针对 | 给定策略 pi | 最优策略 pi* |
| 动作如何处理 | 按 pi 平均 | 取 max |
| 用途 | 策略评估 | 策略改进 |
| 典型算法 | MC/TD 估计 V^pi | Q-learning、DQN |

## 5. 速查
- Bellman 期望方程 + 策略迭代 = 动态规划
- Bellman 最优方程 + Q-learning = 无模型 RL
- 没有转移概率 P 时，用采样替代（MC/TD 就是在做这件事）
