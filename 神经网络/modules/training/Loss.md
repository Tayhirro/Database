# Loss / Objective / ERM（经验风险最小化）

训练一个模型，本质就是：选参数 `θ`，最小化一个可优化的**目标函数（objective）**；在深度学习语境里它通常被叫做 **loss**。  
为了强调这种“一般性”，可以用 ERM（经验风险最小化）把不同学习范式统一到同一个形式里。

## 1. ERM 的最一般形式（不以 `y` 为前提）

把“你认为来自真实世界的数据/交互结果”统一记作随机变量 `u`，其真实分布记作 `p_data`：

$$\min_{\theta}\; \mathbb{E}_{u \sim p_{\text{data}}}\big[\ell_{\theta}(u)\big]$$

训练时用有限样本近似期望（经验风险）：

$$\min_{\theta}\; \frac{1}{N}\sum_{i=1}^{N}\ell_{\theta}(u_i)$$

重点不在于 `u` 里有没有 `y`，而在于：

- 你把什么当成 `u`（你的“数据点”到底是什么）
- 你如何定义 `\ell_\theta(u)`（你希望模型在 `u` 上做到什么）

## 2. `u` 的常见取法（把不同范式放进同一个框）

不同学习范式的差别，很多时候只体现在 `u` 的定义上：

| 范式 | 典型的 `u` | 直观含义 |
| --- | --- | --- |
| 监督学习 | `u=(x,y)` | 一个输入-标签对 |
| 无监督学习 | `u=x` | 一个观测样本 |
| 自监督学习 | `u=(x, t(x))` | 同一数据的两种“视角/任务形式”（增强、mask、next-token…） |
| 强化学习 | `u=\tau` 或转移样本 | 与环境交互得到的轨迹/序列数据 |

在这个视角下，“有无 `y`”只是 `u` 的一种组织方式，不是 loss/训练目标的一般性前提。

## 3. `\ell_\theta(u)` 通常长什么样（几个高频模板）

把需求翻译成 loss 时，最常见的模板是“负对数似然 / 下界 / 对比式目标 / 回报最大化”等：

- **条件预测**：`\ell_\theta(x,y) = -\log p_\theta(y|x)`（交叉熵是其常见实现）
- **密度建模 / 生成**：`\ell_\theta(x) = -\log p_\theta(x)`（拟合 `p(x)` 或 `p(x|c)`）
- **变分推断（VAE）**：`\ell_\theta(x) = -\mathrm{ELBO}(x)`（用可优化的下界替代难算的 `\log p_\theta(x)`；见 [ELBO.md](ELBO.md)）
- **对比/匹配类目标**：把“相似的拉近、不相似的推远”写成 softmax/InfoNCE 形式（见 [ContrastiveLearning.md](ContrastiveLearning.md)）
- **强化学习**：把“回报大”转成可优化目标（例如最大化 `\mathbb{E}[R(\tau)]`，等价最小化 `-\mathbb{E}[R(\tau)]`）

## 4. 正则化/先验：也可以视作 loss 的一部分

很多实际目标会写成：

$$\min_{\theta}\; \mathbb{E}[\ell_{\theta}(u)] + \lambda \Omega(\theta)$$

其中 `\Omega(\theta)` 可以理解为“工程正则”，也可以从 MAP/先验角度理解为对参数的偏好约束（例如 `L2` 对应高斯先验）。
