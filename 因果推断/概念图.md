# 概念图（因果推断）

导航：[因果推断/README.md](README.md) ｜[因果推断/索引.md](索引.md)

## 1. 核心“对象”

- `StructuralCausalModel`：`M = (U, V, F, P(U))`
- `U`：外生变量 / 背景噪声
- `V`：内生变量 / 系统内变量
- `F`：结构方程族，规定每个 `V_i` 怎么生成
- `P(U)`：外生变量的分布

入口：[structures/StructuralCausalModel.md](structures/StructuralCausalModel.md)

## 2. SCM 作为推理引擎

- 输入：
  - Assumptions
  - Queries
  - Data
- 输出：
  - Estimand
  - Estimate
  - Fit indices
- 这条链说明：
  - `SCM` 不只定义对象，还规定“在给定假设和数据条件下，查询如何被识别、估计与检验”

## 3. 从对象导出的三个层次

- 观测层：`P(Y|X=x)`
- 干预层：`P(Y|do(X=x))`
- 反事实层：`P(Y_x=y | e)`

其中：

- 观测层只是在现有世界里条件化
- 干预层会改写结构方程
- 反事实层会问“同一个单位在另一个世界里会怎样”

## 4. 图视角上的常用规则

- `SCM` 在无环情形下可投影为 DAG
- 图不是全部语义，但能提供快速推理规则
- 最常用的两个图规则：
  - `d-separation`：判断哪些路径被阻断
  - `backdoor criterion`：判断能否用调整集合识别因果效应
- 更一般的识别层：
  - `do-calculus`：在给定图假设下化简 `do` 查询

## 5. Pearl 2019：推理引擎、三层层级与七工具

- 先把 `SCM` 表述为 inference engine：
  - `Assumptions + Queries + Data -> Estimand + Estimate + Fit indices`

- 三层层级：
  - Association：`P(Y|X=x)`
  - Intervention：`P(Y|do(X=x))`
  - Counterfactual：`P(Y_x | x', y')`
- 七类工具：
  - Tool 1：编码因果假设
  - Tool 2：混杂控制与 `do-calculus`
  - Tool 3：反事实算法化
  - Tool 4：中介分析
  - Tool 5：适应性 / 外部效度 / 样本选择偏差
  - Tool 6：缺失数据恢复
  - Tool 7：因果发现

## 7. 从基础到扩展的依赖链

- `SCM` → inference engine → `Estimand / Estimate / Fit indices`
- `SCM` → 干预 `do(.)` → `P(Y|do(X=x))`
- `SCM` → 图视角 → `d-separation` → backdoor adjustment
- `SCM` → 干预语义 → 反事实 `Y_x`
- `SCM` → 图语义 → `do-calculus` → 更一般识别
- `SCM` → 反事实语义 → mediation / explanation
- `SCM` → 机制稳定性假设 → transportability / external validity
- `SCM` → 缺失机制建模 → missing data recovery
- `SCM` + 图 / 函数 / 环境变化假设 → causal discovery
