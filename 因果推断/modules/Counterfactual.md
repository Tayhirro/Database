# 反事实（Counterfactual）

## 1. 一句话

- 反事实问的是：对同一个体，假如当时把某个变量改成别的值，结果会不会不同。

## 2. 典型记号

- `Y_x`：把 `X` 设成 `x` 后，`Y` 会是多少
- `Y_x(u)`：对具有特定外生噪声 `u` 的那个体，干预后的 `Y`

## 3. 它和干预有什么区别

- 干预 `P(Y|do(X=x))`：问总体平均效果
- 反事实 `Y_x`：问同一个体在另一个世界里会怎样

所以反事实比平均干预更细，也更强。

## 4. 在 Pearl 体系里的三步

反事实通常按 `abduction -> action -> prediction` 三步理解：

1. `abduction`：先用已观测到的证据推断这个体更可能对应哪些外生变量
2. `action`：在模型里执行干预，改写结构方程
3. `prediction`：在改写后的世界里，预测目标变量

## 5. 为什么它依赖 SCM

- 只靠 DAG 往往不够
- 反事实需要知道结构方程怎么写、噪声怎么进入系统
- 所以它依赖完整的 [../structures/StructuralCausalModel.md](../structures/StructuralCausalModel.md)

## 6. 一个直觉例子

- 已知某病人今天吃了药且恢复了
- 反事实问题是：如果是同一个病人今天没吃药，还会恢复吗

这不是在换一群病人平均比较，而是在问同一个体的平行世界。

## 7. 速查

- 反事实比干预更强
- 反事实通常写成潜在结果形式 `Y_x`
- 没有完整结构语义时，很多反事实问题无法回答
