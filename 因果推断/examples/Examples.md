# Examples（因果推断）

## 1. 混杂例子：药物与恢复

图：

- `Z -> X`
- `Z -> Y`
- `X -> Y`

变量含义：

- `Z`：病情严重程度
- `X`：是否吃药
- `Y`：是否恢复

关键点：

- `P(Y|X=1)` 混进了病情差异
- `P(Y|do(X=1))` 才对应“统一给药”的效果
- 若 `Z` 可观测，可以用 backdoor adjustment

## 2. collider 例子：错误控制

图：

- `X -> Z <- Y`

关键点：

- 默认 `X` 与 `Y` 通过这条路径是不连通的
- 若你控制了 `Z`，反而会把这条路径打开

这就是“不是所有看起来相关的变量都该控制”。
